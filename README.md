# 당근망가번역기

만화 원고의 **OCR → 번역 → 원문 제거 → 식자·검수 → 출력**을 처리하는 데스크톱 앱입니다. OCR은 이미지 속 글자를 읽는 단계, 식자는 번역문을 원고에 배치하는 단계입니다. **Gemma 로컬·Codex·OpenAI 호환 API**로 번역하고, **MCP**로 외부 AI 앱에서 보관함 조회·편집·출력을 요청할 수 있습니다.

## 성인용 만화에서 Gemma 4 사용이 어렵다면: OpenCode Go + DeepSeek V4.1 Flash

**PC 사양이나 실행 환경 때문에 Gemma 4 로컬 번역이 여의치 않다면, OpenCode Go의 DeepSeek V4.1 Flash를 대안으로 강력 추천합니다.** 특히 **수위 높은 성인용 만화에서 대안을 찾는 경우** 우선 추천하는 모델입니다.

처음에는 **월 US$10인 Go 기본 요금제부터 시작하는 것을 추천합니다.** 사용량이 부족한지 확인한 뒤 상위 요금제를 검토하세요. 2026-10-06 확인 기준 가격이며, 무제한 요금제가 아니라 시간대별·주간·월간 사용 한도가 있습니다. [공식 요금·사용 한도](https://opencode.ai/docs/go/#usage-limits)

**OpenCode GO 빠른 설정은 v3.2.0부터 사용할 수 있습니다.** 이전 설치본을 사용 중이라면 위 다운로드 링크에서 업데이트하세요.

### 1. OpenCode Go 가입과 API 키 발급

1. [OpenCode Go 가입 페이지](https://opencode.ai/console/go)를 열고 로그인합니다. 계정이 없다면 화면 안내에 따라 계정을 만듭니다.
2. 사용할 워크스페이스를 선택하고 **Go — $10/month** 요금제를 구독합니다. 결제 화면에서 월 결제 금액을 확인하세요. Go Plus는 상위 요금제이며, 처음 연결하는 데 필수는 아닙니다.
3. 구독한 워크스페이스의 콘솔에서 **API Keys** 항목을 엽니다. 키 생성 기능으로 새 API 키를 만들고, 이름을 입력하는 경우 `CarrotMangaTranslator`처럼 용도를 알아볼 수 있게 적습니다.
4. 발급된 **API 키 전체를 복사**합니다. 아래 당근망가번역기의 API 키 칸에 붙여 넣을 값입니다. OpenCode Go를 구독한 워크스페이스의 키를 사용하세요. 키가 포함된 화면이나 문자열을 이슈·채팅에 공개하지 마세요.

공식 가입 흐름은 **콘솔 로그인 → Go 구독 → API 키 복사**입니다. 화면 구성이나 버튼 이름은 변경될 수 있습니다. [OpenCode Go 공식 안내](https://opencode.ai/docs/go/#how-it-works)

### 2. 당근망가번역기에 연결

1. **설정 열기** (`Ctrl+,`) → **번역**으로 이동하고 번역 엔진을 **API**로 선택합니다.
2. **API 제공자 빠른 설정 → OpenCode GO**를 선택합니다.
3. **API 키** 칸에 앞에서 복사한 키를 붙여 넣습니다. 모델 ID가 **`deepseek-v4.1-flash`**인지 확인합니다.
4. 연결 시험을 실행한 뒤 설정을 저장하고, 먼저 한 페이지를 번역해 말풍선별 대사와 결과를 확인합니다.

빠른 설정이 아래 값을 자동으로 채웁니다. 고급 설정을 직접 바꿨거나 환경 백업을 복원했다면 함께 확인하세요.

| 항목             | 설정값                                       |
| ---------------- | -------------------------------------------- |
| Base URL         | `https://opencode.ai/zen/go/v1`              |
| 모델 ID          | `deepseek-v4.1-flash`                        |
| 대화별 세션 헤더 | 켜짐                                         |
| 세션 헤더 이름   | `x-opencode-session`                         |
| 추가 요청 JSON   | `{"response_format":{"type":"json_object"}}` |

**추가 요청 JSON의 `json_object` 설정은 유지하세요.** 이 모델에 JSON Schema 형식을 요구하면 HTTP 400이 발생한 사례가 있어 빠른 설정에 JSON 모드를 넣었습니다. 인증 오류가 나면 키와 구독 워크스페이스를, 사용량 제한이면 콘솔의 남은 한도를 확인하세요. Go의 모델 목록은 앱에서 자동 조회하지 않으므로 모델 ID를 직접 확인합니다.

이 연결은 당근망가번역기가 API를 직접 호출합니다. OpenCode 프로그램을 별도로 설치하거나 실행할 필요는 없습니다. 번역할 페이지 이미지와 OCR·참고 문맥은 외부 API로 전송되며, OCR·원문 제거 엔진은 별도로 설정합니다.

## 시작하기

1. 앱을 설치하고 **설정 → 번역**에서 원문·번역 언어와 엔진을 선택합니다.
2. **OCR**, **이미지 · 원문 제거**에서 모델을 정한 뒤 **확인 · 업데이트 → OCR/모델 확인**을 실행합니다.
3. **새 원본 추가**로 원고를 가져오고 화를 엽니다.
4. **번역 설정…** (`T`)에서 한 페이지와 실행할 작업을 선택합니다.
5. 원문·번역문을 교정하고 원문 제거·배치·서식을 확인합니다.
6. **결과물 출력** (`Ctrl+E`)으로 저장합니다. 결과가 맞으면 나머지 페이지를 처리합니다.

## 설치

| 환경              | 설치 방법                                                                                 |
| ----------------- | ----------------------------------------------------------------------------------------- |
| Windows 10/11     | 릴리스의 **Setup EXE** 실행 → 데이터 폴더 선택                                            |
| Apple Silicon Mac | **arm64 DMG 또는 ZIP** 다운로드 → 응용 프로그램으로 이동. macOS 14 이상, Intel Mac 미지원 |

실행 경고가 나오면 해당 릴리스의 서명 상태와 체크섬을 확인하세요. macOS 첫 실행 승인은 **시스템 설정 → 개인정보 보호 및 보안**에서 할 수 있습니다. [서명 정책](CODE_SIGNING_POLICY.md)

모델·런타임은 별도로 내려받습니다. 첫 준비에는 인터넷과 여유 저장 공간이 필요합니다. 로컬 Gemma·OCR·인페인팅은 준비 후 PC에서 실행되며, Codex·외부 API·인터넷 조사는 네트워크 연결이 필요합니다.

## 번역 엔진과 언어

**설정 열기** (`Ctrl+,`)의 왼쪽 목록에서 **번역**을 선택합니다. 앱 표시 언어는 **일반**, 원고와 번역의 언어는 **번역**에서 지정합니다.

![번역 엔진·언어와 Codex 로그인·모델 설정](docs/images/readme-current/settings.png)

| 엔진           | 준비·선택 항목                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Gemma 로컬** | Hugging Face 또는 로컬 모델 파일, 모델 계열·프리셋, 장치에 맞는 런타임. RAM/VRAM이 부족하면 작은 프리셋부터 사용 |
| **Codex**      | 앱 안에서 ChatGPT 로그인 → 사용 가능한 모델·추론 강도 선택. 앱 내 번역에는 별도 Codex CLI 설치 불필요            |
| **API**        | 제공자 빠른 설정 또는 Base URL·모델 ID·인증 정보 직접 입력. OpenAI 호환 로컬 서버도 연결 가능                    |

- **Gemma 메모리:** 프리셋의 메모리 표기는 선택 기준입니다. 문맥 길이·이미지·다른 프로그램 사용량도 영향을 줍니다. 여유 VRAM과 이미지 처리 위치를 조정할 수 있습니다.
- **API 연결:** 모델 목록과 이미지 입력 지원을 확인합니다. 여러 키, 호출 간격·재시도는 제공자의 제한에 맞춥니다. 제공자별 인증 방식은 해당 설정을 사용합니다.
- **API 고급값:** Temperature·top_p·top_k·reasoning_effort·추가 JSON·사용자 헤더는 연결한 서버가 지원하는 값만 입력합니다.
- **생성 한도:** 최대 출력 토큰은 응답 길이, 문맥 한도·작품 정보 예산은 참고할 정보량에 관계됩니다. 설정의 권장값을 기준으로 조정합니다.

## OCR·이미지·하드웨어 설정

번역 엔진과 아래 항목은 각각 설정합니다. 번역 엔진을 바꿔도 OCR·원문 제거·이미지 생성·인터넷 조사 엔진이 함께 바뀌지는 않습니다.

| 설정                   | 주요 항목                                                                               |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **OCR**                | HayaiOCR / PaddleOCR, 실행 장치. 영역 검출·문자 인식 결과는 같은 페이지로 비교          |
| **이미지 · 원문 제거** | AOT / LaMa / Flux와 지원 백엔드, 별도의 Codex 이미지 모델·추론 강도, 전송 이미지 가리기 |
| **인터넷 조사**        | Tavily 키·사용량, 검색 결과 분석 모델. Codex 조사는 Codex 계정 사용                     |
| **하드웨어**           | 앱 그래픽 GPU와 로컬 AI 연산 GPU, 장치별 권장값. 그래픽 GPU 변경은 저장 후 재시작 필요  |
| **확인 · 업데이트**    | 현재 버전·릴리스 페이지, OCR·모델 다운로드 및 실행 상태 확인                            |
| **일반**               | 앱 언어·휠 줌 민감도·환경 백업 및 이관                                                  |

## 원고 가져오기와 보관함

보관함은 **작품 → 화 → 페이지 → 블록** 구조입니다. 작품에는 공통 용어·인물 정보가, 페이지에는 원본·번역 블록·보정 결과가 저장됩니다. 블록은 대사·나레이션·효과음처럼 따로 편집하는 영역입니다.

![새 원본 추가의 입력 방식](docs/images/readme-current/import.png)

| 입력                       | 방법                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| PNG·JPEG·WebP              | 이미지 또는 이미지 폴더 선택. 파일·폴더 드래그도 지원            |
| ZIP·CBZ·RAR·CBR            | 압축파일 안의 이미지 확인 후 추가                                |
| PDF                        | 페이지를 이미지로 가져오기                                       |
| 여러 화가 든 폴더·압축파일 | **여러 화 추가**에서 생성할 화·제목·순서 확인                    |
| 웹 페이지                  | **링크로 열기** → 이미지 불러오기 → 크기 필터·선택으로 대상 지정 |
| `.mgtshare`                | **작업 가져오기**로 편집 데이터를 포함한 작업 복원               |

가져오기 미리보기에서 **새 작품 / 기존 작품**과 포함할 항목을 정합니다. 결과물 자동 저장도 이때 켤 수 있습니다. 손상·미지원 파일의 제외 여부를 확인하고, 웹 로그인·접근 제한으로 읽지 못하는 원고는 직접 준비한 파일을 사용하세요.

보관함에서는 작품·화 검색, 이름 변경, 정렬·순서 이동을 합니다. 페이지 목록의 **상태 필터**, **소요 시간**, 각 페이지의 **더 보기**로 처리 상태와 관리 명령을 확인합니다.

## 번역과 페이지 작업

화를 열고 **번역 설정…** (`T`)에서 대상 페이지와 실행 단계를 고릅니다. HayaiOCR은 **기존 버전 / 새 버전**을 전환할 수 있으며 마지막 선택을 기억합니다.

### 단계별 페이지 작업

![HayaiOCR 페이지 선택·작업 프리셋·실행 순서](docs/images/readme-current/workflow.png)

| 프리셋          | 실행 단계                                               |
| --------------- | ------------------------------------------------------- |
| **전체 처리**   | 검출 → OCR → 번역 → 자동 서식 → 원문 제거 → 배치 → 검수 |
| **손번역 준비** | 검출 → OCR → 원문 제거                                  |
| **원문 제거만** | 검출 → 원문 제거                                        |
| **번역만**      | 저장된 원문으로 번역 → 검수                             |
| **식자 마무리** | 자동 서식 → 원문 제거 → 배치 → 검수                     |

- **기존 결과 보존:** 기본적으로 빈 항목만 처리합니다. 다시 처리할 내용은 각 단계의 세부 옵션에서 지정합니다.
- **OCR 교정 후 번역:** 손번역 준비 → 원문 수정 → 번역만 순서로 실행합니다.
- **자동 서식:** 글자 크기 맞춤과 폰트 자동 맞춤은 별도 옵션입니다. 폰트 자동 맞춤은 원문 분위기에 맞는 한글 폰트를 적용합니다.
- **일괄 규칙:** 원문·번역문·최종 서식 단계에 저장한 일괄 편집 규칙을 넣습니다.
- **프리셋 관리:** 별표로 즐겨찾기, **변경 저장**으로 갱신, **새로 저장**으로 복사, 휴지통으로 삭제합니다.
- **이어하기:** 중단된 작업은 상단의 이어하기에서 선택합니다. 실패 페이지와 완료 단계를 확인한 뒤 남은 작업을 실행합니다.

## 원문 제거와 수동 보정

**자동 지우기 → 남은 자국 보정 → 원본 비교** 순서로 처리합니다. 자동 지우기는 블록의 원문 영역을 기준으로 배경을 복원합니다. 남길 글자는 블록의 더 보기에서 **자동 지우기에서 제외**합니다.

![브러시 보정과 크기·색 설정](docs/images/readme-current/retouch.png)

| 도구                             | 동작                                                                       |
| -------------------------------- | -------------------------------------------------------------------------- |
| **자동 지우기** `I`              | 대상 페이지를 골라 설정한 인페인팅 모델로 제거. 후속 말풍선 맞춤 선택 가능 |
| **마스크** `J`                   | 제거할 영역을 직접 칠한 뒤 적용해 배경 복원                                |
| **브러시** `B`                   | 선택한 색으로 작은 자국·평평한 배경 보정                                   |
| **사각형** `R` / **원형** `E`    | 드래그한 도형을 선택 색으로 채우기                                         |
| **지우개** `X` / **사각 지우개** | 보정한 부분을 원본 픽셀로 복원                                             |

브러시·사각형·원형에서 `Alt+좌클릭`으로 색을 추출합니다. `Alt+우클릭 드래그`는 반경 조절, `Shift` 드래그는 직선 그리기입니다. 마스크는 도구 상태에 따라 `Space`로 적용합니다. 잘못 칠하면 실행 취소하고, 원본으로 되돌릴 부분은 복원 지우개를 사용합니다.

## 효과음 번역

원고 왼쪽 아래 **SFX → 효과음 번역 실행**에서 HayaiOCR의 후보를 검토합니다. 놓친 효과음은 영역을 직접 추가하고, 그림을 잘못 잡은 후보는 제외합니다.

![페이지별 효과음 후보와 번역·제거 옵션](docs/images/readme-current/sfx.png)

1. 페이지별 후보의 **영역·원문·포함 여부**를 확인합니다.
2. **텍스트** 또는 **효과음 이미지**를 선택합니다. 이미지 방식은 별도로 설정한 Codex 이미지 모델을 사용합니다.
3. 번역 문구를 검토·수정한 뒤 이미지를 생성합니다.
4. 텍스트는 일반 블록으로, 생성 이미지는 위치·크기·이미지 편집 도구로 다듬습니다.
5. 원본과 비교하고 완성 이미지 또는 PSD로 출력합니다.

개별 효과음 번역은 원문을 유지합니다. 원문 제거까지 하려면 전체 효과음 번역의 **원문 지우기** 옵션을 선택합니다. **초기화**는 제외한 후보를 다시 표시하며 영역 수정과 번역 결과는 유지합니다.

이미지 작업 재개 시 가리기 영역과 겹치는 페이지는 **번역문을 저장하고 이미지 작업을 보류**합니다. 다른 페이지는 계속 처리합니다. 가리기를 조정한 뒤 미완료 이미지 작업을 이어서 실행하세요.

## 전송 이미지 가리기

**설정 → 이미지 · 원문 제거 → 전송 이미지 가리기**를 켜고, 페이지·화·작품 범위의 **가리기 준비** 명령으로 편집 화면을 엽니다. 지원되는 AI 이미지 전송 흐름의 **전송 사본**에 가리기를 적용하며 원본 파일은 유지합니다.

![가리기 영역 편집과 페이지별 검토 상태](docs/images/readme-current/redaction.png)

- **영역 편집:** 사각형·브러시로 가릴 부분을 지정하고 지우개로 조정합니다. 선택·이동·확대·실행 취소를 지원합니다.
- **여러 페이지:** 전체·미확인 등으로 필터링하고 페이지별 또는 선택한 페이지를 확인 처리합니다. 반복 영역은 복사·프리셋으로 재사용합니다.
- **저장·재개:** 초안과 검토 상태를 저장한 뒤 닫습니다. 중단된 번역·이미지 작업은 별도로 재개합니다.
- **확인할 범위:** 번역할 글자·효과음과 겹치지 않게 조정합니다. 가리기는 OCR 텍스트·작품 문맥까지 제거하지 않습니다.

외부 번역·조사·이미지 엔진과 MCP는 요청에 필요한 이미지·텍스트·문맥을 해당 서비스로 보낼 수 있습니다. [개인정보 안내](docs/privacy-policy.md)

## 결과물 자동 저장

**설정 → 결과물 자동 저장**에서 작품·화별 저장 여부와 연결 폴더를 관리합니다. 가져오기 단계에서는 자동 저장 여부와 출력 형식도 지정할 수 있습니다. 편집 결과를 연결 폴더에 계속 반영하며 앱 내부 편집 데이터 저장과는 별개입니다.

3. 최신·대기·실패 상태를 확인합니다. 실패하면 폴더 접근 권한·저장 공간과 오류 내용을 먼저 확인합니다.

| ----------- | -------------------------------- |
| `result`    | 번역문·보정을 합성한 완성 이미지 |
| `originals` | 복구용 원본                      |
| `inpainted` | 원문 제거본                      |
| `mask`      | 제거한 영역                      |

연결을 끄거나 폴더를 옮기기 전에 저장 위치와 미완료 항목을 확인하세요. 이 폴더들은 사용자 원본·결과물이므로 캐시처럼 삭제하지 않습니다.

## AI 앱 연결 · MCP

MCP(Model Context Protocol)는 AI 앱이 당근의 기능을 도구로 호출하는 연결 방식입니다. **Codex·ChatGPT·Claude·Claude Code**에서 보관함을 읽고 번역·식자·검수·출력을 요청합니다. 변경 결과는 당근 보관함에 저장되어 앱에서 이어서 편집할 수 있습니다.

![MCP 연결 주소·승인된 앱·기능별 권한](docs/images/readme-current/mcp.png)

| 작업            | 지원 범위                                                                                    |
| --------------- | -------------------------------------------------------------------------------------------- |
| **조회·검수**   | 작품·화·페이지·블록·문맥 검색, 원본·부분 이미지·앱 렌더링 확인                               |
| **번역·편집**   | AI가 작성한 번역문 저장, 앱 OCR·번역 실행, 블록 생성·수정, 여러 페이지 텍스트·서식 일괄 변경 |
| **식자·보정**   | 폰트 목록·견본, 크기·배치·효과, 원문 제거·마스크·이미지 수정·효과음 처리                     |
| **문맥·보관함** | 용어·인물·기억·조사, 파일·웹 원고 가져오기, 작품·화·페이지 구조 관리                         |

### MCP 연결 순서

1. 당근 실행 PC에 **Tailscale을 설치하고 로그인·기기 연결**을 완료합니다.
2. **설정 → AI 앱 연결 (MCP) → MCP 켜기**를 누릅니다. HTTPS·Funnel 안내가 나오면 브라우저에서 허용한 뒤 다시 켭니다.
3. **연결 가능 → 연결 방법 및 도움말 → 연결 진단**을 확인하고 **주소 복사**로 `/mcp`까지 복사합니다.
4. 사용할 AI 앱에 등록하고, 브라우저와 당근의 **숫자 코드·요청 권한을 확인해 승인**합니다.
5. 새 대화에서 당근을 선택해 작업을 요청합니다. 사용하는 동안 당근과 Tailscale을 켜 둡니다.

**[클라이언트별 등록 화면·명령·권한·문제 해결 → MCP 상세 가이드](docs/mcp-user-guide.md)**

### MCP 작업 요청과 권한

> 「작품명」 2화 1~3페이지를 한국어로 번역해줘. 1화의 용어·말투를 유지하고, 식자 결과를 확인한 뒤 PNG ZIP 파일을 줘.

요청에 **작품·화·페이지 범위, 수정할 내용, 유지할 내용, 출력 형식**을 지정합니다. AI가 직접 번역문을 저장하는 방식과 당근에 설정한 번역 모델을 실행하는 방식은 다릅니다. 원하는 쪽을 명시하면 됩니다. 출력은 작업 완료 후 다운로드 파일까지 요청하세요.

기본 조회 범위는 **보관함 전체**입니다. 이미지 전송·텍스트 편집·보관함 관리 및 모델 실행은 별도 권한으로 제어합니다. Funnel 주소는 인터넷에 공개되며 도구 호출에는 OAuth 인증과 앱 승인이 필요합니다. **권한 변경**은 진행 작업 취소·재승인, **MCP 끄기**는 접속 중단, **연결 해제**는 해당 AI 앱의 승인 철회입니다.

## 문제 해결

| 증상                        | 확인할 항목                                                                                                   |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 번역이 시작되지 않음        | 페이지 선택 → 언어·엔진 → 로그인·키·모델 준비 → OCR/모델 확인                                                 |
| 첫 실행이 오래 걸림         | 모델 다운로드·검증 진행 상태. 준비 후 대표 페이지로 확인                                                      |
| 메모리 부족·GPU 오류        | 작은 Gemma 프리셋·문맥 한도, GPU 권장값, OCR CPU·가벼운 원문 제거 모델                                        |
| OCR 영역·내용이 잘못됨      | 원문 언어·HayaiOCR/PaddleOCR 비교, 영역·원문 수정 후 필요한 단계만 재실행                                     |
| 이름·말투가 흔들림          | 용어집·캐릭터·누적 컨텍스트. 이미 번역한 내용은 화자 조건 일괄 편집                                           |
| 글자가 넘치거나 너무 작음   | 영역·방향·줄바꿈·크기·장평, 부분 서식·말풍선 맞춤                                                             |
| 원문 제거가 그림을 손상시킴 | 실행 취소·원본 복원, 제외 블록·마스크 범위, 다른 제거 모델                                                    |
| 이미지 효과음이 보류됨      | 가리기와 대상 영역의 겹침 수정 후 이미지 작업 재개                                                            |
| 저장·일괄 적용 충돌         | 최신 페이지를 다시 읽고 변경 전후 확인 후 적용                                                                |
| Codex 연결 실패             | 앱 안의 로그인·모델 목록, 로그의 내장 서버 오류                                                               |
| API 401/403/404             | 키·Base URL·모델·이미지 지원, 미지원 고급값 제거                                                              |
| 출력 폰트가 다름            | 폰트 등록·누락, 부분 서식, PSD 래스터 처리 대상 확인                                                          |
| 자동 저장이 밀리거나 실패함 | 연결 폴더 접근·남은 공간·대기/실패 상태 확인 후 재시도                                                        |
| MCP 연결·도구 호출 실패     | 당근·Tailscale 실행 → 진단 → 코드 승인·권한 → 도구 목록 갱신. [상세 해결](docs/mcp-user-guide.md#5-문제-해결) |

계속 재현되면 설정 하단의 **오류 보고**에서 보고서를 검토하고 [이슈](https://github.com/ucx0204/CarrotMangaTranslator/issues)에 앱 버전·OS·엔진·재현 순서·예상/실제 결과를 적어 주세요. 보고서는 자동 업로드되지 않습니다. 로그·보고서의 API 키·개인 경로·원고 내용은 공유 전에 확인하세요. [개인정보 안내](docs/privacy-policy.md) · [보안 정책](SECURITY.md)
