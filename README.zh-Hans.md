# Carrot Manga Translator

把 **OCR → 翻译 → 原文擦除 → 嵌字与校对 → 导出**放在一起的桌面应用。导入自己准备的漫画原稿，使用本地 Gemma、Codex 或 OpenAI 兼容 API 翻译。

## 先完成一页

1. **[安装](#install)**后，在**设置 → AI → 翻译**中选择原文语言、目标语言和引擎。
2. 检查 **[OCR 与图像设置](#setup)**，运行**检查/更新 → OCR/模型检查**。
3. 通过**[添加原稿](#import)**导入图片或文件夹。
4. 打开章节，在**[翻译设置](#translate)**中选一页，先用**仅翻译**检查结果。
5. **[修正 OCR 和译文](#edit)**，再用**[擦除原文](#erase)**和**适配气泡**整理。
6. **[导出结果](#export)**保存成品。设置合适后再处理剩余页面。

## 安装

| 平台              | 下载与操作                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| Windows 10/11     | 运行发行版的 **Setup EXE**，选择数据文件夹。                                                    |
| Apple Silicon Mac | 下载 **arm64 DMG 或 ZIP**，把应用移到**应用程序**。需要 macOS 14 或更高版本，不支持 Intel Mac。 |

系统弹出警告时，请核对该发行版的签名信息与校验和。Mac 首次启动许可可在**系统设置 → 隐私与安全性**中确认。[签名政策](CODE_SIGNING_POLICY.md)

模型与运行时单独下载，需要额外磁盘空间。首次准备需要联网。文件准备完成后，本地 Gemma、OCR 和图像修复可以在本地运行；Codex、远程 API 与网络调查需要联网。

## 语言与 AI 设置

**界面语言**在**设置 → 常规**中选择，**原文和目标语言**在**设置 → AI → 翻译**中单独选择。

![翻译引擎、语言与 Codex 账户](docs/images/readme-v2712/settings-translation.png)

| 引擎           | 准备内容                          | 选择后检查                                                   |
| -------------- | --------------------------------- | ------------------------------------------------------------ |
| **本地 Gemma** | 模型存储空间、RAM/VRAM            | 模型预设与运行时。先试适合设备的小预设。                     |
| **Codex**      | 在应用内登录 ChatGPT              | 账户可用模型与推理强度。使用内置服务器，无需另装 Codex CLI。 |
| **API**        | Base URL、模型 ID，必要时提供密钥 | OpenAI 兼容性及图像输入支持。也可以使用兼容的本地服务器。    |

**AI 下的各个标签配置不同任务。** 切换翻译引擎不会同时更换所有 OCR、擦除、Codex 图像处理和调查设置。

| AI 子标签    | 配置内容                                                                                |
| ------------ | --------------------------------------------------------------------------------------- |
| **翻译**     | 语言、Gemma/Codex/API、生成上限                                                         |
| **OCR**      | HayaiOCR/PaddleOCR、支持的设备。识别区域或文字不理想时，用同一页比较。                  |
| **图像**     | **AOT / LaMa / Flux** 原文擦除及后端、独立的 **Codex 图像模型与推理强度**、发送图像遮挡 |
| **网络调查** | 账户/密钥、搜索结果分析模型、使用限额                                                   |
| **硬件**     | 应用图形 GPU、本地 AI 计算 GPU、检测设备的推荐值。更换图形 GPU 后需保存并重启。         |

<details>
<summary>高级设置与更多截图</summary>

- **Gemma：**选择 Hugging Face 模型或本地文件。预设中的内存标注是参考，长页面、上下文及其他程序也会占用内存。运行时须匹配设备；内存不足时先降低预设和上下文上限。
- **API：**Temperature、top_p、top_k、reasoning_effort、额外 JSON、自定义请求头只填写服务器支持的项目。请求间隔、重试和密钥设置应符合服务限额。不要分享显示密钥的截图。
- **生成上限：**最大输出 token 限制回复长度，作品信息预算限制参考上下文的数量。数值越大不代表翻译一定越好。
- **准备检查：**保存设置后运行**检查/更新 → OCR/模型检查**。检查更新会打开发行页面。

## 导入原稿与书库

层级为**作品 → 章节 → 页面 → 文本块**。作品保存共用术语和角色；章节包含页面；页面包含原稿、翻译文本块与修补结果。文本块是一段对白、旁白或音效。

使用**添加原稿**选择来源，在预览中检查顺序和排除项，再新建作品或添加到已有作品。一次导入多回时使用**添加多个章节**，也可以把文件或文件夹拖入应用。

![导入来源选择](docs/images/readme-v2712/import.png)

| 来源                      | 导入方式                                      |
| ------------------------- | --------------------------------------------- |
| PNG、JPEG、WebP           | 选择图片或图片文件夹                          |
| ZIP、CBZ、RAR、CBR        | 选择压缩包并检查内部图片                      |
| PDF                       | 将页面作为图片导入                            |
| 含多个章节的文件夹/压缩包 | 使用多章导入，检查章节划分与顺序              |
| 网页                      | 加载图片列表，按尺寸筛选后选择所需图片        |
| `.mgtshare`               | 用**导入工程**恢复编辑工作。[分享说明](#data) |

书库搜索用于查找作品与章节，页面列表显示顺序和处理状态。检查损坏或不支持文件的排除结果。网站登录或访问限制导致无法读取时，请使用自己准备的本地文件。

## 翻译、继续与重译

打开章节后点击**翻译设置**或按 `T`。选择作品中的章节和页面，可用**仅未翻译**筛选剩余任务。

![翻译范围、嵌字与原文擦除选项](docs/images/readme-v2712/translate.png)

| 选项                  | 作用                                                                     |
| --------------------- | ------------------------------------------------------------------------ |
| **快速单次**          | 每页翻译一次，参考简短的近期上下文。                                     |
| **累积上下文**        | 积累场景、术语和角色供后续页面参考。可选详细记录、平衡记录或仅关键术语。 |
| **自动生成文本块**    | 重新检测文字区域。                                                       |
| **保留已有文本块**    | 保留区域与格式，更新文字；没有文本块的页面会自动创建。                   |
| **自然换行**          | 根据区域大小在译文中插入换行。想保留手动换行时先检查再开启。             |
| **AI 字号匹配**       | 估计原文文字大小。                                                       |
| **自动字体匹配**      | 为每块选择风格合适的**韩文字体**，与字号匹配独立。                       |
| **仅翻译 / 擦除原文** | 只完成翻译，或继续擦除原文。                                             |
| **适配气泡**          | 擦除后将译文安排在气泡内部。                                             |
| **Codex 擦除**        | 在可用条件下用 Codex 图像处理去除原文。也请检查[图像设置](#setup)。      |

常用组合可保存为下次默认值。`Shift+T`继续剩余页面。查看任务状态中的进度与错误，优先选择未完成部分，避免无必要地重做完成页。

**重译可能替换手动修改和已有结果，而且不进入工作区撤销历史。** 请先用[导出工程](#data)保留需要的版本。处理中的页面会限制修改，但未锁定的其他页面仍可编辑。影响整章的操作会根据该章的任务状态限制。

## 熟悉工作区

左侧是**书库与页面**，中间是**原稿**，右侧是**页面文本块与所选块编辑器**。折叠面板可增加原稿空间。选择画面文字或列表项目即可编辑。

| 操作               | 方法                                                      |
| ------------------ | --------------------------------------------------------- |
| 翻页               | 缩略图、`PageUp` / `PageDown`                             |
| 平移               | 用手形工具 `H` 或 `3` 拖动                                |
| 缩放               | `Ctrl+滚轮`或缩放控件；可适合页面/宽度/高度或显示实际尺寸 |
| 原稿对照           | `O`切换原稿预览                                           |
| 显示译文           | `V`切换文本块，`Shift+B`切换编辑背景与边框                |
| 新建文本块         | `W`或`2`后拖出区域                                        |
| 选择、移动、缩放块 | `S`或`1`，拖动块和控制点                                  |
| 多选               | 多选操作或`Ctrl+A`选中当前页所有块                        |
| 阅读顺序           | 列表上下按钮、`Ctrl+Alt+↑/↓`、按坐标排序                  |

选中颜色与编辑边框不等同于最终输出。放大检查细节后，也要在整页视图中确认换行与平衡。

## 修改台词与嵌字

### 文本：先检查 OCR

选择文本块，在**文本**标签中对照原文与译文。名字、数字或符号误识别时先修正原文，再重译所需范围。角色类型、说话人、校对状态和备注也用于后续批量操作。

![所选文本块的编辑](docs/images/readme-v2712/editor-text.png)

选中部分译文，可以只为这些字设置粗体、斜体、字体、字号、颜色、透明度、背景、描边和辉光。无选区时注意设置是否作用于之后输入的文字。**代码**视图可直接检查和修改格式表达。**清除全部格式**会去除句子中的局部格式。

### 布局：让文字适合气泡

| 调整                 | 用途                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| 位置、大小、旋转     | 移动和调整区域；`Ctrl+Shift+T`重置旋转。                                   |
| 横/竖排、对齐、换行  | 配合原稿与气泡形状，区分手动换行和自动折行。                               |
| 气泡适配             | 以内侧区域排版；用多边形或扩展/缩减笔刷编辑形状，取消适配则恢复 OCR 区域。 |
| 曲线、透视、网格变形 | 使用画面控制点调整弯曲或倾斜的台词和音效，并查看预览。                     |

### 格式：字形与间距

**格式**标签可调整字体、字号、粗体、斜体、对齐、文字颜色、描边、辉光、行距、字距、字宽与透明度。少数字符外观不同时，也要检查局部格式。

**批量应用**可把选定格式组复制到选区、页面或章节。只想复制颜色时，避免把字号也选中。[布局截图](docs/images/readme-v2712/editor-layout.png) · [格式截图](docs/images/readme-v2712/editor-format.png)

## 重用字体、格式与文本块

| 功能         | 保存内容           | 使用方法                                                               |
| ------------ | ------------------ | ---------------------------------------------------------------------- |
| **默认格式** | 新文本块的初始值   | 设置 → 默认格式；已有块需要另行应用。                                  |
| **格式预设** | 选定的格式组       | 从当前格式创建，命名并选择组，可固定到快捷格式、分配`Alt+1`～`Alt+0`。 |
| **文本块库** | 可复用文字与格式   | 块菜单 → 保存到库；按名称/原文/译文搜索后插入当前页。                  |
| **字体管理** | 注册字体和显示顺序 | 注册 TTF/OTF、收藏、隐藏、排序和指定默认字体。                         |

预设可以改名、分组或用当前格式覆盖；库中的文本块也可编辑内容。换电脑后若缺少字体，请注册相同字体或选择替代。翻译时的自动字体匹配与保存预设是不同功能。

[默认格式截图](docs/images/readme-v2712/settings-format.png)

Codex ImageGen 音效也可存入**文本块库**，一起保留图片、蒙版和字重，在其他页面复用。选中的文本/图片块可用 `Ctrl+C` / `Ctrl+V` 在页面、章节和作品之间复制。

## 擦除原文与手动修补

按**自动擦除 → 清理残留 → 对照原稿**的顺序处理。自动擦除使用文本块的原文区域来修复背景。要保留的文字，在块菜单中设为**从自动擦除中排除**。

![修补工具与原稿](docs/images/readme-v2712/retouch.png)

| 工具                             | 作用                                         |
| -------------------------------- | -------------------------------------------- |
| **自动擦除** / `I`               | 选页并运行设定的修复模型，可接着适配气泡     |
| **蒙版** / `J`                   | 手动画出待擦除区域，应用后重建背景           |
| **画笔** / `B`                   | 用选定颜色涂画，适合平坦背景的小残痕         |
| **矩形** / `R`、**椭圆** / `E`   | 用所选颜色覆盖拖出的形状                     |
| **橡皮擦** / `X`、**矩形橡皮擦** | 恢复**原始图像像素**，不是擦除修复蒙版的工具 |
| **取色器** / `P`                 | 从原稿取绘画颜色                             |

画笔、矩形和椭圆中，**`Alt+左键`可取色**。绘画工具的`Alt+右键拖动`调整半径；`Shift`拖动画笔可约束直线。在允许的工具状态下，`Space`应用蒙版。

矩形、椭圆和矩形恢复工具使用黑白双轮廓的固定十字光标，浅色和深色原稿上都容易定位。画错了用撤销，要恢复原始像素则用橡皮擦。[自动擦除截图](docs/images/readme-v2712/erase.png)

## 音效：先确认，再处理

大型音效只换字体，容易失去原有的笔触和冲击力。**Codex ImageGen** 可以翻译文字图片，同时让对白继续保持为可编辑文本。

| 日语原稿                                                                              | 韩语对白＋音效图片                                                                             |
| ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| <img src="docs/images/readme-v2712/comparison-before.png" alt="日语原稿" width="430"> | <img src="docs/images/readme-v2712/comparison-after.png" alt="韩语对白＋音效图片" width="430"> |

示例把大型 `ドン` 改成了笔刷风格的 `쾅`。对白先擦除原文，再对齐文本块。此对比使用 Codex 内置 imagegen 准备的素材和应用的实际文字渲染器。[制作过程](docs/images/readme-v2712/README.md)

HayaiOCR 的音效候选可与台词分开审核。打开**音效翻译**，逐页包含或排除候选。把画面误识别成文字时排除，漏检时手动添加或修正区域。

![音效候选与翻译方式](docs/images/readme-v2712/sfx.png)

1. 检查识别原文与区域。
2. 选择可编辑的**文本**或**Codex 图像**；图像方式使用独立的 Codex 图像设置。
3. 图像方式先审核译文，**全部页面确认后生成**。在文字变成图片前定稿。
4. 对照原稿。文本按普通块编辑；生成字使用提供的图像编辑与恢复工具调整。

单区域翻译保留原文。擦除选项在整批音效翻译中选择。**重置**会恢复删除/排除的候选显示，同时保留区域修正与译文。

继续图像任务时，音效与遮挡区域重叠的页面会**保存译文并暂缓图像步骤**，其他页面继续。调整遮挡后再继续，只处理未完成图像。[遮挡说明](#redaction)

## 发送图像遮挡

在**设置 → AI → 图像 → 发送图像遮挡**中启用。它作用于支持的 AI 图像流程中的**发送副本**，不是在原稿文件上涂色。

使用页面、章节或作品范围的**准备遮挡**命令检查并调整区域。自动判断需要人工确认。翻译或生成目标文字不能被遮住，否则无法处理；先修正重叠。它与擦除原文的用途不同。

开启图像遮挡并不意味着请求里的 OCR 文字和作品上下文也全部被移除。请结合所用引擎与[隐私政策](docs/privacy-policy.md)确认发送内容。

## 用术语与记忆统一名称和语气

从右侧工具打开**术语/记忆**，维护同一作品跨章节的共用信息。

![术语表与作品上下文](docs/images/readme-v2712/context-glossary.png)

| 标签         | 记录内容                               | 示例原稿                           |
| ------------ | -------------------------------------- | ---------------------------------- |
| **术语表**   | 原文、译法、别名、类别、备注、启用状态 | `侍従長 → 시종장`（侍从长）        |
| **角色**     | 名字、别名、说话方式、人物备注         | 瑟拉菲娜：用平静敬语下达残酷命令   |
| **翻译规则** | 敬称、音效处理、基本语气               | 保留敬称、翻译音效                 |
| **剧情记忆** | 各页场景摘要与视觉信息                 | 她因红茶变凉下令处刑，宫廷陷入寂静 |

手动输入或检查 **AI 术语/记忆**分析结果，也能整理翻译积累的内容。合并重复名称和别名后保存。[角色](docs/images/readme-v2712/context-characters.png) · [规则](docs/images/readme-v2712/context-rules.png) · [剧情](docs/images/readme-v2712/context-memory.png)

<details>
<summary>网络调查、提案审核与上下文预算</summary>

**网络调查**在确认作品标题、引擎和范围后补充外部信息。搜索标题独立于书库名称。Codex 调查与 Tavily 搜索后由 LLM 分析，需要的账户、密钥和限额不同；先检查**设置 → AI → 网络调查**。

将建议的术语、角色、规则与来源和现有内容比较，只应用需要的项目。搜索结果可能错误或属于另一作品。没有外部资料的原创示例可直接手动填写。

信息增多后留意预算，优先保留翻译所需内容。保存冲突时先检查其他改动，再打开最新版本应用修改。**清空全部术语/记忆**会删除作品术语表、角色及所有章节的剧情记忆，不要作为常规整理工具。

</details>

<a id="batch"></a>

## 批量修改文字与格式

`Ctrl+H`打开**批量文本编辑**，按**范围 → 条件 → 操作 → 前后对照 → 应用**进行。先在当前页验证规则，再扩大到整章。

![条件、操作与原稿上的修改预览](docs/images/readme-v2712/batch.png)

可按原文、译文、角色类型、说话人、校对状态等筛选。区分**全部满足**与**任一满足**；**所有气泡**会包含所选范围内的全部块。把文字替换、格式/字段修改、局部强调按执行顺序排列。

### 示例：只统一瑟拉菲娜的语气

1. 条件设为**说话人 = 瑟拉菲娜**且**译文包含`처형했습니다`**。
2. 将`처형했습니다`替换为更正式的`처형하였습니다`。
3. 只把新生成的`처형하였습니다`加粗。
4. 确认侍从的台词未变，再应用。

说话人条件需要文本块已正确关联人物。各作品的 ID 不同，不要直接照搬示例 ID。

<details>
<summary>其他用法与保存规则</summary>

- **省略号与空格：**用初始示例规则把`...`变成`…`，合并连续空格。
- **音效格式：**只筛选音效角色，调整粗细、字号和描边。
- **校对标记：**查找空译文或指定表达，更新校对状态与备注。
- **正则表达式：**普通字符匹配不够时使用；检查大小写和全部替换设置。
- **排除结果：**即使符合条件，也可排除不该修改的项。检查真实页面上的前后效果与应用数量。
- **复用：**命名后保存为 YAML。序列能按顺序执行多个规则，前一步结果作为下一步输入。
- **冲突：**预览后已变化的块会跳过，避免覆盖。用最新数据重新预览；刚执行的批量编辑可以撤销。

</details>

<a id="review"></a>

## 集中阅读与校对

`G`打开**文本汇总**，可同时显示 OCR 与译文，也可只显示一方并搜索。点击页面标题返回原稿，也能选择文本块，只批量应用改动的格式项。

![OCR 与译文汇总](docs/images/readme-v2712/gather.png)

| 交换格式         | 对应方式               | 注意                                           |
| ---------------- | ---------------------- | ---------------------------------------------- |
| 复制 / TXT 导出  | 当前显示文本           | 可选择是否包含页面标题                         |
| TXT 导入         | **仅译文**导出的行顺序 | 改变顺序可能错配；确认警告和数量               |
| CSV / TSV 校对表 | `block_id`             | 更新译文、校对状态、备注，不改 OCR；保留 ID 列 |

外部电子表格校对建议使用校对表以保持对应关系。保留导出原件，导入前检查未知 ID、重复和缺失等警告。

## 导出成品与 PSD

在**导出结果**或`Ctrl+E`中选择章节与页面。预检发现未翻译、失败或后处理未完成时，返回相关页面确认。

![导出范围、格式与保存方式](docs/images/readme-v2712/export.png)

| 输出                           | 用途与设置                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| **原格式 / PNG / JPEG / WebP** | 合成成品图片；选择 JPEG/WebP 质量及是否保留原文件名、子文件夹                                              |
| **不含文字**                   | 不合成译文，只保存清理后的背景；需要擦除结果                                                               |
| **分层 PSD**                   | 分开原稿、清理背景和各块文字。支持的文字保留可编辑性，复杂竖排、曲线、透视或局部格式可能栅格化以保留外观。 |

选择新建时间戳文件夹或直接保存到指定文件夹，并确认同名文件的**替换 / 跳过 / 取消**策略。图像导出不同于[工程分享](#data)，PSD 也不是应用全部编辑状态的完整备份。[PSD 截图](docs/images/readme-v2712/export-psd.png)

<a id="autosave"></a>

## 自动保存结果

在**设置 → 结果自动保存**中管理作品、章节的连接状态与输出格式。需要编辑时持续更新外部结果文件夹，就使用此功能。确认目标位置与状态，在状态控件中重试失败或待处理项。

![按作品管理自动保存](docs/images/readme-v2712/settings-results.png)

`result`是成品图，`originals`是恢复用原稿，`inpainted`是擦除图，`mask`是擦除区域。它与保存应用编辑数据不同。关闭连接或更换格式前先确认路径，不要把这些文件夹当缓存删除。

<a id="data"></a>

## 工程分享、备份与隐私

**导出工程**可选择作品与章节并保存为`.mgtshare`。另一台电脑的**导入工程**可以新建作品，或向现有作品添加/替换章节。检查最终列表和顺序后应用。

| 工程文件包含                                         | 另行准备                                                                             |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 原稿图片、文本块、阅读顺序、格式、修复结果等工作数据 | 应用设置、ChatGPT 登录/API 密钥、AI/OCR 模型与运行时、日志；目标环境也须检查所需字体 |

需要保留完整环境时，关闭应用后**备份数据文件夹**。`library`保存原稿和编辑数据，不是可删除的缓存。区分设置、字体、日志、模型缓存，并保留原始文件和输出。macOS 默认路径为`~/Library/Application Support/manga-gemma-translator`。

外部引擎可能接收任务所需图片、文字和上下文。日志可能含路径或部分原稿，分享前请检查。错误报告不会自动上传。[隐私政策](docs/privacy-policy.md) · [安全政策](SECURITY.md)

<a id="troubleshooting"></a>

## 遇到问题时

| 症状                | 先检查                                                      |
| ------------------- | ----------------------------------------------------------- |
| 翻译不启动          | 选页 → 语言/引擎 → 登录/密钥/模型 → OCR/模型检查            |
| 首次运行慢          | 下载与校验进度；准备完成后用代表页比较                      |
| 内存不足或 GPU 错误 | 分别尝试小 Gemma 预设、推荐设备设置、CPU OCR、轻量擦除模型  |
| OCR 错误合并/拆分   | 原文语言、对比 HayaiOCR/PaddleOCR；修正区域后保留已有块重译 |
| 名称或口吻不一致    | 术语表、角色、累积上下文；已有译文按说话人批量修改          |
| 文字溢出或过小      | 区域、方向、换行、字号、字宽，以及局部格式和气泡适配        |
| 擦除损坏画面        | 撤销/恢复原稿，排除块或缩小蒙版，对比其他模型               |
| 音效图像被暂缓      | 修正与遮挡的重叠后继续图像任务                              |
| 保存或批量应用冲突  | 打开最新数据比较，避免覆盖其他修改后再应用                  |
| Codex 连接失败      | 应用内登录、模型列表，以及日志中的内置服务器错误            |
| API 401/403/404     | 密钥、URL、模型、图像支持；移除不支持的高级参数             |
| 导出字体不同        | 字体注册/缺失情况，是否属于 PSD 栅格化情形                  |

若可重复出现，通过**设置 → 错误报告**检查内容，再在 [Issue](https://github.com/ucx0204/CarrotMangaTranslator/issues) 中提供版本、OS、引擎、复现步骤、预期与实际结果。分享前检查密钥、私人路径和原稿内容。
