# 업데이트 안내

## 새 버전 설치는 안전합니다

새 버전 설치 파일(`당근망가번역기 Setup x.y.z.exe`)을 **기존 버전을 제거하지 않고**
같은 위치에 그대로 실행해도 됩니다. 다음 데이터는 별도의 데이터 루트
(설치 시 선택, `data-root.txt`에 기록)에 저장되므로 업데이트로 삭제되지 않습니다.
데이터 루트는 설치 폴더 안의 `data`일 수도 있고, 다른 드라이브의 전용 폴더일 수도 있습니다.

- 다운로드한 번역 모델(GGUF 등)
- Paddle OCR 런타임
- 보관함(작품·화·페이지·번역 결과)
- 작업 컨텍스트/용어집, 로그, 캐시

즉 **업데이트 후 모델을 다시 받을 필요가 없습니다.**

## Windows 설치 위치와 관리자 승인

설치 프로그램은 시작할 때 Windows 관리자 승인(UAC)을 요청합니다.
`Program Files` 같은 보호된 폴더에도 설치할 수 있으며, 설치 프로그램을
처음부터 관리자 권한으로 실행했다는 이유로 거부하지 않습니다.
사용자용·전체 사용자용 설치 선택은 유지됩니다. 현재 사용자용 설치는
설치 프로그램을 실행하는 Windows 계정에 등록되므로, 다른 관리자 계정의
자격 증명을 입력했다면 설치 대상 계정과 데이터 위치를 확인하세요.

**프로그램 설치 위치와 데이터 저장 위치의 권한은 별개입니다.**
프로그램이 `Program Files`에 있어도 데이터가 일반 권한으로 쓰기 가능한
별도 폴더에 있으면 앱은 관리자 승인 없이 시작합니다. 실제 데이터 위치에
권한이 부족한 경우에만 앱이 관리자 실행을 한 번 요청합니다.

관리자 실행 중인 앱에는 일반 Windows 탐색기에서 파일을 끌어놓을 수 없습니다.
이때는 앱의 파일 열기 기능을 사용하세요. 평소 드래그앤드롭을 사용하려면
설치할 때 일반 권한으로 쓰기 가능한 전용 데이터 폴더를 선택하세요.
설치 폴더 전체의 보안 권한을 풀거나 Windows UAC를 끌 필요는 없습니다.

UAC를 취소하면 실행을 중단하며 반복해서 승인 창을 띄우지 않습니다.
자동 재실행에서 다른 관리자 계정을 입력하면 기존 API 키와 설정을 보호하기
위해 데이터에 접근하기 전에 중단합니다. 같은 계정으로 승인할 수 없는 환경에서는
일반 권한으로 쓸 수 있는 데이터 위치를 사용하세요.
디스크 부족·잘못된 경로·관리자 권한으로도 해결되지 않는 오류는 별도로 안내합니다.

기존 데이터를 유지하려면 같은 위치에 덮어 설치하고 기존 데이터 루트를 그대로
선택하세요. 저장 위치를 바꾸는 것이 데이터 자동 이동을 뜻하지는 않습니다.
권한 오류를 해결하려고 `data`나 `data-root.txt`를 먼저 삭제하지 마세요.

## 제거할 때만 데이터가 지워질 수 있습니다

제거(언인스톨) 과정에서 선택형 “데이터도 함께 삭제” 항목을 **직접 선택하지
않으면** 데이터 루트는 그대로 남습니다. 기본 동작은 앱 파일만 제거합니다.
제거 프로그램도 필요한 관리자 승인을 요청하며, 승인을 취소하면 제거하지 않습니다.

## 업데이트 확인 방법

- 설정 → **설치 / 확인** 탭의 **업데이트** 영역에서 현재 버전을 확인하고
  **“업데이트 확인 (릴리스 페이지 열기)”** 버튼으로 최신 릴리스를 엽니다.
- 최신 `당근망가번역기 Setup x.y.z.exe` 를 내려받아 그대로 실행하면 됩니다.

## 릴리스 산출물

각 릴리스에는 설치 파일과 함께 업데이트 메타데이터가 포함됩니다.

- `당근망가번역기 Setup x.y.z.exe`
- `당근망가번역기 Setup x.y.z.exe.blockmap`
- `latest.yml`

`electron-builder` 의 `publish: github` 설정으로 빌드 시 `latest.yml` 과 블록맵이
함께 생성됩니다.
