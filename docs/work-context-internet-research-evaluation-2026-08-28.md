## Gemma 추론 단계 조정

모든 비교는 QAT 12B 속도 프리셋, 컨텍스트 65,536, 최대 출력 32,768, 빈 가이드, Tavily 검색 4회로 실행했다.

`높음`이 공식 표기와 출력 구조를 가장 안정적으로 유지했다. 이후 검색어 우선순위, 근거 체크리스트, 2차 로컬 감사, 공식 독음·OCR 표기 정규화를 보강한 최종 실행에서 5/5가 됐다. 따라서 인터넷 조사 기본값은 `속도 12B(QAT) + 높음`으로 정했다.

같은 조사 프롬프트와 높은 추론 단계로 26B와 31B도 핵심 검증 5/5를 통과했다. 31B는 컨텍스트 32,768, 최대 출력 32,768, 여유 VRAM 1,536 MiB를 그대로 전달해 실행했으며 자동 컨텍스트 축소나 fit-target 재시작은 없었다. 최종 결과의 정규화 중복, 수동 항목 변경, 외부 사실의 출처 누락은 모두 0건이었다.

## Tavily 사용량 확인

Tavily `/usage`는 검색 직후 잠시 이전 값(0)을 반환했고 이후 실제 사용량으로 갱신됐다. 앱은 `/usage` 값을 기준으로 하되, 아직 반영되지 않은 검색 응답의 `usage.credits`를 로컬 대기분으로 합산해 강제 새로고침 때 사용량이 뒤로 돌아가지 않게 한다. 최종 빈 가이드 실행 전후 표시값은 4/1,000에서 8/1,000으로 바뀌었고 검색 응답의 실제 소비도 4크레딧이었다.

Tavily 경로의 설정 마이그레이션, 키 마스킹, Usage/Search 응답 파싱, 쿼터·429 재시도·취소, 프롬프트 인젝션 처리, JSON 복구 실패와 실행당 크레딧 제한은 자동 테스트로 검증한다.
