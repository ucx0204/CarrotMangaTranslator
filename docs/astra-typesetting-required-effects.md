# 반드시 해결해야 하는 효과음 회귀 사례

사용자는 2026-09-06에 큰 효과음을 귀찮거나 어렵다는 이유로 넘어가지 말고
최종적으로 오류 없이 처리해야 한다고 명확히 요구했다. 원문 보존은 일시적인
실패 처리일 뿐이며, 완성·승격·성공률의 성공 분자에 포함하지 않는다.

`user-regressions/required-stare-20260906.json`은 discovery-004의 6쪽
ギロ 효과음을 원본 전체 페이지와 스크린샷 SHA-256에 묶는다. 원문 제거,
인물/망점/패널선의 자연스러운 복원, 한국어 효과음, 실제 저장본과 레이어 검증을
모두 통과해야 한다. 검사를 약하게 바꾸거나 해당 영역을 제외해서 통과할 수 없다.
현재 큰 ギロ 한 곳은 **알려진 회귀 통과**다. 아래 2026-09-06 갱신 근거가
이전 실패 기록보다 최신이다. 전체 화나 다른 효과음까지 통과한 것은 아니다.

이것은 최초 20장 실험의 「転生悪女の黒歴史」 기존 6번과 다른 원고다.
기존 6번의 1/10 사용과 사용자 요청 시 마지막 재실행 정책은 유지한다.
새 방법은 다음 미사용 화에서 개발·검증하고, 이 알려진 사례는 필수 회귀로
명시해 재확인한다. 회귀 통과를 새로운 일반화 검증 화로 세지 않는다.

3쪽 옷 위 カチャ와 얼굴 위 パアァァァ도 원문 잔류 실패 사례로 보존한다.
큰 붓글씨, 망점 위 윤곽 문자, 인물과 겹친 글자, 페이지 가장자리에서 잘린
글자가 전체 품질 평가에 포함되어야 한다. 평범한 말풍선만으로 완료를 선언하지 않는다.

## 기존 실패의 경계 위치 추적

discovery-005 실행 중 기존 discovery-004/candidate-004의 마지막 ギロ 생성안을
읽기 전용으로 조사했다. `readonly-required-stare-boundary-localization-001`에
원본·생성안·제거 허용 범위의 네이티브 크롭과 SHA를 저장했다. 신규 모델 호출,
추가 만화 후보, 마스크 변경, 거부된 패치의 적용은 없다. 당시 봉인한
`codexTypesettingRegistration.js`와 `codexTypesettingMask.js`가 현재와 byte 단위로
같음을 확인하고, 원본과 생성물 해시·허용 픽셀 수를 검사했다.

기존 경계 1,859개 표본의 평균 오차 0.24508488123786595와 최악 묶음 오차
0.9840639114825366이 정확히 재현됐다. 높은 오차 위치 8개를 직접 보니 제거 범위
밖의 보존 픽셀에 ギロ의 검은 획 일부가 남아 있었다. 예를 들어 페이지 픽셀
(663,393)의 16×16 묶음은 보존 경계 표본 3개에서 원본 밝기 평균 약 0.00784,
생성안 약 0.99191이다. 주변 16개·26개·29개 표본 묶음에서도 같은 유형이 관찰됐다.
따라서 이 큰 경계 차이에는 원문 획을 덜 덮은 마스크가 기여한다. 막연히 모든
차이를 그림 정합 실패로 취급하거나 경계 검사를 완화할 근거가 아니다.

전체 주변 문맥 오차 0.12092933130190073 역시 당시 허용값을 넘으므로 마스크
문제만 고치면 성공한다고 결론 내리지 않는다. 원본·정렬한 기존 원시 생성안·허용
범위 비교를 사용자에게 직접 보여 주었고 실제 적용 결과가 아님을 명시했다.
알려진 이 사례의 원문 제거·복원·한국어 식자 상태는 여전히 실패다.

## 2026-09-06 갱신 · 큰 ギロ 회귀 통과

사용자가 승인한 완전 교체 core와 바깥 feather를 실제 production adapter에
연결했다. `required-stare-pipeline-v046-001`의 실제 Astra 배경 검수는 issues와
corrections가 모두 비었다. 실제 폰트 견본을 본 Astra는 찌릿을 image로 선택했다.
첫 harness는 잘못된 JSON 전용 client로 생성 요청을 보내 실패했다. 앱은 이미
별도 image-generation capability client를 쓰므로 harness만 바로잡았다.
`002`는 배경과 식자 계획의 해시를 검증해 그대로 재사용했고 실제 전경을 1회 생성했다.
독립 재판독은 찌릿, Astra 완성본 검수는 issues:[]였다.

이때 숨겨진 대체 텍스트의 overflow를 활성 이미지에 적용하는 결함을 재현했다.
실제 전경의 CSS 사각형을 덮는 raster 영역 밖 ink는 0이다. 기존 정수 crop helper는
소수점 원점을 버려 마지막 안티앨리어싱 행의 4픽셀을 놓치므로 그 값을 숨기거나
다른 용도의 좌표 알고리즘을 바꾸지 않았다. v0.4.7은 활성 이미지에만 숨겨진 텍스트의
overflow를 적용하지 않는다. 텍스트 편집으로 이미지가 비활성화되면 overflow 검사는
다시 동작한다. 변경 전 실패한 characterization과 변경 후 검증을 보존했다.

`required-stare-persistence-v047-001/result.json`은 실제 library 저장, 다시 열기,
전경 이동, 번쩍으로 편집, 원래 찌릿 복원과 native PNG 내보내기를 통과했다.
편집 내내 배경 SHA는 고정됐고 원문은 되살아나지 않았다. 원래 최종 결과와 저장 후
결과의 차이 0픽셀, 배경+투명 전경 재합성 차이 0픽셀이다. 이 재생의 새 모델 호출은
0회다. 26개 check gate와 실제 PageArtwork 넓은/좁은 UI 검증도 통과했다.
최종 결과와 편집 결과는 직접 열어 확인하고 사용자에게 공유했다.
