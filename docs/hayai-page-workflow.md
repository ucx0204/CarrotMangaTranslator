# Hayai 페이지 작업 (#121)

- Hayai는 `hayaiTranslationUi` 설정으로 기존 `LegacyTranslationOptionsModal`과 새 `PageWorkflowModal`을 선택한다. 기본값은 새 화면이며 Paddle은 기존 경로를 유지한다.
- 공개 IPC는 `preflightPageWorkflow`, `startPageWorkflow`, `getPageWorkflowRun`이다.
- `pageWorkflowService`가 단계 순서·페이지 소유권·취소·저장을 조율한다. 단계 어댑터는 기존 OCR, 번역, C23 폰트 분석, 제거, 배치 구현을 호출한다.
- 번역은 저장된 원문을 고정 영역 입력으로 전달한다. 검출과 OCR은 번역 엔드포인트를 시작하지 않는다.
- 원문/번역문/서식은 기본적으로 빈 항목만 채운다. 일괄 편집은 사용자가 지정한 변경 명령이며, 규칙 내용은 실행 시작 시 고정된다.
- 번역 성공 여부는 기존 고정 블록 파이프라인의 판정을 따른다. 일부 블록의 미출력·필터 제외만으로 페이지 실패나 강제 재시도를 추가하지 않는다. 정상 번역은 저장하고 응답이 없는 블록은 기존 값을 유지한다. 빈 번역은 선택한 자동 검수 단계에서 확인 대상으로 남긴다. 모델 요청·파싱 등 실제 실패는 실패 기록과 페이지 오류로 표시한다.
- 번역 실패 이후에도 독립적인 원문 제거는 실행한다. 공통 런타임 오류와 저장 충돌은 실행을 중단한다.

## 페이지 작업 UI

- 헤더의 기존/새 버전 선택을 UI 설정에 저장한다. 전환 직전 실제 너비에서 다음 너비로 280ms 보간하며, 연속 전환은 현재 너비에서 이어진다. 동작 줄이기 설정에서는 공간 이동을 생략한다.

- 모달은 화면 높이를 채우고 실행 순서는 420px을 사용한다. 나머지 폭은 대상 페이지에 배정하며 썸네일은 기존 번역 설정과 같은 컴포넌트·크기를 사용한다.
- 각 작업과 하위 옵션의 설명은 툴팁으로 제공한다. 드롭다운을 열면 툴팁을 닫아 선택 항목을 가리지 않는다.
- 프리셋 편집은 선택한 이름을 유지하고 수정 표시를 붙인다. `변경 저장`은 기존 ID와 이름을 유지하며, `새로 저장`은 별도 프리셋을 만든다.
- 프리셋은 즐겨찾기 우선으로 정렬한다. 사용자 프리셋은 삭제 확인 후 제거하고 즐겨찾기 참조도 함께 정리한다. 설정은 `pageWorkflowFavoritePresetIds`에 저장한다.
- 옵션 재검사 중에는 마지막 요약을 유지하고 시작 버튼을 잠근다. 결과를 확정할 때 요약을 교체해 체크마다 숫자와 목록이 깜빡이지 않게 한다.

## 저장과 재개

`dataRoot/page-workflows/<runId>.json`에 계획·선택 대상·고정 규칙을 저장한다. 페이지의 선택적 `pageWorkflow`에 단계별 입력/출력 지문과 완료 기록을 저장한다. 콘텐츠와 완료 기록, 번역의 누적 기억·용어집은 같은 보관함 트랜잭션에서 확정한다.

같은 실행의 재개는 저장된 계획과 규칙을 사용한다. 새 실행은 새 규칙 스냅샷을 만든다. 설정 지문에는 인증 정보를 저장하지 않는다. 번역문 수정은 원문 제거 완료 기록을 무효화하지 않는다.

새 준비 블록의 `textDisplayMode: translation-only`는 빈 번역문을 화면·PNG·PSD에 그리지 않는다. 기존 블록의 원문 대체 표시는 유지한다. `workflowOrigin`은 최초 서식과 OCR 기하를 보관하며, 수동 변경과 자동 적용을 구별한다.

## 검증 범위

- `pageWorkflowService`, `pageWorkflowAdapters`, `pageWorkflowPersistence`, `pageWorkflowRunStore`, `pageWorkflowRuleRenderer`, `pageWorkflowModal` 테스트.
- 실제 파일 트랜잭션의 중간 종료/복구, 규칙 중복 적용 방지, 저장 충돌, 렌더러 글자 크기 계측, 기존 고정 블록 OCR 기하와 래스터 크기 결과 비교.
- 기존 Paddle 모달, 캔버스, PSD, 내보내기 취소 회귀 테스트.
- 프로덕션 컴포넌트 UI 캡처: 1600×980, 1240×760, 200% 확대, 읽기 24px, 긴 원문, 규칙 오류.

네이티브 모델을 모두 구동하는 실제 만화 전체 처리의 픽셀 단위 비교는 별도 검증 대상이다. 기존 알고리즘과 모델 artifact를 재사용한다.
