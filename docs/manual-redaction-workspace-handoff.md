작업 브랜치: `feat/manual-redaction-workspace-20260910`

## 최신 기준

**제품 수정은 원격에 커밋되어 있다. 이전 ZIP을 다시 적용하거나 처음부터 만들지 않는다.** 최신 제품은 `e67713d`; 진행한 검사와 현재 실행은 `manual-redaction-latest-validation.md`가 기준이다. 과거의 “후속 파일 미반영” 설명은 더 이상 현재 상태가 아니다.

전체 보기/보류 기능 없이 연속 편집 하나를 사용한다. 선택 확인은 왼쪽에 노출하고 페이지 확인과 전체 작업 재개를 구분한다. 진행률/저장 상태는 텍스트다. 미리보기 미표시를 이유로 추가 확인 체크박스를 요구하지 않는다. 실제 오류는 별도로 표시하며, 마지막 Enter와 자동 저장이 전송을 승인하지 않는다.

모달은 창 안으로 제한되고 숫자 입력은 자신의 영역 안에 머문다. 페이지 이동 후 캔버스 포커스를 유지하며 페이지 번호 전체를 입력한 뒤 이동한다. Windows의 실제 프로덕션 UI 11개 상태를 검사하고 PNG를 직접 확인했다. 이후 오류 상태/IPC 의존성 구조 수정도 작은 커밋으로 보존했다.

## 중단 후 재개 순서

2. Windows Actions `34508336718`의 검사 소스와 최종 결과를 확인한다. 기록 시점에는 실행 중이다.
3. 실패가 남았다면 로그에 나온 원인만 고치고 작고 검증 가능한 단위로 커밋한다. 체크 비활성화/예산 완화/강제 push로 숨기지 않는다.
4. 통과 후 최종 검사 소스와 결과, 실제 화면 인수를 최신 검증 문서에 기록한다.

원래 3차의 작품/화/선택 페이지 사전 편집 앱 진입점과 앱 전체 이어하기 연결은 이번 오류 수정과 별도 미완료 범위다.

## 유지할 사용자 요구

수동 전용이며 자동 감지/추천을 추가하지 않는다. 전체 보기 탭과 보류 기능을 복원하지 않는다. 핵심 동작은 짧은 텍스트로 보이고 설명만 툴팁에 둔다. 기존 가림과 사용자 원본/보관함/출력물을 보존한다. 같은 브랜치에서 자주 커밋하며 기본 브랜치 병합, 버전 변경, 태그/릴리즈는 하지 않는다.
