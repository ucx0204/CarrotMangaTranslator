# 수동 전송 이미지 가리기 작업 인계

## 최신 상태 — 이 브랜치에서 계속

작업 브랜치: `feat/manual-redaction-workspace-20260910`

단일 화면 보존본의 제품/테스트 **32개 파일 전체를 통합했다**. `cf24c8f`에 반영된 25개 파일은 보존했고, 누락 7개 리팩터링과 종료 오류 표시/중복 실행 잠금을 그 위에 추가했다. 이전 문서의 "제품 코드 미반영" 또는 "7개 미반영"은 과거 상태다. 정확한 범위와 트리 식별자는 `manual-redaction-continuous-ui.md`, 최신 검사 결과는 `manual-redaction-latest-validation.md`를 읽는다.

전체 보기 탭 없이 썸네일과 연속 편집을 한 화면에 두고, 일괄 작업/프리셋은 메뉴 안에, 도구는 아이콘/툴팁으로 정리했다. 페이지별 이력, 명시적 확인/보류, 최종 전송 승인 분리는 유지한다.

## 사용자 범위

- 수동 전용. 자동 위치 감지, 자동 마스킹, 자동 추천은 추가하지 않는다.
- 전체 보기 탭을 다시 만들지 않는다. 가능한 작업을 연속 편집 하나에서 처리한다.
- 상시 설명은 최소화하고 필요한 안내는 툴팁으로 제공한다. 오류는 짧게 표시한다.
- 같은 브랜치에서 이어가며 작은 커밋과 실제 검사 결과를 보존한다.
- master 병합, 버전 변경, 태그/릴리즈 게시는 하지 않는다.
- 사용자 원본 이미지·보관함·기존 출력물은 수정하거나 삭제하지 않는다.

## 재개 규칙

최신 HEAD, AGENTS.md, 이 문서, 실제 diff와 검사한 소스 SHA를 먼저 확인한다. 이미 반영한 32개 파일을 처음부터 다시 만들거나 누적 패치를 무조건 재적용하지 않는다. 74개 파일/122개 테스트의 과거 기록은 현재 원격에 반영된 범위가 아니므로 완료로 간주하지 않는다. 다른 사람의 변경을 보존하고 강제 push하지 않는다. 차단된 요청을 다른 API/인코딩/워크플로로 우회하지 않는다.

과거 체크포인트 문서들은 각각 표시된 과거 소스에 대한 기록이다. 이 최신 인계와 현재 원격 코드가 재개 기준이다.
