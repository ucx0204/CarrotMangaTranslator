# 원본 해상도 미리보기

원본 크롭 계약과 캐시는 `ffe8358`, `6f7c2ed`에서, 실제 연속 편집 화면 연결은 `99e354f`에서 반영됐다. 이 파일의 과거 기록에 있던 미연결 Git tree나 조회되지 않는 SHA를 완료 근거로 사용하지 않는다.

100% 이상에서는 표시 영역의 원본 픽셀 크롭을 overview 위, 가림 아래에 표시한다. 페이지·영역·재시도 버전이 달라지거나 원본 확대를 다시 켜면 새 표시가 준비돼야 현재 페이지 확인을 허용한다. 실패·취소·잘못된 크기의 결과를 정상으로 표시하지 않는다. 기본 UI 동작 검사는 기존 3개이며 화면 캡처 매트릭스는 없다.

현재 전체 검사 결과는 [redaction-review-repair.md](redaction-review-repair.md)를 따른다.
