# 연속 편집 단일 화면 정리

브랜치: `feat/manual-redaction-workspace-20260910`
시작 소스: `ffd769ef65eee22069eaad592c767053d56e8720`

## 최신 사용자 요청

전체 보기와 연속 편집의 탭 구분을 없애고 연속 편집 화면 하나에서 처리한다. 설명문은 최소화하며 필요한 안내는 툴팁으로 제공한다. 자동 위치 감지/추천은 추가하지 않는다. master, 태그, 버전, 릴리즈는 변경하지 않는다.

## 구현과 검증 체크포인트

- [ ] 탭/전체 그리드 제거. 기존 grid 모드 초안도 편집 화면으로 복원.
- [ ] 왼쪽 썸네일에서 페이지 이동, Shift 범위 선택, Ctrl/Command 다중 선택 유지.
- [ ] 도구 모음은 짧은 편집 도구와 되돌리기만 표시. 일괄 처리·프리셋·설정은 필요할 때 여는 메뉴로 이동.
- [ ] 페이지 필터를 썸네일 영역으로 제한하여 가로 전체를 차지하는 입력 제거.
- [ ] 진행률/저장 상태와 이동/확인 동작을 간결하게 배치. 마지막 페이지 확인과 최종 전송 승인은 계속 분리.
- [ ] 컴파일·로케일·선택/탐색·일괄 동작 회귀 검사 및 실제 넓은/좁은 화면 QA.

이 문서는 시작 체크포인트이며 아직 구현 완료 기록이 아니다. 기존 기반/3차 사전 준비의 미완료 사항은 `manual-redaction-workspace-handoff.md`에 남아 있다. 재개 시 최신 브랜치와 실제 diff, 검사 로그를 먼저 확인한다.
