# C23 승인 상태와 로컬 앱 통합

사용자가 confirmation-014의 원본 해상도 C18/C23 비교 후 C23 승격을 명시적으로 승인했다.
이 승인은 system-reset-005의 이전 기각 판정을 대체한다. W06의 서체 분열, 일반 내레이션의
과한 굵기와 013/P008의 강조 부족은 남아 있는 반례로 보존한다. 개선이 완벽하다는 판정은 아니다.

## 정확한 변경

내부 버전은 `c23.0`, 소유 팩은 `font-chapter-c18/c23-v1`이다. C18의
`font-chapter-c18/v1`과 모델 파일은 보존한다. 기존 gateway 이름은 유지해 불필요한 구조 이동을 피한다.

- 원문 검증 글자가 0개인 영역에서만 median 3×3 / dark core <64로 줄 위치를 제안한다.
- Hayai 줄/글자 검증에는 가공하지 않은 원문을 사용한다. 줄의 일본어 글자 2개 이상이 원문
  OCR에 연속 일치해야 추가한다. 기존 글자, shape gate, pixel cutoff는 유지한다.
- S5/S6 묶음, S20 유형/굵기 모델, C18 한국어 선택과 렌더 경로는 그대로다. 모델 재훈련이 아니다.
- 연구 산출물의 오래된 strictGlyphs 상세 카운터만 바로잡는다. 폰트 결정에는 사용하지 않는 메타데이터다.

새 팩의 3,137파일 / 911,870,343bytes를 검증했다. 학습 자산 inventory는 C18과 같다.
로컬 팩 검증 명령은 `python scripts/install-font-chapter-c18-local.py --source font-chapter-c18/c23-v1`이다.
공개 자산이나 앱 installer 릴리스를 만들지 않는다.

## 검증 상태

2026-09-07 로컬 앱 통합 검증 완료. 증거는 LAB의
`artifacts/font-palette-lab/system-reset-006`에 보존한다.

- `characterization-002/receipt.json`: 012/013/014/W06의 233영역. 기존 줄 추출과 C23
  dark-core 제안, 총 2,239개 글자 bytes, 묶음 비교 근거, 233개 선택이 동결 연구와 일치했다.
- `c23-app-014-parity.json`: 실제 앱 chapter port, typography, 크기 및 exporter로 66블록,
  9쪽 PNG가 승인된 연구 C23과 일치했다. 전체 실행은 약 179초이며 Hayai 장치 설정을 그대로
  사용했다. 이 숫자를 CPU 모델 단독 시간으로 부르지 않는다.
- `c23-app-W06-parity.json`: 실제 앱 chapter 선택 69개, 최종 70블록과 PNG 10쪽이 일치했다.
  SFX 1개는 기존 계약대로 chapter port 대상이 아니며 최종 SFX 출력까지 같음을 확인했다.
  최초 검증기가 SFX에도 chapter style을 요구한 오류는 검증기에서 수정했다. 제품은 바꾸지 않았다.
- 이 실행은 동결 Hayai 영역 입력/번역/지움/기하를 공유한 통합 parity다. 새 화 일반화나 새
  번역·인페인팅 전체 실행으로 세지 않는다. 앱 014/P004/P008 및 W06/P007 PNG를 다시 직접 열었다.
- `npm run check`: 26개 gate, 5,402개 테스트 통과/기존 skip 2개, 빌드·coverage·타입·lint·
  출력 parity·image protocol 포함. 172.96초. 로그 `.tmp/c23-full-check002.log`.
  최초 check는 후속 연구 메모의 Prettier 서식으로 실패했고 수정 후 전부 통과했다.
- `tests/python/font_chapter_c23_test.py`의 기존 글자 보존/검증되지 않은 추가 거부 및
  복구 불필요 시 추가 OCR 생략 검사 2개 통과. 모델 자산을 새로 학습하거나 교체하지 않았다.

[원본 해상도 앱 C23 통합 보고서](http://127.0.0.1:8769/system-reset-006/chapter-014-app-c23-review.html)
는 기존 C18 B와 승인 C23 앱 C를 명시한다. 1440×1000 및 700×900 실제 Chromium 화면에서
조작부·원본 배율·스크롤과 잘림/겹침을 직접 확인했다. 기존 보고서는 덮어쓰지 않았다.

## 이후 작업 기준

검증한 C23을 master에 커밋하고 그 정확한 커밋에서 새 워크트리를 만든다. 이후 재훈련 계획과
후보는 그 워크트리에서 진행한다. B는 승인 C23, C는 명시적으로 등록한 새 후보다.
과거 v2.5.0/C18 보고서와 기존 실패 판정은 덮어쓰지 않는다. 최신 사용자 지시로 새 품질
평가의 단위는 서로 다른 작품의 무작위 미사용 화 3개, 총 30쪽 안팎이다. 세 화를 보기 전에
봉인하고 한 후보를 중간 수정 없이 함께 평가한다. 화당 최대 5후보, 원본 해상도 HTML과
전체 선택 페이지 검수, 미사용 화 순환을 유지한다. 기존 9/10쪽 검증을 새 3화 평가로 세지 않는다.

롤백은 C23 통합 커밋의 revert와 보존한 C18 팩으로 수행한다. 사용자 fonts·library·원본·출력은
삭제하지 않는다. 새로운 모델은 이 승인 기준의 학습 자산을 덮어쓰지 않는다.
