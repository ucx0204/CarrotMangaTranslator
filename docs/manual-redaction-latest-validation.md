## 최종 검사

측정을 위한 임시 쓰기 권한 workflow와 스크립트는 제거한다. 기존 읽기 전용 Windows 검증에 번역/커버리지 변경 경로와 전체 로그 보존만 추가하고, 기존 `npm run check`의 26개 게이트를 그대로 실행한다. 측정 작업 성공을 최종 전체 check 성공으로 대신하지 않는다.

재개 시 최신 HEAD의 `Manual redaction UX validation` 실행 결과와 artifact부터 확인한다. 이미 반영된 패치나 과거 ZIP을 다시 적용하지 않는다. 최종 전체 검사 및 실제 화면 검사 결과를 확인한 뒤 이 문서를 갱신한다.

이번 복구는 보고된 UI/CI 오류 범위다. 원래 3차의 사전 편집 앱 진입점은 별도 미완료 범위이며 완료했다고 표시하지 않는다. master, 버전/태그/릴리즈, 사용자 보관함/원본/출력물은 변경하지 않았다.
