# 번역 키 노출 점검 — 2026-09-20

## 확인 범위

`src` 전체의 TypeScript/TSX에서 번역 호출 2,500개 이상을 확인했다. `t`, main 번역 함수, appI18n 호출, TFunction으로 바인딩된 별칭, Trans의 i18nKey, labelKey/descriptionKey/titleKey/messageKey 등 옵션 레지스트리를 포함한다. 한국어·영어·일본어·중국어 간체·번체의 실제 합성 catalog를 기준으로 검사한다. 누락 키를 임의의 문구로 치환하는 runtime fallback은 추가하지 않았다.

기존 정규식 검사는 고정 문자열을 주로 확인했다. 새 검사는 TypeScript의 실제 enum/union 타입과 조건식·템플릿을 열거한다. 타입보다 실제 선택지가 좁은 경우도 전체 타입 범위를 검사한다. 타입이 단순 string인 경로는 모두 자동으로 증명할 수 없으므로 원본 레지스트리와 반환 함수를 별도로 확인했다. 최초 조사에서 이런 호출은 47개였다. 설정 옵션/프리셋/탭, API 오류 키, stage 도구, progress label/legacy progress map, 사용 횟수 포맷, resize 대문자 조합, 곡선 정렬·방향이 해당한다. 원본에 있는 키 형태의 문자열도 전수 대조하여 저장 경로·localStorage 키·진단 코드와 번역 키를 구분했다.

## 수정

- 실제 노출: 저장된 효과음 작업 이력의 `statusDock.history.kind.sound-effect-translation` 누락을 수정했다.
- 실제 데이터 경로: 예전 glossary의 `sfx`는 읽기 호환용인데 Select 선택지에 없었다. 기존 sfx 행에서만 번역된 선택지를 제공하고 다른 행에는 폐기된 분류를 다시 추가하지 않는다.
- 타입 계약의 잠재 누락: 원근 identity와 stage warp 이름/도움말을 보완했다. 현재 메뉴에 나타나는 모든 항목이 깨져 있었다는 뜻은 아니다. 메뉴에 없더라도 키를 생성하는 함수가 허용하는 타입 범위를 완성했다.
- 총 5개 키를 지원 언어 5개에 추가했다. 빈 번역·동일 키 문자열을 번역값으로 둔 항목도 별도 점검했다.
