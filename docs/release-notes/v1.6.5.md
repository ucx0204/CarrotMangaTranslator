# v1.6.5 패치노트

기준 범위: `v1.6.4` 이후부터 `v1.6.5`까지의 변경 사항입니다.

## 텍스트 줄바꿈 방식 추가

- 텍스트 블록마다 `표준`, `글자 단위`, `단어 단위`, `긴 문자열 넘침 방지` 중 하나를 선택할 수 있습니다.
- 선택 블록의 서식 패널, 여러 블록 직접 서식, 서식 일괄 적용, 새 블록의 기본 서식 설정에서 같은 옵션을 사용할 수 있습니다.
- 선택한 방식의 동작을 짧은 설명으로 함께 표시하며, 좁은 편집 패널에서도 설명이 패널 밖으로 넘치지 않도록 줄바꿈합니다.
- 기존 프로젝트의 가로·세로 블록은 각각 종전 줄바꿈 방식으로 자동 해석되므로 기존 문서의 모양은 바뀌지 않습니다.

## 화면 표시와 내보내기 일치

- 편집 화면, 자동 글자 크기 계산, 이미지·PDF용 페이지 렌더링이 같은 줄바꿈 규칙을 사용합니다.
- 가로쓰기와 세로쓰기, 부분 굵게·기울임 서식, 한중일 문장부호와 긴 영문·URL을 함께 처리합니다.
- 이모지와 결합 문자 같은 한 글자 단위를 중간에서 쪼개지 않도록 줄 계산을 보강했습니다.

## 검증

- TypeScript 타입 검사와 ESLint 통과
- Vitest 전체 187개 파일, 1,210개 테스트 통과·2개 건너뜀
- 프로덕션 컴포넌트를 사용한 1360px 및 390px Chromium UI QA에서 잘림, 겹침, 가로 넘침 확인
- 프로덕션 빌드와 `git diff --check` 통과

## Code signing policy

[SignPath.io](https://about.signpath.io/)가 제공하고 [SignPath Foundation](https://signpath.org/)이 인증서를 제공하는 무료 코드 서명 정책을 사용합니다.

v1.6.5 Windows 설치 파일에는 Authenticode 서명이 적용되지 않으므로 SignPath Foundation 정책의 보호 대상이 아닙니다. 유효한 SignPath Foundation 서명이 있는 산출물만 해당 정책의 적용을 받습니다.

v1.6.5 Apple Silicon macOS 산출물은 ad-hoc 서명만 적용되며 Apple이 확인한 개발자 신원이나 공증을 포함하지 않습니다. Gatekeeper 승인 전에 릴리스의 체크섬과 다운로드한 파일을 대조하세요.
