# v1.13.1 패치노트

기준 범위: `v1.13.0` 태그의 최종 상태와 `v1.13.1`의 최종 상태를 비교했습니다.

v1.13.1은 Windows AMD Radeon 환경에서 BeeLlama ROCm/HIP 실행 런타임 설치가 `ggml-hip.dll` 크기 제한으로 중단되던 문제를 수정한 안정화 릴리즈입니다.

## AMD Radeon 런타임 설치 수정

- BeeLlama v0.3.1 HIP 런타임에 포함된 1,515,477,504바이트 `ggml-hip.dll`을 정상적으로 압축 해제할 수 있게 했습니다.
- 허용 범위는 파일명·URL·압축 크기·SHA-256이 모두 일치하는 고정된 공식 자산에만 적용됩니다. 다른 런타임 압축파일의 공용 안전 제한은 완화하지 않았습니다.
- 다운로드 파일이 검증 또는 압축 해제 도중 교체되거나 크기·체크섬이 달라지면 설치 결과를 게시하지 않고 실패 처리합니다.
- 설치된 ROCm/HIP 커널 파일도 무결성 검사에 포함하고, 대용량 DLL은 4MiB 단위로 검사해 파일 전체를 메모리에 올리지 않도록 했습니다.

## 업그레이드 안내

- 기존 작품·페이지·번역문·서식, 설정과 모델 캐시의 저장 형식은 변경되지 않습니다.
- 이 문제를 겪었던 경우 v1.13.1로 업데이트한 뒤 `설정 → 설치 / 확인`에서 AMD Radeon 실행 런타임 설치를 다시 시도하세요.
