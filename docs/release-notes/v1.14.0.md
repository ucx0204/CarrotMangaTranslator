# v1.14.0 패치노트

기준 범위: `v1.13.2` 태그의 최종 상태와 `v1.14.0`의 최종 상태를 비교했습니다.

v1.14.0은 번역 텍스트를 Photoshop 방식의 3×3 또는 5×5 메쉬로 부드럽게 변형하는 워프 편집과 출력 지원을 추가한 기능 릴리즈입니다.

## 텍스트 메쉬 워프

- 블록 편집기의 `배치 → 변형`에 `워프` 모드를 추가했습니다. 3×3과 5×5는 칸 수이며 각각 4×4, 6×6 제어점을 제공합니다.
- 제어점 드래그, Shift+클릭과 영역 다중 선택, 격자선으로 행·열 전체 이동, 방향키 1px 및 Shift+방향키 10px 이동을 지원합니다. 선택점 X/Y 백분율 입력과 선택점·격자 초기화도 사용할 수 있습니다.
- `아치 위`, `아치 아래`, `벌지`, `압축`, `깃발`, `물결` 프리셋을 제공하며 적용 후 모든 제어점을 자유롭게 조절할 수 있습니다.
- 3×3과 5×5 전환은 현재 Thin Plate Spline 곡면을 새 격자에 재표본화합니다. 전환과 포인터 드래그는 각각 하나의 실행 취소·자동 저장 기록으로 확정됩니다.

## 변형 안전성과 조합

- 제어점 사이를 Thin Plate Spline으로 보간하고, 격자 뒤집힘·접힘·과도한 축소·비유한 좌표·허용 범위 초과와 페이지 밖 완전 이탈을 거부합니다.
- 여러 줄, 세로쓰기, 부분 굵게·기울임, 외곽선과 기존 곡선 텍스트를 같은 DOM 텍스트 결과 위에서 변형하므로 별도 글꼴 엔진 없이 기존 조형을 유지합니다.
- 합성 순서는 `텍스트 배치·곡선 → 워프 → 원근 → 회전`으로 고정했습니다. `모두 초기화`는 회전·원근·곡선·워프를 함께 제거합니다.
- 워프 모드와 제어점 안내, 접근성 레이블을 한국어·영어·일본어·중국어 간체·번체에 추가했습니다. 분리 편집 패널에서도 모드와 블록 상태가 동기화됩니다.

## PNG·PSD 출력과 성능

- 실제 `OverlayText`와 `CurveText` 결과에 역변위 PNG 맵과 인라인 SVG `feDisplacementMap`을 적용합니다. 드래그 중에는 저해상도 맵을, 확정 화면과 PNG/PSD 출력에는 고해상도 맵을 사용하며 변형·크기별로 캐시합니다.
- 출력 렌더러는 모든 워프 변위 맵이 디코딩되고 안정화된 뒤에만 ready 상태가 됩니다. 편집 화면과 PNG 출력은 복합 워프 fixture에서도 픽셀 단위로 동일하게 렌더링됩니다.
- 워프 블록은 PSD에서 투명 배경의 정확한 개별 래스터 텍스트 레이어로 저장합니다. 워프가 없는 일반 블록의 편집 가능한 PSD 텍스트 동작은 그대로 유지합니다.

## 업그레이드 안내

- 기존 작품과 페이지는 `warpTransform` 필드가 없으면 이전과 동일하게 동작하며 별도 마이그레이션이 필요하지 않습니다.
- 사용자 워프 프리셋 저장과 서식 일괄 적용은 이번 버전에 포함되지 않습니다. 워프는 각 블록의 고유 기하로 저장됩니다.
