# v3.2.3

Windows 설치본에서 폰트 자동 맞춤과 OCR 종료 단계가 실패하던 문제를 고쳤습니다.

## 오류 수정

- Python 3.14 기반 Hayai 런타임에서 폰트 자동 맞춤의 NumPy·SciPy·ONNX Runtime을 불러오지 못하던 호환성 문제를 수정했습니다([#141](https://github.com/ucx0204/CarrotMangaTranslator/issues/141)). Windows용 의존성을 새 자산 묶음으로 배포하며 기존 폰트 모델과 선택 알고리즘은 유지합니다.
- OCR 프로세스가 정상 종료되는 순간 Windows 종료 명령이 같은 프로세스를 찾지 못해 전체 페이지 작업을 실패 처리하던 문제를 수정했습니다. 정상 종료가 확인된 경우만 허용하며 실제 종료 실패는 계속 보고합니다.

## 개발 검증 속도

- GitHub Check의 전체 테스트를 Windows와 macOS 각각 네 runner에 분산하고, 빌드와 동시에 실행합니다. 모든 테스트와 빌드가 통과한 뒤 커버리지를 합쳐 기존 기준을 검사합니다.
- Rust 빌드 캐시, 같은 네이티브 CLI 호출의 결과 재사용, MCP 이미지 fixture의 중복 PNG 인코딩 제거로 반복 준비 비용을 줄였습니다.
- 중복 스키마·CSS 검사를 정리하고 공통 회귀 입력을 통합했습니다. 취소·권한 철회·동시 실행·복구·rollback 검사와 커버리지 기준은 유지합니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.2.3.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.2.3-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
