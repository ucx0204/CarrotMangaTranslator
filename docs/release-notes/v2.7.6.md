# v2.7.6

- 텍스트가 포함된 PSD 출력에서 `Cannot read properties of undefined (reading 'render')` 오류로 작업이 실패하던 문제를 수정했습니다. 렌더 세션의 공개 함수가 항상 자신이 생성된 세션을 사용하도록 보강했습니다.
- 실제 렌더 세션과 PSD 작성기를 함께 실행하는 회귀 테스트를 추가했습니다. 정규 검사에서도 Electron으로 PSD를 저장하고 다시 읽어 배경·텍스트 레이어와 투명도를 검증합니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
