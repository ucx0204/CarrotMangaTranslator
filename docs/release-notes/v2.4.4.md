# v2.4.4 패치노트

## OpenAI Codex

- 내장 Codex App Server를 0.153.1로 업데이트해 계정에 제공되는 GPT-6-Astra를 선택할 수 있도록 했습니다.
- 설정 화면이 열려 있는 동안 5분마다 Codex 모델 목록과 추론 강도를 자동으로 갱신합니다. 창으로 돌아올 때도 목록이 오래되었으면 다시 조회하므로, Codex가 계정에 공개한 새 모델을 앱에 일일이 등록할 필요가 없습니다.
- 모델 목록 갱신에 실패하면 기존 목록과 선택을 유지하고 다음 조회에서 자동으로 복구합니다. 로그인·로그아웃과 진행 중인 작업에 갱신이 간섭하지 않도록 하고, 늦게 도착한 응답이 계정 상태를 덮어쓰는 경우를 방지했습니다.

새로운 Codex 실행기 기능이 필요한 모델은 앱 업데이트가 필요할 수 있습니다.
