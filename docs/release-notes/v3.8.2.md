# v3.8.2

v3.8.1의 UI·접근성 개선을 포함하는 후속 릴리스입니다. macOS 배포 검증에서 디스크 이미지 등록을 실제 볼륨 마운트 완료로 오인하던 문제를 수정했습니다.

## 배포 검증 수정

- macOS 업데이트 검사에서 다운로드한 DMG의 볼륨이 실제로 준비될 때까지 기다립니다. 이미지 등록 직후의 일시적인 상태 때문에 정상 패키지의 게시가 중단되는 문제를 해결했습니다.
- 마운트가 끝내 완료되지 않거나 상태 조회가 실패하면 여전히 검사를 실패 처리합니다. 기존 90초 제한과 실제 볼륨 확인 조건을 유지했습니다.
- 이미지 등록과 볼륨 마운트 사이의 지연을 재현하는 회귀 테스트를 추가했습니다.
- 앱의 UI와 업데이트 동작은 v3.8.1과 같습니다. 숫자·단위 겹침, 포커스 테두리 잘림, 키보드 이동 등 개선 내용은 [v3.8.1 릴리스 노트](v3.8.1.md)에서 확인할 수 있습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.2.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.2-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
