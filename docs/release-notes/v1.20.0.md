# v1.20.0 패치노트

기준 범위: `v1.19.1` 태그(`3bd3f662`)와 이번 `v1.20.0` 최종 트리를 직접 비교했습니다. 연구 과정에서 만들었다가 폐기한 방식이나 중간 조정 내역이 아니라, 최종 제품에 남은 동작만 기록했습니다.

v1.20.0은 번역문을 단순히 블록 끝까지 키우는 대신 원문 이미지에서 실제로 보이는 글자의 크기를 측정해 한글 글꼴의 시각 크기로 옮기는 `글자 크기 자동 맞춤`을 추가한 기능 릴리스입니다.

## 원문 시각 크기 기반 자동 맞춤

- `번역 실행 → 블록 · 줄 나눔`에 `글자 크기 자동 맞춤`을 추가했습니다. 새 설치에서는 기본으로 켜지며, 선택한 값은 번역 기본값으로 저장할 수 있습니다. 현재 페이지 재번역에서도 같은 옵션을 제공합니다.
- 기본 서식에 있던 블록 크기 기준 자동 맞춤 스위치는 제거했습니다. 글자 크기를 자동으로 정할지는 번역 실행에서 선택하고, 기본 서식의 크기 입력은 자동 맞춤을 끈 경우 사용할 기준 크기로 역할을 분리했습니다. 기존 스타일 프리셋과 작업에 저장된 자동 맞춤 값은 호환성을 위해 계속 읽습니다.
- 이 기능은 원 제작자가 지정했던 `pt`나 명목상 `font-size`를 추측하지 않습니다. 같은 32px이라도 글꼴마다 실제 글자 몸통이 차지하는 비율이 다르기 때문에, 페이지에 래스터화되어 실제로 보이는 글자 면적과 높이·폭을 기준으로 맞춥니다.

### 작동 원리

1. OCR이 찾은 원문 영역을 가로쓰기·세로쓰기 방향에 맞춰 읽고, 어두운 글자와 밝은 반전 글자 양쪽의 후보 마스크를 만듭니다.
2. 연결 성분과 방향별 투영을 분석해 말풍선 경계, 배경 무늬, 작은 후리가나, 외곽선 효과처럼 글자 크기를 부풀릴 수 있는 요소를 걷어냅니다. OCR 글자 수에서 예상되는 글자 간격, 행 수, 전경 비율과 각 행의 크기 분산도도 함께 비교합니다.
3. 신뢰도 검사를 통과한 본문 글자의 가시적인 몸통 크기만 `source face` 값으로 기록합니다. 합성 자료에서 교정한 작은 고정 보정식을 함께 사용하지만 별도의 AI 런타임이나 모델 다운로드는 추가하지 않습니다.
4. 실제 번역문, 선택된 한글 글꼴, 굵기·기울임과 쓰기 방향을 프로덕션 Canvas에서 측정합니다. 원문의 가시 크기와 한글 글꼴의 실제 글자 몸통이 같아지는 명목 px를 역산하므로, 같은 숫자라도 작게 보이는 글꼴과 크게 보이는 글꼴을 서로 다르게 보정합니다.
5. 계산한 크기는 기존 블록 자동 맞춤의 **상한**으로 사용합니다. 최종 크기는 `원문 시각 크기에 맞춘 값`과 `번역문이 블록 안에 들어가는 최대값` 중 작은 값입니다. 따라서 번역문이 길면 기존처럼 더 줄어들 수 있지만, 번역문이 짧다는 이유만으로 원문보다 과도하게 커지지는 않습니다.
6. 배경이 복잡하거나 글자 수가 너무 적고, 방향·간격·성분 분석이 서로 맞지 않는 경우에는 억지로 크기를 바꾸지 않습니다. 이런 블록은 측정을 포기하고 기존 블록 자동 맞춤으로 돌아갑니다.

폰트 자동 맞춤 v2는 계속 글꼴 종류와 굵기를 담당하고, 이번 기능은 그 결과로 선택된 글꼴의 시각 크기만 별도로 계산합니다. 폰트 자동 맞춤을 사용하지 않아도 사용자가 선택한 글꼴을 기준으로 같은 크기 보정이 적용됩니다.

## 적용 범위와 검증

- 일반 가로·세로 대사와 내레이션을 우선 대상으로 합니다. 곡선, 원근, 심한 왜곡·회전, 장식 효과음처럼 신뢰할 수 있게 몸통 크기를 분리하기 어려운 블록은 자동 변경하지 않고 기존 동작을 유지합니다.
- 글자 크기 측정값과 신뢰도는 선택 필드로 저장됩니다. 기존 작업을 일괄 변환하지 않으며, 번역 또는 재번역으로 새 블록을 만들 때 선택한 옵션에 따라 기록합니다.
- 합성 평가에서는 학습에 사용하지 않은 일본어 글꼴에서도 보정 후 가시 크기 오차가 중앙값 1.54%, P90 6.42%였습니다. 원문과 한글에 같은 명목 px를 그대로 적용했을 때 글꼴에 따라 20~30% 가까이 벌어지던 차이를 실제 대상 글꼴 렌더링으로 보정했습니다.
- 표지를 제외한 20개 서로 다른 작품의 본문 페이지를 기존 방식과 같은 인페인트·출력 렌더러로 A/B 비교했습니다. 개발군 10/10페이지와 분리된 홀드아웃 10페이지 중 8페이지에서 새 방식이 원문 글자 몸통에 더 가까웠고, 페이지 전체가 기존 방식보다 나빠진 사례는 없었습니다. 신뢰도 검사를 통과한 일반 본문 적용률은 각각 84.7%, 91.9%였으며 나머지는 기존 방식으로 안전하게 복귀했습니다.
- 가로·세로, 검정·반전 글자, 외곽선, JPEG 노이즈, 다양한 내장 글꼴, 저장 후 재로딩과 프로덕션 출력 경로를 자동 테스트로 고정했습니다.

## 번역·출력 창 정리

- 번역 실행, 원문 지우기의 `지울 페이지 선택`, 결과물 출력 창이 화면 여백을 제외한 세로 공간을 활용하도록 확장했습니다. 내용이 많은 설정에서도 작은 내부 영역만 스크롤하는 대신 한 화면에서 더 많은 항목을 볼 수 있습니다.
- 현재 페이지 재번역에서도 글자 크기 자동 맞춤 여부를 선택하고 기본값으로 저장할 수 있게 했습니다. 선택한 페이지가 실행 전에 사라졌거나 비어 있는 경우에는 잘못된 범위로 번역을 시작하지 않고 명확한 오류로 중단합니다.

## 호환성 참고

- 기존 폰트 자동 맞춤 v2 모델과 폰트 선택 결과는 변경하지 않았습니다.
- 기존 작업과 스타일 프리셋은 그대로 불러오며, 저장된 블록을 백그라운드에서 일괄 재작성하지 않습니다.
- 글자 크기 측정은 CPU에서 실행되는 결정론적 전처리이며, 새 모델 자산이나 네트워크 요청을 요구하지 않습니다.
- 지원 운영체제는 Windows 10/11과 Apple Silicon macOS 14+로 v1.19.1과 같습니다.
