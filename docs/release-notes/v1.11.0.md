# v1.11.0 패치노트

기준 범위: `v1.10.1` 이후부터 `v1.11.0`까지의 변경 사항입니다.

v1.11.0은 작업 공간의 검수 UX, 서식 재사용, 작업 상태 확인, 덮어쓰기 방지 안내를 크게 개선한 릴리즈입니다. 동시에 OCR·GPU 런타임과 가져오기·저장·종료 과정의 데이터 안전성을 보강했습니다.

## v1.10.1 대비 핵심 차이

- **페이지 검수 화면:** 페이지를 고르면 오른쪽에 현재 페이지의 모든 블록이 읽기 순서대로 표시됩니다. 원문을 확인하면서 번역문을 바로 고칠 수 있고, 필요한 블록만 `상세 편집`으로 들어갈 수 있습니다.
- **페이지 목록:** 썸네일, 블록 수, 상태 필터, 표시 개수, 페이지별 더보기 메뉴가 추가됐습니다. `번역 완료`와 지우기·후처리까지 끝난 `완료`도 구분합니다.
- **작업 잠금:** 화 전체를 막는 대신 실제 처리 중인 페이지를 잠급니다. 먼저 끝난 페이지는 다음 페이지가 처리되는 동안 열고 검수·편집할 수 있습니다.
- **서식 프리셋:** 현재 블록이나 기본 서식에서 프리셋을 만들고, 필요한 서식 항목만 저장해 한 블록 또는 여러 선택 블록에 다시 적용할 수 있습니다.
- **작업 센터와 저장 상태:** 최근 작업, 진행률, 취소, 실패 페이지 재시도, 결과 검토, 내보내기, 로그 열기를 한곳에 모았습니다. 자동 저장 상태는 화 제목 옆에서 바로 확인할 수 있습니다.
- **안전한 번역·설정 흐름:** 번역 옵션이 다음 작업의 기본값을 몰래 바꾸지 않으며, 완료 결과를 다시 번역할 때 덮어쓰기 경고를 표시합니다. 설정 초기화도 저장 전에는 실제 설정에 적용되지 않습니다.
- **PNG 출력:** 선택 범위를 내보내기 전에 미완료·실패·후처리 대기·빈 번역·인페인팅 누락을 확인하고, 문제 페이지로 바로 이동할 수 있습니다. 인페인팅 배경만 저장하는 `글자 없이 출력`도 추가됐습니다.
- **OCR·GPU·데이터 안전성:** 설치된 OCR 백엔드의 실제 패키지 검증, RTX 20 계열 Flux 경로, API 키 OS 암호화, 저장 트랜잭션과 종료 정리를 추가했습니다.

## 페이지 검수와 작업 공간 UI

- 페이지를 선택하면 오른쪽 패널에 `현재 페이지 블록` 목록이 열립니다. 각 행에서 원문과 번역문을 함께 보고 번역문을 바로 수정할 수 있습니다.
- 블록은 원문 읽기 방향에 맞춰 정렬됩니다. `검토 필요`, `효과음`, `지우기 제외` 상태도 목록에서 바로 확인할 수 있습니다.
- 목록에서 블록을 선택하는 동작과 전체 서식 편집기를 여는 동작을 분리했습니다. 번역문을 고치려다 의도치 않게 상세 편집 화면으로 전환되지 않습니다.
- 이전·다음 페이지와 이전·다음 블록 단축키를 추가했습니다. 페이지를 바꾸면 블록 목록도 해당 페이지에 맞춰 전환됩니다.
- 페이지 목록에 썸네일, 블록 수, 처리 상태, 표시 중인 페이지 수를 추가했습니다.
- 페이지 상태를 `전체`, `진행`, `실패`, `대기`, `완료`로 필터링할 수 있습니다. 필터 때문에 현재 선택한 페이지가 가려지면 별도 안내를 표시합니다.
- 페이지별 재번역·삭제는 행의 더보기 메뉴로 정리했습니다. 페이지 목록은 `번역 완료`와 지우기·후처리까지 끝난 `완료`를 구분합니다.
- 보관함과 페이지 목록을 각각 접을 수 있어 필요한 목록에 세로 공간을 더 줄 수 있습니다.
- 화의 모든 페이지가 끝났는데 보관함에는 `부분 완료`로 남던 오래된 집계 상태를 페이지 실제 상태에서 다시 계산합니다.
- 현재 페이지의 빈 공간을 클릭해 선택을 해제한 뒤 번역문을 편집할 때, 이전 블록의 서식 편집 경로로 잘못 이동하던 문제를 수정했습니다.

## 보관함·가져오기·선택 UI

- 작품 선택창에서 제목을 검색하고 `보관함 순서`, `이름순`, `최근 수정`으로 정렬할 수 있습니다. 말줄임된 긴 제목은 마우스를 올리면 전체 제목을 보여줍니다.
- `번역`은 `새 원본 추가`, `작품 일괄 번역`은 `여러 화 추가`, `공유하기/공유본 가져오기`는 `작업 내보내기/작업 가져오기`로 바꿔 실제 동작이 드러나게 했습니다. 사이드바와 명령 팔레트의 이름도 함께 맞췄습니다.
- 새 원본 추가 화면은 이미지 여러 장, 폴더, ZIP·CBZ가 각각 어떻게 화로 추가되는지 바로 설명합니다. 열어 둔 작품이 있으면 새 화의 기본 대상으로 표시합니다.
- 텍스트 모아보기의 가져오기·내보내기 동작을 한 메뉴로 정리하고 검색 입력의 접근성 레이블을 보강했습니다.
- 렌더러의 기본 `<select>`를 앱 디자인의 공통 드롭다운으로 교체했습니다. 키보드 이동, 검색, 비활성 항목 건너뛰기, 닫힌 뒤 포커스 복원, 화면 경계 배치를 공통으로 지원합니다.
- 설정, 가져오기, 내보내기, 재번역, 확인 창의 제목·본문·위험 안내·하단 버튼 배치를 공통 모달 구조로 정리했습니다. 체크박스, 숫자 입력, 탭, 세그먼트, 진행 표시와 팝업의 조작 방식도 통일했습니다.
- 작품·화 검색창의 겹친 테두리와 배경에 묻히던 입력 글자색을 수정하고, 새 원본 선택 카드의 잘못된 초기 강조를 제거했습니다.

## 블록 서식 프리셋

- 현재 블록의 서식 또는 설정의 기본 서식에서 새 프리셋을 만들 수 있습니다.
- 글꼴, 크기·자동 맞춤, 정렬, 줄바꿈, 가로·세로 방향, 굵게·기울임, 줄 간격, 자간, 글자 폭, 색상, 외곽선, 회전·투명도 중 필요한 그룹만 골라 저장할 수 있습니다. 원문·번역문과 블록 위치는 프리셋에 포함되지 않습니다.
- 저장한 프리셋은 블록 편집기에서 바로 선택·적용·삭제할 수 있습니다. 여러 블록을 선택한 경우 한 번에 적용되고 작업 공간 실행 취소 기록도 한 단계로 남습니다.
- 자주 쓰는 프리셋을 `빠른 서식`에 고정하고, 프리셋을 사용자 그룹으로 묶을 수 있습니다. 그룹을 열면 소속 프리셋이 같은 탭 영역에 펼쳐집니다.
- 설정의 기본 서식 화면에서 프리셋을 선택한 채 포함 항목과 값을 직접 수정할 수 있습니다. 프리셋이 많아지면 탭 영역을 가로로 스크롤할 수 있습니다.
- 저장된 글꼴을 찾을 수 없으면 경고를 표시하고, 적용할 때 해당 글꼴만 건너뛰어 나머지 서식은 유지합니다.
- 적용 항목을 0개로 만들 수 없도록 구체적인 안내를 표시하며, 제외된 항목은 위치를 유지한 채 비활성화하고 다시 켜는 위치를 툴팁으로 알려줍니다.

## 페이지 단위 잠금·저장·작업 센터

- 번역, 재번역, 인페인팅, PNG 내보내기는 작업 시작 시 대상 페이지 revision을 기록합니다.
- 작업 중인 페이지의 원문·블록·이미지 상태가 바뀌면 오래된 결과를 최신 페이지 위에 덮어쓰지 않습니다.
- 실제 처리 중인 페이지만 편집 잠금으로 표시합니다. 번역이 먼저 끝난 페이지는 후속 페이지가 실행 중이어도 잠금이 풀려 바로 검수할 수 있습니다.
- 자동 저장 상태를 화 제목 옆에 `저장 대기 중`, `저장 중`, `저장됨`, `저장 실패`, `저장 충돌`로 표시합니다. `저장됨`은 잠시 뒤 사라지고, 실패한 저장은 다시 시도할 수 있습니다.
- 작업 센터에서 현재 진행률과 취소 상태, 최근 작업 기록을 확인할 수 있습니다. 최근 상태는 최대 5개 높이에서 내부 스크롤되며 기록을 지울 수 있습니다.
- 완료된 번역은 `결과 검토`와 `내보내기`로 바로 이어지고, 실패한 작업은 실패 페이지별 재시도와 로그 폴더 열기를 제공합니다.
- 백그라운드 작업 중에는 작은 알림 표시 대신 실행 중 상태를 더 눈에 띄게 보여줍니다.

## 번역·재번역 안전성

- 번역 실행 창에서 바꾼 옵션은 기본적으로 이번 실행에만 사용합니다. `다음 번역의 기본값으로 저장`을 직접 선택했을 때만 다음 작업에도 저장됩니다.
- 완료된 페이지나 수동 수정이 있는 블록을 선택 범위에 포함하면 기존 결과가 바뀐다는 경고와 별도 확인 단계를 표시합니다.
- 번역·재번역으로 현재 작업 중인 화의 블록 내용이 바뀌면 실행 전·후 스냅샷을 작업 공간 기록에 남깁니다. 페이지 재번역 결과는 한 번의 실행 취소로 기존 번역과 수동 수정 상태를 복구할 수 있습니다.
- `정밀 2차`는 `정밀 2차 (레거시)`로 표시하고 처리 시간 대비 일반적인 품질 향상 효과가 제한적이며 추후 제거 예정임을 안내합니다.
- OCR `최소`도 `최소 (레거시)`로 표시합니다. Paddle OCR의 CUDA 레거시 풀로드 선택지는 제거하고 저장된 별칭은 현재 풀로드 경로로 마이그레이션합니다.

## 인페인팅과 PNG 내보내기

- 하나의 말풍선이 둘 이상의 텍스트 블록으로 나뉜 경우, 가까운 원문 글자 마스크를 안전 영역까지 연결해 블록 사이에 세로 글자나 원문 조각이 남는 문제를 줄였습니다.
- 연결 마스크는 같은 말풍선으로 묶인 가까운 글자에만 확장하며, 관계없는 블록 사이의 빈 공간까지 과하게 지우지 않습니다.
- 인페인팅이 실행되는 동안 페이지가 수정됐다면 오래된 결과를 거부하고 최신 수동 편집을 보존합니다. 각 결과는 독립된 이미지 revision으로 기록돼 실행 취소·다시 실행 충돌도 줄였습니다.
- PNG 출력 전에 선택한 화·페이지 수와 파일명 예시를 보여주고 페이지 상태를 점검합니다.
- 사전 점검은 작업 중, 번역 실패·대기, 후처리 대기, 빈 번역문, 글자 없는 출력에 필요한 인페인팅 결과 누락을 구분해 보여줍니다. 각 문제에서 해당 페이지로 바로 이동할 수 있습니다.
- `글자 없이 출력`을 추가했습니다. 번역 글자를 합성하지 않고 인페인팅된 배경 PNG만 저장하므로 Photoshop 등 외부 도구에서 직접 식질할 수 있습니다.
- 기존 파일을 덮어쓰지 않는 정책과 실제 생성될 파일명 예시를 화면에서 미리 확인할 수 있습니다.
- 입력 이미지와 출력 PNG의 실제 치수, 최대 픽셀 수, base64·PNG 데이터 크기를 재검사해 비정상적으로 큰 출력이나 손상된 캡처를 차단합니다.

## 설정·하드웨어·API 키

- 변경한 설정이 있으면 저장하지 않고 닫기 전에 확인합니다. 저장 버튼은 실제 변경이 있을 때만 활성화됩니다.
- `기본값 복원`은 즉시 실제 설정을 덮어쓰지 않고 편집 중인 초안에만 불러옵니다. `저장`해야 적용되고 `취소`하면 기존 설정이 유지됩니다.
- 하드웨어 설정 상단에 감지된 GPU, 현재 OCR 경로, 현재 인페인팅 경로와 권장 설정 일치 여부를 요약합니다. 권장값을 한 번에 적용할 수도 있습니다.
- GPU 배정, OCR 실행 장치, 인페인팅 백엔드는 고급 설정으로 접어 기본 화면의 정보 밀도를 낮췄습니다.
- API 키를 `settings.json` 평문에서 Electron의 OS 암호화 저장소로 이전합니다. 기존 평문 키도 업그레이드 후 암호화 저장소로 마이그레이션하며, 설정 화면에는 마스킹된 상태만 전달합니다.
- GPU OCR 권장값은 최소 모드로 자동 하향하지 않습니다. 사용 가능한 GPU 메모리가 4GB 이상이면 풀로드를, 그보다 작거나 CPU를 사용하면 절약을 권장합니다.
- OCR 풀로드는 PaddleOCR의 고품질 좌표·조각과 Transformers 처리를 결합하며, Gemma가 의미 단위로 묶는 현재 경로를 사용합니다.

### NVIDIA·AMD·CPU OCR 런타임 수정

- NVIDIA CUDA 12.6/13.0은 `torch`와 `torchvision`을 각각 정확한 `+cu126`/`+cu130` wheel 및 SHA-256으로 고정합니다.
- AMD는 Windows ROCm 7.2.1 wheel, CPU는 CPU PaddlePaddle, NVIDIA Paddle 경로는 CUDA 12.6/12.9 wheel만 허용합니다.
- 설치 전 lock 파일과 설치 후 실제 패키지 버전을 모두 검사합니다. 선택한 장치와 다른 백엔드가 설치되면 이를 드라이버 문제로 잘못 안내하지 않고, 해당 런타임을 폐기해 올바른 패키지를 다시 설치합니다.
- 기존에 잘못 설치된 OCR 런타임이 남아 있어도 재사용하지 않습니다. 업그레이드 후 첫 OCR 실행에서는 올바른 런타임을 다시 내려받느라 시간이 걸릴 수 있습니다.

## GPU와 플랫폼 지원

- NVIDIA 공식 CUDA·cuDNN 재배포 manifest가 파일 크기를 숫자 문자열로 제공할 때 정상 파일을 거부하던 문제를 수정했습니다. CUDA Flux와 AMD ZLUDA 보조 런타임이 사용하는 네 아카이브의 크기와 SHA-256을 앱 내부에도 고정해 원격 manifest와 다운로드 결과를 이중 검증합니다.
- AMD Flux ROCm 분할 런타임은 전체 크기와 SHA-256을 확인한 뒤 조립하며, 검증된 캐시만 재사용합니다. OCR용 관리 Python도 캐시해 반복 설치 비용을 줄였습니다.
- RTX 20 계열과 같은 SM75 GPU에서 Flux를 사용할 수 있는 실험적 CUDA 경로를 추가했습니다.
- macOS Apple Silicon 패키지는 런타임 자산, ZIP 의존성, 앱 실행 수명주기와 Metal 경로를 더 엄격하게 검증합니다.
- Windows와 macOS 패키징 모두 포함 런타임과 다운로드 자산의 무결성 계약을 강화했습니다.

## 데이터 보존과 작업 수명주기

- 같은 데이터 보관 위치를 두 앱 인스턴스가 동시에 열지 못하도록 단일 인스턴스 데이터 잠금을 추가했습니다.
- 작품·화·페이지 변경을 트랜잭션으로 저장하고, 쓰기 도중 앱이 종료돼도 다음 실행에서 완료 또는 롤백할 수 있는 복구 기록을 남깁니다.
- 가져오기·공유 패키지 읽기와 내보내기를 스트리밍 처리해 큰 작업이 메모리를 과도하게 점유하지 않도록 했습니다.
- 공유 패키지 가져오기 중 취소·충돌·종료가 발생해도 기존 작품과 새 파일이 반쯤 섞이지 않도록 원자적 게시와 휴지통 복구를 적용했습니다.
- 번역·인페인팅·내보내기·모델 테스트 같은 장시간 작업을 중앙 작업 레지스트리에서 추적하고, 취소와 앱 종료 시 자식 프로세스 트리까지 제한 시간 안에 정리합니다.
- 종료 정리가 끝나지 않는 경우 무한히 멈추지 않도록 하드 타임아웃을 적용했습니다.
- 치명적인 메인 프로세스 오류나 창 수명주기 실패가 발생하면 새 저장 작업을 계속 받지 않는 fail-closed 동작을 적용했습니다.

## 입력·다운로드·내보내기 방어

- 가져오기 전에 PNG·JPEG·WebP 헤더와 실제 이미지 크기를 검사해 비정상적으로 큰 이미지나 손상된 파일을 디코더에 넘기지 않습니다.
- 페이지 렌더링과 PNG 출력에 픽셀·메모리 예산을 적용해 지나치게 큰 캔버스가 프로세스를 고갈시키는 것을 막습니다.
- 모델·런타임 다운로드와 API 응답에 크기 제한과 절대 시간 제한을 적용하고, 취소 시 남은 응답 스트림과 자식 프로세스를 정리합니다.
- ZIP·tar 압축 해제 경로, 심볼릭 링크, 파일 개수와 해제 크기를 검증해 대상 폴더 밖으로 쓰거나 비정상적으로 팽창하는 압축파일을 거부합니다.
- 런타임 설치는 hash-complete lock과 무결성 manifest를 사용하며, 임시 디렉터리에서 검증을 끝낸 뒤 완성된 디렉터리만 게시합니다.

## 업그레이드 안내

- 기존 작품·화·페이지와 설정은 유지됩니다. `v1.11.0`에서 새로 만든 서식 프리셋은 설정에 함께 저장됩니다.
- 앱 삭제 후 설치 경로에 `data` 폴더만 남아 있다면 작품 보관 데이터를 위해 정상적으로 보존된 상태입니다. 해당 폴더를 직접 삭제하지 마세요.
- 잘못된 OCR 런타임만 자동 재설치 대상이며 작품 보관함은 삭제하지 않습니다.
- `정밀 2차 (레거시)`와 `최소 (레거시)`는 이번 버전에서는 계속 사용할 수 있지만 추후 제거될 예정입니다.
