# v2.7.7

## 결과물 동기화 중 편집 잠김 수정

- 결과물 자동 동기화와 블록 선택·편집이 겹칠 때 해당 페이지의 편집 잠금이 오래 유지되던 문제를 수정했습니다. 취소된 렌더링이 제한 시간까지 기다리지 않고 종료되도록 했습니다. ([#106](https://github.com/ucx0204/CarrotMangaTranslator/issues/106))
- 취소 신호를 이미지 읽기, 페이지 로드, 렌더 준비와 캡처 단계까지 전달합니다. 큰 이미지의 타일 합성도 해당 FFmpeg 프로세스가 종료된 뒤 임시 파일을 정리하고 페이지 잠금을 해제합니다.
- 다른 페이지·렌더 세션의 작업과 잠금은 유지하며, 취소 후 늦게 도착한 결과가 작업을 다시 진행하지 않도록 보호합니다.

## 검증 보강

- 렌더링 각 단계의 취소, 페이지 잠금 해제, 다른 세션과의 격리, FFmpeg 종료·실패·시간 초과를 확인하는 회귀 테스트 17개를 추가했습니다.
- 기존 PNG·PSD 렌더링과 타일 합성의 픽셀 일치 검사를 유지합니다. 보관함 형식, OCR·번역·폰트 알고리즘은 변경하지 않았습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
