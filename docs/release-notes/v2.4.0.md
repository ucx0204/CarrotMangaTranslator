# v2.4.0 패치노트

## 작업 화면과 모달

- 페이지 작업 영역을 간결하게 정리하고, 중복 안내 문구를 제거했습니다. 현재 도구 이름은 왼쪽 도구 모음이 접힌 경우에만 오른쪽 빠른 도구 모음 옆에 표시됩니다.
- 좌우 도구 모음의 아이콘 버튼이 마우스와 키보드 입력에 일관되게 반응하도록 수정하고, 좁은 화면에서 도구 모음이 접히는 동작을 안정화했습니다.
- 모달과 주요 화면 전환에 짧고 자연스러운 애니메이션을 적용했습니다. 운영체제의 동작 줄이기 설정을 사용하면 애니메이션도 함께 줄어듭니다.
- 텍스트 모아보기에서 일괄 편집을 열 때 새 창이 완전히 표시된 뒤 기존 창이 닫히도록 전환 순서를 수정했습니다.

## API 공급자 설정

- Custom API, NVIDIA NIM, Gemini API, Vertex AI, OpenRouter, Ollama의 엔드포인트·인증 키·인증 방식·추가 헤더를 공급자별로 따로 저장하도록 변경했습니다.
- 로컬 Gemma, Codex, 각 API 공급자와 모델의 출력 한도와 문맥 한도를 서로 독립적으로 설정할 수 있습니다. 인터넷 조사도 번역 설정과 분리된 공급자별 설정과 생성 한도를 사용합니다.
- Vertex AI 서비스 계정 JSON 선택과 기존 인증 정보 이전을 지원하고, 모델 목록을 불러올 때 현재 선택한 공급자에 저장된 인증 정보를 사용하도록 수정했습니다.

## 모델 호환성과 실행 수명

- Gemini 3.5 Flash-Lite, Vertex AI, NVIDIA NIM의 요청 형식과 구조화 응답 처리를 각 공급자의 규격에 맞게 수정했습니다.
- Ollama Cloud는 구조화된 `items`·`labels` 응답을 직접 요청하고 검증하며, 번역 결과 자리에 일본어 원문이 반환되는 문제를 수정했습니다.
- 로컬 Ollama 모델은 번역·OCR·효과음·인터넷 조사·연결 테스트 작업이 끝나면 실제 사용한 모델만 메모리에서 내립니다. Ollama Cloud에는 언로드 요청을 보내지 않습니다.

## 텍스트 편집

- 번역문을 한글 IME로 직접 편집할 때 조합 중인 초성·중성·종성이 반복 입력되던 문제를 수정했습니다.
- 텍스트 편집 중 커서가 보이지 않던 문제를 수정하고, 편집 종료 시 조합 상태와 예약된 갱신 작업을 정리하도록 보강했습니다.
