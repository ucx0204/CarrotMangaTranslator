# v1.4.0 패치노트

기준 범위: `v1.3.1` 이후부터 `v1.4.0`까지의 변경 사항입니다.
주요 포함 변경: 텍스트 블록 360° 회전과 정밀 크기 조절, 네 모서리 원근 변형, 곡선을 따라 배치하는 효과음 텍스트와 v1.4.0 릴리즈 준비 변경.

## 새 기능 및 개선

### 텍스트 블록 360° 회전과 정밀 크기 조절

- 텍스트 블록을 원하는 각도로 자유롭게 회전할 수 있으며, 캔버스의 회전 손잡이와 오른쪽 패널의 슬라이더·숫자 입력을 함께 지원합니다.
- 블록의 여덟 방향 크기 조절 손잡이가 회전된 블록의 방향을 기준으로 움직여, 기울어진 텍스트도 자연스럽게 크기를 조절할 수 있습니다.
- 모서리를 드래그할 때 `Shift`를 누르면 가로세로 비율을 유지하고, 회전 중에는 15° 단위로 각도를 맞출 수 있습니다.
- X, Y, 너비와 높이를 직접 입력하고 비율 유지 여부를 선택할 수 있어 마우스 조작과 정밀 입력을 필요에 따라 함께 사용할 수 있습니다.

### 네 모서리 원근 변형

- 캔버스 작업 막대와 변형 패널에 원근 도구를 추가해 텍스트를 간판, 벽면과 기울어진 말풍선의 면에 맞출 수 있습니다.
- 네 모서리와 각 변의 손잡이를 직접 움직여 사각형의 원근을 조절하고, 필요하면 각 꼭짓점 좌표를 숫자로 입력할 수 있습니다.
- 위쪽·아래쪽·왼쪽·오른쪽 좁게와 좌우 평행사변형 프리셋으로 자주 쓰는 형태를 빠르게 적용할 수 있습니다.
- 회전과 원근을 한 블록에 함께 적용할 수 있으며 편집 화면과 PNG 내보내기에서 같은 결과를 유지합니다.

### 곡선을 따라 배치하는 효과음 텍스트

- 가로쓰기 한 줄 텍스트를 곡선으로 변환해 만화 효과음을 둥근 움직임이나 충격선의 흐름에 맞춰 배치할 수 있습니다.
- 곡선의 양 끝점으로 길이와 방향을 정하고 가운데 굽힘점으로 휘어짐을 캔버스에서 바로 조절합니다.
- 직선, 위로 휘기와 아래로 휘기 프리셋을 제공하며 휘어짐, 경로 위치, 시작·가운데·끝 정렬과 글자 방향을 세밀하게 조절할 수 있습니다.
- 경로 방향 뒤집기, 글자를 똑바로 세우기와 경로 길이에 맞춘 자간 조절을 지원합니다.
- 기존 폰트, 글자 크기, 장평, 자간, 굵게·기울임, 색상과 외곽선 서식을 곡선 위의 글자에도 그대로 적용합니다.

## 사용성 개선

### 처음 사용해도 흐름을 알 수 있는 고밀도 변형 패널

- 변형 기능을 `선택`, `원근`, `곡선` 세 탭으로 나누고 현재 필요한 조작만 표시해 복잡한 기능을 한꺼번에 마주치지 않도록 했습니다.
- 사용 중, 사용 안 함과 일시 중지 상태를 표시하고 각 도구 아래에 손잡이 사용법과 취소 방법을 짧게 안내합니다.
- 숫자 입력, 프리셋과 초기화 작업을 좁은 간격과 2열 배치로 정리해 패널을 불필요하게 크게 차지하지 않도록 했습니다.
- 숫자를 입력하는 도중 `Enter`로 적용하고 `Esc`로 이전 값으로 돌아갈 수 있으며, 값이 바뀌지 않은 입력은 실행 취소 기록을 만들지 않습니다.
- 넓은 화면과 좁은 화면 모두에서 변형 설정이 잘리거나 가로로 넘치지 않도록 반응형 배치를 다듬었습니다.

### 캔버스 조작 안내와 오류 피드백

- 크기, 회전 각도와 맞춤 상태를 조작 위치 가까이에 표시해 드래그 결과를 바로 확인할 수 있습니다.
- 원근 꼭짓점이 교차하거나 지나치게 가까워지는 경우와 변형 결과가 페이지 밖으로 완전히 나가는 경우에는 변경을 적용하지 않고 이유를 안내합니다.
- 곡선보다 글자가 길면 넘치는 길이를 표시하고, 가능한 경우 자간 맞추기와 글자 크기 줄이기 작업을 바로 제안합니다.
- 세로쓰기 또는 여러 줄 텍스트에서는 곡선을 일시 중지하고 이유를 표시하며, 조건을 다시 만족하면 기존 곡선 설정을 복원합니다.
- 드래그 중 `Esc`를 누르면 시작 상태로 돌아가고, 페이지가 바뀔 때 진행 중인 조작이 다음 페이지에 잘못 적용되지 않도록 했습니다.

## 성능 및 안정성 개선

### 편집·저장·내보내기의 변형 결과 통일

- 회전, 원근과 곡선 설정을 작품 데이터와 자동 저장 IPC 스키마에 연결해 앱을 다시 열어도 그대로 유지합니다.
- 열린 편집 패널에도 현재 변형 모드와 페이지 크기를 동기화하고, 이미 선택이 바뀐 블록을 대상으로 도착한 오래된 명령은 적용하지 않습니다.
- PNG 내보내기에서 회전, 원근과 곡선을 편집 화면과 같은 순서로 합성하며 편집용 손잡이와 안내선은 결과에 포함하지 않습니다.
- 곡선의 실제 길이와 각 글자의 너비를 계산해 글자를 배치하고, 장평·자간·경로 반전과 접선 방향을 함께 반영합니다.
- 곡선을 사용할 수 없는 세로쓰기와 여러 줄 텍스트는 설정을 삭제하지 않은 채 일반 텍스트 방식으로 안전하게 내보냅니다.

### 잘못된 변형 데이터 방지

- 교차·축소·뒤집힘·오목한 형태처럼 안전하게 렌더링할 수 없는 원근 사각형을 저장과 불러오기 단계에서도 거부합니다.
- 지나치게 짧은 곡선과 허용 범위를 벗어난 좌표·각도를 검증하고 정규화해 잘못된 변형 데이터가 렌더링을 중단하지 않도록 했습니다.
- 원근과 곡선의 공용 계산을 편집 화면, 저장 스키마와 내보내기가 함께 사용하도록 정리해 결과 차이를 줄였습니다.

## 내부 정리 및 테스트

- 회전된 블록의 여덟 방향 크기 조절, 비율 유지, 각도 맞춤, 취소와 단일 실행 취소 기록을 테스트로 검증합니다.
- 원근 행렬, 프리셋, 꼭짓점·변 손잡이, 잘못된 사각형 거부와 페이지 바깥 이동 방지를 회귀 테스트로 고정했습니다.
- 곡선 길이 계산, 글자별 배치, 정렬·반전·자간 맞춤, 넘침 안내와 지원하지 않는 텍스트의 안전한 대체 렌더링을 검증합니다.
- 저장 IPC, 편집 패널 동기화와 일반·회전·원근·곡선 텍스트의 PNG 내보내기 결과를 테스트합니다.
- 회전·원근·곡선 UI 안내를 한국어, 영어, 일본어, 중국어 간체와 번체에 추가했습니다.
