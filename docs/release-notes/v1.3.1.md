# v1.3.1 패치노트

기준 범위: `v1.3.0` 이후부터 `v1.3.1`까지의 변경 사항입니다.
주요 포함 변경: 대형 작품의 페이지 미리보기 지연 로딩, 페이지 수 제한 없이 유지되는 안전한 이미지 주소, 실제 파일 형식 기반 이미지 가져오기와 v1.3.1 릴리즈 준비 변경.

## 사용성 개선

### 페이지가 많은 작품의 미리보기 개선

- 페이지 선택 화면에서 현재 보이는 영역과 가까운 미리보기만 불러오도록 변경해 수백·수천 페이지가 있는 작품도 더 가볍게 열 수 있습니다.
- 아직 불러오지 않은 이미지는 기존 자리 표시자로 유지하고, 화면에 가까워졌을 때 자동으로 불러옵니다.
- 이미지 표시가 실패하면 주소를 한 번 다시 요청해 재시도하며, 이후에도 실패하면 `미리보기 실패` 상태를 분명하게 표시합니다.
- 페이지 이미지가 바뀌는 도중 이전 요청이 늦게 끝나도 새 이미지 미리보기를 덮어쓰지 않도록 했습니다.

## 성능 및 안정성 개선

### 페이지 수 제한 없이 유지되는 이미지 주소

- 메모리에 최대 500개만 보관하던 임시 이미지 주소를 파일 정보로 서명한 상태 비저장 주소로 교체했습니다.
- 2,000페이지처럼 큰 작품에서도 먼저 발급한 미리보기 주소가 뒤의 페이지 때문에 사라지지 않습니다.
- 이미지의 크기와 수정 시각을 주소에 포함해 파일이 교체되거나 삭제된 경우 오래된 주소를 안전하게 무효화합니다.
- 주소 변조, 경로 이탈과 보관함 밖을 가리키는 정션·심볼릭 링크를 차단하고, 보관함 안의 지원 이미지 파일만 제공합니다.

### 확장자가 잘못된 WebP 이미지 가져오기 수정

- 일반 이미지 파일과 ZIP 항목을 가져올 때 확장자만 믿지 않고 JPEG, PNG와 WebP의 실제 파일 서명을 확인합니다.
- WebP 내용이 `.jpg` 같은 다른 확장자로 저장된 경우에도 올바르게 감지해 PNG로 변환하고 보관함에 저장합니다.
- 변환 후에도 페이지 목록에는 사용자가 가져온 원래 파일 이름을 유지합니다.
- 파일 형식 판별 과정에서도 기존 파일 크기 제한과 ZIP 항목 안전 제한을 그대로 적용합니다.

## 내부 정리 및 테스트

- 2,000개의 이미지 주소를 반복 발급해도 모두 유효한지, 파일 교체·삭제와 주소 변조가 안전하게 처리되는지 테스트합니다.
- 보관함 밖 경로, 경로 순회, 정션 이탈, 지원하지 않는 파일과 일반 파일이 아닌 경로를 이미지 프로토콜에서 거부하는지 검증합니다.
- 2,000페이지 선택 화면에서 교차 영역에 들어온 미리보기만 요청하는지와 로드·재시도·실패·늦은 응답 상태를 컴포넌트 테스트로 고정했습니다.
- 600개 이미지가 포함된 ZIP을 실제 이미지 디코딩 없이 자연 정렬 순서로 미리 볼 수 있는지 검증합니다.
- JPEG, PNG와 WebP 서명 판별 및 확장자가 잘못된 일반 파일·ZIP 항목 가져오기를 회귀 테스트로 추가했습니다.
- 미리보기 실패 안내를 한국어, 영어, 일본어, 중국어 간체와 번체에 추가했습니다.
