# v3.8.6

번역 중 편집 저장 대기가 풀리지 않던 문제를 수정하고, 연결된 출력 폴더가 있는 보관함의 반복 시작 검사를 개선했습니다.

## 번역 중 편집 저장 대기 복구

- 앱이 바빠 저장 응답이 늦게 도착해도 완료를 확인한 뒤 편집 상태를 다시 점검하고 번역을 이어갑니다.
- 창 밖에서 마우스를 놓거나 다른 창으로 이동했을 때 포인터 입력이 계속 진행 중인 것으로 남는 문제를 수정했습니다. 한글 등 조합 입력과 이미지 저장은 완료를 기다립니다.
- 여러 페이지의 작업 예약 상태를 한 번에 전달해 대량 번역을 시작할 때 불필요한 화면 통신을 줄였습니다.
- 저장 대기의 단계·소요 시간과 느린 화면 프레임을 진단 로그에 남겨 멈춤 원인을 확인하기 쉽게 했습니다.

## 시작 검사와 개발 실행

- 연결된 출력 폴더의 파일과 연결 상태가 그대로이고 대기 작업이 없으면 이전 시작 검사 결과를 재사용합니다. 파일 변경·누락, 복구 작업 또는 캐시 오류가 있으면 전체 검사를 수행합니다.
- 개발 실행의 파일 해시 캐시와 Electron 메인 번들로 반복 실행 준비 시간을 줄였습니다. 배포 빌드의 파일 검증과 모듈 출력 방식은 유지합니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.6.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.6-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
