# v2.6.3

## 내보내기

- 이미지·PSD 내보내기의 페이지 수 제한을 2,000장에서 **5,000장**으로 늘렸습니다. 내보내기 전 검사와 실제 실행에 같은 제한을 적용합니다. [#92](https://github.com/ucx0204/CarrotMangaTranslator/issues/92)

## CPU OCR·폰트 자동 맞춤

- CPU에서 폰트를 자동 분석할 때 OCR 모델을 재사용하고 독립된 페이지를 병렬 처리해 반복 준비 비용을 줄였습니다. OCR 입력, 모델과 폰트 선택 알고리즘은 유지합니다.
- Windows의 CPU OCR 작업량을 CPU 수와 여유 메모리에 맞춰 조절합니다. 짧은 작업에서는 모델 시작 비용을 줄이고, 큰 작업에서는 최대 8개 워커를 사용합니다.
- Windows CPU OCR 프로세스의 실행 우선순위를 낮춰 다른 작업에 미치는 영향을 줄였습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다.
- Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다.
