# v1.8.0 패치노트

기준 범위: `v1.7.0` 이후부터 `v1.8.0`까지의 변경 사항입니다.
주요 포함 변경: 휠 조합을 지원하는 이미지 확대·축소 단축키, 원본만 보는 비교 토글, 사각형·원형 리터치 도구, 키보드 텍스트 블록 이동과 색상 스왑.

## 이미지 보기와 원본 비교

### 확대·축소 휠 단축키

- 이미지 확대와 축소를 마우스 휠 위·아래에 직접 지정할 수 있습니다.
- 일반 휠뿐 아니라 `Ctrl`, `Alt`, `Shift`와 휠을 조합한 입력도 각각 단축키로 등록할 수 있습니다.
- 페이지 이동 단축키와 같은 설정 방식으로 동작하며, 등록된 조합은 작업 화면에서 이미지 배율만 변경합니다.
- 휠 입력을 캡처할 때 실제 방향과 보조 키 조합을 표시해 원하는 동작을 바로 확인할 수 있습니다.

### 한 번에 전환하는 원본 비교

- `원본과 비교`를 누르면 작업 중인 텍스트 블록, 리터치 마스크·미리보기와 선택 표시를 자동으로 숨기고 원본 이미지만 표시합니다.
- 버튼을 다시 누르면 비교하기 전의 텍스트 블록, 선택 상태와 편집 화면으로 그대로 돌아옵니다.
- 비교 중에는 붓·도형·마스크를 비롯한 포인터 편집을 잠시 막아 원본을 보면서 처리본이 실수로 바뀌지 않습니다.
- 원본과 번역 블록이 겹쳐 보이던 기존 비교 방식을 수정해 원본 자체를 방해 없이 확인할 수 있습니다.

## 더 빠른 리터치 작업

### 사각형·원형 덮기 도구

- 기존 붓에 더해 채워진 `사각형`과 `원형` 리터치 도구를 추가했습니다.
- 시작점부터 끝점까지 한 번 드래그하면 넓은 영역을 선택한 색으로 바로 덮을 수 있습니다.
- 드래그 중 실제 적용 범위를 미리 표시하며, 이미지 경계를 벗어난 도형은 안전하게 잘라서 처리합니다.
- 도형 리터치도 기존 이미지 작업 기록에 포함되어 실행 취소와 다시 실행을 사용할 수 있습니다.

### 알아보기 쉬운 색상 선택

- 붓·사각형·원형의 색상 입력을 큰 색상 견본과 대문자 HEX 값으로 정리했습니다.
- 색상 영역 안의 불필요한 팔레트 아이콘과 중복 도구 이름을 제거해 현재 색을 바로 구분할 수 있습니다.
- 좁은 편집 패널에서도 색상 견본과 `#FFFFFF` 형식의 값이 잘리거나 겹치지 않습니다.

## 텍스트 블록 키보드 편집

### 방향키 이동과 자연스러운 가속

- 선택한 텍스트 블록을 키보드 방향키로 이동할 수 있습니다.
- 두 방향키를 함께 누르면 속도를 과도하게 높이지 않고 자연스럽게 대각선으로 이동합니다.
- 짧게 한 번 누르면 정확히 이미지 기준 `1px`만 이동하며, `300ms` 이상 계속 누른 뒤에만 반복 이동을 시작합니다.
- 길게 누르는 동안에는 `1px`에서 최대 `8px`까지 부드럽게 빨라지고, `Shift`와 방향키를 함께 누르면 고정 `10px`씩 이동합니다.
- 여러 블록을 선택한 경우 간격을 유지한 하나의 그룹으로 움직이며 페이지 경계를 넘지 않습니다.
- 텍스트 입력이나 다른 편집 컨트롤에 초점이 있을 때는 방향키 입력을 가로채지 않습니다.

### 글자색·외곽선색 스왑

- 한 번의 버튼 클릭으로 선택 블록의 글자색과 외곽선색을 서로 바꿀 수 있습니다.
- 검은 글자·흰 외곽선을 흰 글자·검은 외곽선으로 전환하는 자주 쓰는 작업을 색상 값을 다시 입력하지 않고 처리합니다.

## 편집 안정성과 성능

- 키보드 이동은 운영체제의 키 반복 속도 대신 앱이 관리하는 단일 입력 주기를 사용해 방향 전환과 대각선 이동이 일정하게 이어집니다.
- 리터치 미리보기와 실제 적용이 같은 도형 계산을 사용하도록 통합해 드래그 중 보이는 범위와 결과의 차이를 줄였습니다.
- 개발 중 컴포넌트 갱신에서도 키보드 이동 상태의 Hook 구성이 바뀌지 않도록 정리해 편집 화면 오류를 방지했습니다.
- 개발 빌드 캐시가 런타임 자산을 잘못 재사용하지 않도록 제외 규칙을 보강했습니다.

- Vitest 전체 252개 파일, 1,625개 테스트 통과·2개 건너뜀

- 프로덕션 컴포넌트를 사용한 1440×900 및 900×700 Chromium UI QA에서 색상 입력의 잘림, 겹침과 가로 넘침 확인
- 실제 앱을 1280×800 크기로 새로 실행해 편집 화면의 렌더러 오류가 없는 것을 확인
- `git diff --check` 통과
