# v2.8.2 — 기존 블록 OCR 오류 수정과 백업 개선

## 기존 블록 유지 및 Windows 긴 경로

- Windows에서 **기존 블록 유지**로 번역·재번역할 때, 깊게 중첩된 OCR 작업 경로를 읽지 못해 실패하는 문제를 수정했습니다. 긴 경로 지원이 꺼진 환경에서도 OCR 입력과 결과·진행 로그를 처리합니다. ([#128](https://github.com/ucx0204/CarrotMangaTranslator/issues/128))
- Windows 설치·업데이트 시 긴 경로 지원을 자동 활성화합니다. 설정 변경이 제한된 PC에서도 OCR 자체의 긴 경로 처리는 유지됩니다. 앱의 실행 권한은 기존과 같습니다.

## 백업 및 복원

- 백업 복사·검증·압축 단계의 진행률을 처리한 데이터 크기로 표시해 대용량 백업의 진행 상태를 확인하기 쉽게 했습니다.
- 가져온 백업의 복원 확인을 별도 대화상자로 표시하고, 아직 현재 보관함에 적용되지 않았다는 안내와 복원 후 재시작 동작을 명확히 했습니다.
- 보관함 요약 정보를 불러오는 중에도 백업 내보내기를 시작할 수 있습니다.
- 백업 압축 취소 시 읽기 스트림을 정리한 뒤 임시 파일을 제거하도록 보완했습니다.
- 개발 실행 중 환경 복원 후 앱을 재시작할 때 개발 서버를 유지하도록 수정했습니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
