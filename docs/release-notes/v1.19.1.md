# v1.19.1 패치노트

기준 범위: `v1.19.0` 태그(`f5716062`)와 이번 `v1.19.1` 최종 트리를 직접 비교했습니다. 중간 실험이 아니라 두 최종 트리에 실제로 남은 차이만 기록했습니다.

v1.19.1은 전용 VRAM 8GB 환경에서 Gemma 12B 번역 엔진의 GPU 배치를 개선하고, 사용자가 VRAM 여유량과 이미지 프로젝터 배치를 직접 조절할 수 있게 한 성능·안정성 패치입니다.

## Gemma GPU 메모리 설정

- 전용 VRAM이 8GB 이하인 Windows GPU에서는 최초 설정과 `기본값 복원` 시 `여유 VRAM 512MiB`와 `이미지 프로젝터 CPU`를 기본으로 사용합니다. 8GB를 초과하는 GPU와 VRAM 용량을 확인할 수 없는 환경은 기존 기본값인 1,024MiB와 GPU 배치를 유지합니다.
- 번역 엔진 설정에 `여유 VRAM` 드롭다운과 `이미지 프로젝터`의 GPU·CPU 선택을 추가했습니다. 앱의 기존 드롭다운과 같은 조작 방식을 사용하며, 설정 화면을 중첩 카드 없이 평평하게 구성했습니다.
- 여유 VRAM을 낮추면 모델을 GPU에 더 많이 배치해 번역이 빨라질 수 있고, 높이면 다른 GPU 프로그램과 함께 사용할 공간을 더 남기는 대신 번역이 느려질 수 있다는 동작을 설정 화면에서 안내합니다.
- 이미지 프로젝터를 CPU로 옮기거나 KV 캐시 CPU 배치를 선택하면 호환되지 않는 MTP 초안 모델을 자동으로 비활성화합니다. 이 설정은 사용자가 지정한 컨텍스트 길이와 ubatch를 변경하지 않습니다.
- 저장된 사용자 설정은 다음 실행에도 유지되며, 이전 버전 설정에 새 항목이 없거나 값이 잘못된 경우에만 현재 GPU에 맞는 기본값으로 보완합니다.

## 컨텍스트·벤치마크 안정성

- 자동 GPU 배치가 메모리를 맞추는 과정에서 요청한 컨텍스트 길이를 몰래 줄이지 못하도록, 설정된 컨텍스트 길이를 필수값으로 전달합니다. 메모리가 부족하면 컨텍스트를 축소하는 대신 GPU 레이어 배치를 조절합니다.
- Gemma 후보 벤치마크 결과에 번역 서버와 모델이 준비될 때까지의 로드 시간을 별도로 기록합니다. 연속 페이지 처리 시간, 토큰 속도, VRAM 측정과 함께 초기 로드 비용도 비교할 수 있습니다.
- 런타임 인자, GPU별 기본값, 설정 저장·복원, MTP 비활성화와 폼 왕복을 자동 테스트로 고정했습니다.

## 호환성 참고

- 지원 운영체제는 Windows 10/11과 Apple Silicon macOS 14+로 v1.19.0과 같습니다.
- Apple Silicon의 통합 메모리는 전용 VRAM 8GB 규칙을 적용하지 않으며 기존 Metal 메모리 기본값을 유지합니다.
