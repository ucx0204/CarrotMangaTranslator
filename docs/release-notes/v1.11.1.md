# v1.11.1 패치노트

기준 범위: `v1.11.0` 이후부터 `v1.11.1`까지의 변경 사항입니다.

v1.11.1은 자동 생성된 번역 블록을 옮긴 뒤 인페인팅이 이전 위치를 지우던 문제를 수정한 패치 릴리즈입니다.

## 자동 블록 이동과 인페인팅 위치 수정

- 자동 생성 블록을 마우스로 이동하면 원문 검출 영역인 `bbox`와 번역문 표시 영역인 `renderBbox`가 정확히 같은 거리만큼 함께 이동합니다.
- 방향키로 블록을 미세 이동하거나 여러 블록을 함께 이동하는 경로에도 같은 좌표 규칙을 적용했습니다.
- 페이지 가장자리에서는 두 영역 중 먼저 경계에 닿는 쪽을 기준으로 공통 이동량을 제한합니다. 한쪽 좌표만 따로 보정되어 두 영역의 상대 위치가 틀어지지 않습니다.
- 자동 블록을 이동한 뒤 인페인팅하면 이전 원문 좌표가 아니라 이동된 현재 좌표에 마스크가 생성됩니다.
- 블록 크기 조절은 기존 동작을 유지합니다. 번역문 배치 크기만 조절하며 원문 인페인팅 영역의 크기는 임의로 바꾸지 않습니다.
- `renderBbox`가 없는 수동 생성 블록의 이동 동작도 기존과 동일하게 유지됩니다.

## 검증

- 마우스 포인터 이동, 방향키 이동, 다중 선택 이동, 페이지 경계 보정 회귀 테스트 추가
- 이동 후 이전 위치에는 마스크가 남지 않고 새 위치에 인페인팅 마스크가 생성되는 회귀 테스트 추가
- 넓은 화면과 좁은 화면에서 실제 프로덕션 블록 렌더링을 사용한 이동 전·후 UI 캡처 검증 통과
- TypeScript 타입 검사, ESLint, Vitest 전체 회귀 테스트, 프로덕션 빌드 검증

## 업그레이드 안내

- 기존 작품과 설정은 그대로 유지됩니다.
- 업데이트 후 자동 생성 블록을 새 위치로 옮기면 원문 인페인팅 영역도 같은 이동량으로 함께 이동합니다.
