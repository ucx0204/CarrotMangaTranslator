# v1.6.1 패치노트

기준 범위: `v1.6.0` 이후부터 `v1.6.1`까지의 변경 사항입니다.
주요 포함 변경: Windows 설치 진행 로그 표시, 설치 파일 압축 해제 경로 최적화, 불필요한 패키지와 중복 런타임 제거 및 패키징 회귀 방지.

## 설치 사용성 개선

### 설치 중인 작업을 바로 확인

- 설치 진행 화면의 상세 정보 영역을 기본으로 펼쳐 두어 빈 화면처럼 보이지 않도록 했습니다.
- `설치 준비`, `프로그램 파일 압축 해제`, `데이터 저장 위치 적용`, `바로가기와 설치 정보 등록`, `설치 설정 마무리`처럼 현재 작업 단계를 순서대로 표시합니다.
- 일반 설치 파일 안에는 앱 본체가 이미 들어 있으므로 설치 중에는 앱을 인터넷에서 다시 다운로드하지 않습니다. 모델, OCR 및 일부 인페인팅 런타임은 앱에서 해당 기능을 처음 준비할 때 별도로 다운로드됩니다.
- 파일 하나하나를 출력하면 대용량 압축 해제가 다시 느려질 수 있어, 상세 영역에는 성능 부담이 작은 단계 로그를 표시합니다.

## 설치 성능 개선

### 임시 폴더 전체 복사 제거

- 앱 전체를 임시 폴더에 먼저 압축 해제한 뒤 설치 폴더로 다시 복사하던 경로를 제거했습니다.
- 빠른 Deflate ZIP을 설치 폴더에 직접 압축 해제해 대용량 앱 본체를 두 번 기록하지 않습니다.
- 이 앱은 GitHub Releases를 직접 여는 수동 업데이트 방식을 사용하므로, 설치가 끝난 뒤 설치 파일 전체를 electron-updater 캐시에 한 번 더 복사하던 작업도 제거했습니다.
- 공개 설치 파일의 통제된 압축 해제 검사에서 170개 파일, 658.4MiB 페이로드를 3.135초에 처리했습니다. 실제 설치 시간은 저장장치, Windows Defender와 다른 백신의 실시간 검사 상태에 따라 달라질 수 있습니다.

### 설치 대상 정리

- OpenAI Codex OAuth 런타임을 하나의 검증된 ESM 파일로 묶어, 수천 개의 Node.js 파일을 ASAR 밖에 따로 기록하지 않도록 했습니다.
- React, 아이콘, 드래그 UI처럼 렌더러 번들에 이미 들어간 라이브러리 원본을 설치판에 중복 포함하지 않습니다.
- 로컬에서 생성된 런타임 복사본, 개발 문서와 설정 파일을 설치판에서 제외했습니다.
- 앱이 지원하는 한국어, 영어, 일본어, 중국어 간체·번체용 Electron 언어팩만 포함합니다.
- 공개 Windows 패키지는 170개 파일과 658.4MiB이며, 설치 파일은 289.6MiB입니다.

## 안정성 및 재발 방지

- electron-builder의 NSIS 템플릿을 빌드할 때 필요한 지점만 엄격하게 패치합니다. 업스트림 템플릿이 바뀌면 잘못된 설치 파일을 만들지 않고 빌드 단계에서 즉시 실패합니다.
- 설치 상세 로그, 직접 ZIP 압축 해제와 불필요한 캐시 복사 제거가 실제 NSIS 템플릿에 적용되는지 테스트합니다.
- 패키지 파일 수와 전체 크기 예산, 허용 Electron 언어팩을 릴리스 빌드에서 검사해 중복 파일이나 불필요한 런타임이 다시 포함되지 않도록 했습니다.
- 패키지된 Electron 실행 파일과 `app.asar` 안의 실제 동적 import 보호 경로로 Codex OAuth 번들을 불러온 뒤, 로컬 서버를 실제로 시작하고 종료하는 smoke test를 추가했습니다.
- 대용량 ZIP의 파일별 로그가 압축 해제를 느리게 만들 수 있다는 NSIS 권고에 따라, 빠른 `Unzip` 경로와 읽기 쉬운 단계 로그를 함께 유지합니다.
