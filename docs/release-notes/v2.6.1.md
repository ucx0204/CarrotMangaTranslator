# v2.6.1

## SFX 자동 번역

- SFX 자동 번역의 이미지 판독·번역 지침을 영역 번역과 통일했습니다. 확대된 효과음 영역을 먼저 읽고, 전체 페이지와 용어·스토리 메모리를 번역 문맥으로 사용합니다.
- 일부 페이지만 선택하거나 순서를 바꿔 번역할 때 이전 페이지의 스토리 메모리가 빠지거나 잘못 선택되던 문제를 수정했습니다.
- 특정 단어 조합이나 OCR 참고문과의 차이만으로 번역을 거절하던 규칙을 제거했습니다. 이미지에서 읽은 원문을 우선하며, 비어 있거나 잘못된 형식의 결과는 다시 확인합니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다.
- Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다.
