# v1.1.0 패치노트

기준 범위: `v1.0.0` 이후부터 `v1.1.0`까지의 변경 사항입니다.
주요 포함 변경: 번역·인페인팅 작업 화면 통합, 화·페이지 선택형 자동 지우기, 작품 전체 PNG 출력, 보정 입력 성능 개선 및 v1.1.0 릴리즈 준비 변경.

## 새 기능 및 개선

### 번역과 인페인팅을 하나의 작업 화면으로 통합

- 별도 인페인팅 화면과 전역 모드를 제거해, 왼쪽 보관함과 중앙 캔버스를 유지한 채 번역과 이미지 보정을 바로 오갈 수 있습니다.
- 캔버스 도구막대를 `선택`, `블록 추가`, `손`, `마스크`, `브러시`, `지우개`, `색 추출` 도구로 통합하고 한 번에 하나의 도구만 활성화되도록 정리했습니다.
- 오른쪽 상단에 `번역`, `자동 지우기`, `PNG 출력`을 항상 표시하고, 오른쪽 아래에는 현재 도구와 선택 상태에 필요한 설정 하나만 문맥에 맞게 표시합니다.
- 자동 지우기 패널을 열었을 때만 인페인팅 제외 블록을 표시하며, 원본 비교, 되돌리기, 가이드와 보정 설정을 더 짧은 동선으로 사용할 수 있습니다.

### 화·페이지 선택형 자동 지우기

- 자동 지우기를 누르면 번역 선택 화면과 같은 방식의 모달에서 현재 작품의 화와 페이지를 직접 선택할 수 있습니다.
- 현재 페이지를 기본으로 선택하며 `현재 화`, `전체 선택`, `전체 해제` 빠른 선택과 화별 펼치기, 페이지 썸네일 선택을 지원합니다.
- 다른 화의 페이지와 썸네일은 필요할 때 불러오고, 보관함 순서대로 선택 페이지를 처리합니다.
- 여러 화를 한 번에 처리할 때 인페인팅 엔진을 작업 전체에서 재사용하고, 선택한 전체 페이지 수를 기준으로 통합 진행률과 취소 상태를 표시합니다.

### 작품 전체 PNG 출력

- 현재 페이지뿐 아니라 현재 작품의 모든 화를 펼쳐 페이지 단위로 최종 이미지를 선택해 출력할 수 있습니다.
- 출력 시작 시 Windows 폴더 선택창을 열며, 취소하면 선택 모달을 그대로 유지하고 작업을 시작하지 않습니다.
- 인페인팅 결과가 있는 페이지는 보정 이미지를 사용하고, 결과가 없는 페이지는 원본 이미지에 현재 번역 블록을 합성합니다.
- 화와 페이지를 보관함 순서로 정렬하고 일부 페이지만 선택해도 원래 페이지 번호를 유지합니다.
- 선택한 폴더 아래에 `<작품명>-<타임스탬프>/<화 번호>-<화명>/<페이지 번호>-<원본파일명>.png` 구조로 저장하고 완료 후 결과 폴더를 엽니다.

### 읽기 쉬운 도구 아이콘과 도움말

- 캔버스 도구막대 아이콘을 MIT 라이선스의 Tabler Icons로 교체해 선택, 이동, 보정 도구를 더 쉽게 구분할 수 있습니다.
- 운영체제 기본 툴팁 대신 지연 표시와 이동·페이드 애니메이션이 적용된 앱 전용 툴팁을 추가했습니다.
- 활성 보정 도구와 실제 브러시 크기를 작은 캔버스 배지와 반경 커서로 표시합니다.

## 성능 및 안정성 개선

### 마스크·브러시·지우개 포인터 지연 제거

- 포인터 이동 좌표와 누적 미리보기를 최상위 React 상태에서 분리해, 마우스를 움직일 때 사이드바, 번역 블록, 오른쪽 패널 전체가 다시 렌더되던 병목을 제거했습니다.
- 커서는 캐시된 이미지 좌표와 `requestAnimationFrame`, GPU 합성 가능한 `translate3d`를 사용해 화면 프레임당 한 번만 갱신합니다.
- 누적 SVG 경로를 매번 처음부터 만들던 방식을 증분 Canvas 렌더링으로 교체해, 마스크 붓, 보정 브러시, 보정 지우개가 긴 스트로크에서도 가볍게 따라오도록 개선했습니다.
- 고주사율 포인터 입력은 화면 갱신만 묶고 실제 입력 점은 모두 보존하며, 보정 적용과 마스크 저장은 포인터를 놓을 때 한 번만 실행합니다.

### 저장되지 않은 편집과 작업 전환 보호

- 자동 지우기, 보정 적용, 실행 취소·다시 실행, 되돌리기, PNG 출력 전에 저장되지 않은 번역 편집을 먼저 저장하고, 저장 실패 시 후속 작업을 중단합니다.
- 미실행 마스크가 있는 상태에서 페이지나 화를 바꾸면 폐기 여부를 확인하며, 페이지 변경, 작업 시작, `Esc` 입력 시 선택 도구로 안전하게 복귀합니다.
- 보정 작업 중에는 추가 입력을 막아 적용 중인 스트로크가 조용히 유실되지 않도록 했습니다.
- `Ctrl+Z`는 보정 도구가 활성화된 동안 보정 기록에, 그 밖의 경우에는 번역 편집 기록에 적용합니다.

### 인페인팅 엔진과 출력 작업 수명 정리

- 인페인팅 엔진을 화면 모드가 아니라 실제 작업 수명에 연결해 반복 보정에서는 재사용하고, 번역 작업 전과 앱 종료 시 안전하게 해제합니다.
- 출력 요청에서 작품·화·페이지 소속, 빈 선택, 중복 ID를 검증하고 전체 선택 수를 기준으로 진행률과 취소 상태를 보고합니다.
- 출력 취소나 실패 시 미완성 결과 폴더를 정리하며, 마지막 페이지 처리 중 취소도 놓치지 않도록 검사 지점을 보강했습니다.
- 출력 완료 후 폴더 열기에만 실패한 경우 이미지 출력 성공 결과는 유지하고 별도의 열기 오류로 안내합니다.

## 내부 정리 및 테스트

- 번역과 출력에서 함께 사용할 수 있는 공용 작품·화·페이지 선택기를 추가하고, 자동 지우기와 출력에는 각각 안전한 선택 타입과 IPC 검증을 적용했습니다.
- 별도 인페인팅 화면, 단계 전환 컴포넌트와 전역 세션 Provider를 제거해 작업 상태와 도구 소유권을 단순화했습니다.
- 도구 상호 배타성, 페이지·화 전환, 단축키 소유권, 자동 지우기 선택, 다중 화 출력, 정렬, 진행률, 취소와 실패 처리를 회귀 테스트로 고정했습니다.
- 포인터 연속 입력이 React 재렌더를 만들지 않고, 레이아웃 측정과 화면 갱신이 프레임 단위로 제한되는지 성능 회귀 테스트를 추가했습니다.
