# v3.8.10

폰트 자동 맞춤의 글자 검증 모델 다운로드 경로를 복구하고, 다운로드 이후 실제 분석 상태를 표시하도록 수정했습니다. ([#179](https://github.com/ucx0204/CarrotMangaTranslator/issues/179))

## 폰트 자동 맞춤 복구

- 원본 배포처에서 받을 수 없어진 CPU 글자 검증 모델과 사전을 별도 GitHub 자산 릴리스로 복구했습니다. 기존에 검증한 모델과 동일한 파일을 사용하며, 다운로드 시 크기와 SHA-256을 확인합니다.
- 폰트 분석이 시작되면 다운로드 용량·파일명 표시를 분석 상태로 전환합니다.
- 선택적 가속 모델을 준비하지 못한 경우 **기본 방식으로 폰트 분석 중**이라고 안내하고, 분석 시간이 더 걸릴 수 있음을 표시합니다.
- 기존 폰트 선택·글자 검증 알고리즘과 GPU 분석 경로, 사용자 보관함·원본·출력물은 유지합니다.

## 검증 범위

- 게시된 모델·사전·manifest를 다시 다운로드해 파일명·크기·SHA-256을 대조했습니다.
- 빈 캐시에서 실제 앱 다운로더로 설치하고, CPU 로드·추론 및 기존 모델과의 결과 일치를 확인했습니다.
- 정상 설치, 실패 시 기본 분석 전환, GPU 경로, 취소, 진행 상태와 다국어 문구를 테스트했습니다.
- 실제 작업 센터를 넓은 화면과 좁은 화면에서 확인했습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.10.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.10-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
