# v2.3.1 패치노트

## 번역 블록 복구

- 번역 결과에서 비어 있거나 형식·번역 언어 검사를 통과하지 못한 고정 블록이 있으면 정상 블록은 그대로 보존하고 실패한 블록 ID만 최대 3회 다시 요청합니다.
- 세 번의 재요청 뒤에도 문제가 해결되지 않으면 페이지 전체를 실패시키거나 해당 블록을 누락하지 않습니다. 마지막으로 읽을 수 있었던 모델 응답을 화면에 표시하고 그 블록만 `검토 필요` 상태로 표시합니다.
- 읽을 수 있는 모델 응답이 한 번도 없으면 OCR 원문을 해당 고정 영역에 유지합니다. OCR 원문도 비어 있는 경우에는 말줄임표를 표시해 블록 자체가 사라지지 않도록 했습니다.
- 최초 모델 응답 전체가 올바른 JSON 형식이 아니어도 계획된 블록을 다시 요청한 뒤 같은 복구 절차로 결과를 표시합니다.
- 복구된 블록의 `검토 필요` 상태가 준비된 번역 체크포인트의 엄격한 형식 검사에서 거부되어 작업이 실패하던 문제를 수정했습니다. 저장과 이어서 처리에서도 해당 상태를 유지합니다.
