# v2.7.5

- 번역·이미지 처리 중에도 페이지 이동, 확대, 원본 비교와 도구 설정을 사용할 수 있습니다. 현재 처리 중인 페이지를 제외한 페이지에서는 텍스트·서식·위치 편집, 일반 붓, 원본 복원과 충돌하지 않는 실행 취소를 허용합니다.
- 번역 대기 페이지도 편집할 수 있도록 개선했습니다. 처리 차례가 오면 진행 중인 입력과 저장을 마친 뒤 최신 내용을 넘겨받으며, 처리 중인 페이지는 최종 결과 저장이 끝날 때까지 보호합니다.
- 작업 센터에서 병행 작업의 진행 상황을 유지하고 개별 작업을 취소할 수 있습니다. 모델 실행, ChatGPT 계정 변경, 가져오기·내보내기는 실제로 사용하는 자원과 저장 대상의 충돌에 맞춰 제한합니다.
- 편집 저장과 자동 결과 저장이 겹칠 때 작업 소유권이 섞여 저장이 거절되거나, 늦게 도착한 응답이 최신 편집을 되돌리던 문제를 수정했습니다. 이미지 정리와 실행 취소 기록의 보존 범위도 보강했습니다.
- 효과음 이미지 생성이 일부 실패해도 확정한 번역문·영역과 성공한 이미지를 보존하고 이미지 작업을 이어할 수 있도록 개선했습니다. 길고 좁은 원문 제거 영역은 주변 문맥을 포함해 나눠 처리하여 요청 영역과 생성 배경의 비율이 맞지 않던 문제를 줄였습니다.
- 생성된 효과음에 별도의 외곽선 두께·색상과 보정 붓을 추가했습니다. 보정 붓으로 칠한 부분에도 외곽선이 적용되며, 기존 텍스트 서식과 원본 이미지는 유지합니다. 효과음 보정의 숫자 입력은 서식 패널과 같은 2열 배치와 −/+ 입력기로 통일했습니다.
- 작업 중 편집 화면에서 발생하던 상태 참조 오류를 수정하고, 화면과 내보내기에서 보정 효과가 일치하는지 검증했습니다.
