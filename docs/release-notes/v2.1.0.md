# v2.1.0 패치노트

기준 범위: `v2.0.1` 태그(`e50dd405`)와 `v2.1.0` 릴리스 커밋의 직접 diff입니다. 최종 제품에 남은 변경만 기록했습니다.

## PDF · RAR/CBR 가져오기

- 파일 선택기와 드래그 앤 드롭에서 PDF, RAR, CBR 원본을 바로 가져올 수 있습니다. 기존 이미지·폴더·ZIP/CBZ 가져오기와 같은 미리보기 및 보관함 추가 흐름을 사용합니다.
- PDF의 모든 페이지를 흰 배경 PNG로 변환합니다. 목표 해상도는 300 DPI이며, 이미지 크기 안전 한도를 넘는 페이지는 비율을 유지한 채 한도 안에서 렌더링합니다. 암호화된 PDF는 지원하지 않습니다.
- RAR/CBR 안의 PNG, JPG/JPEG, WebP 이미지를 추출하고 `page2`가 `page10`보다 먼저 오도록 경로를 자연 정렬합니다. `__MACOSX`, `.DS_Store`, `Thumbs.db` 같은 메타데이터 항목은 제외합니다. 암호화되었거나 여러 볼륨으로 나뉜 RAR/CBR은 지원하지 않습니다.
- 단일 원본은 최대 1 GiB, 압축파일 항목은 최대 10,000개, 실제 페이지는 최대 2,000개, 페이지당 최대 256 MiB, 변환·압축 해제 결과 합계는 최대 4 GiB로 제한됩니다. 비정상 압축률, 중복 항목명, 불완전 추출, 잘못된 이미지와 경로 이탈은 가져오기 전에 차단합니다.
- 페이지 변환·추출 진행률과 취소 상태를 작업 센터에 표시합니다. 취소하거나 실패하면 임시 변환 결과를 정리하고, 보관함 반영 전이었다면 입력한 작품명·화 선택·자동 저장 설정을 그대로 복원합니다.

## 작업 센터와 백그라운드 작업

- 이미지·폴더·압축파일·PDF 준비, 보관함 추가, 웹 이미지 검색·다운로드, 공유 파일 가져오기·내보내기, 모델 설치·확인, ChatGPT 계정 연결, 인터넷 조사를 공통 작업 센터에서 확인하고 취소할 수 있습니다. 선택을 마치면 입력 모달은 닫히므로 진행 중에도 다른 화면을 사용할 수 있습니다.
- 번역·인페인팅 실행 대상처럼 실제로 충돌하는 동작만 잠급니다. 작업 중에도 다른 화·페이지 탐색, 검색, 설정, 폴더 열기와 현재 페이지 편집은 계속 사용할 수 있습니다. 보관함 반영 중 이름 변경·삭제·순서 변경은 메인 프로세스에서도 차단합니다.
- 반영 전 취소·실패는 입력 상태를 복원합니다. 보관함 반영이 끝난 뒤 목록 새로고침이나 자동 이동만 실패한 경우에는 완료된 가져오기를 다시 실행하지 않고 후처리 실패로 따로 알립니다.
- 작업을 시작한 뒤 사용자가 다른 화나 페이지로 이동하면 결과가 준비되어도 화면을 강제로 전환하지 않습니다.
- 최근 완료·부분 완료·실패 작업 8개의 종류, 상태, 제한된 실패 코드만 보존합니다. 원본 경로와 내부 로그는 기록하지 않습니다.
- 완료 알림음을 번역, 원문 지우기, 인터넷 조사별로 각각 켜고 끌 수 있으며 전체 음량도 조절할 수 있습니다.
- 좁은 창에서도 보관함 제목이 두 줄로 접히지 않도록 헤더 배치를 보정했습니다.

## 페이지별 소요 시간

- 번역이 진행되는 동안 페이지별 시간을 체크포인트로 저장하고 화면에 즉시 반영합니다. 앱이나 작업이 중단되어도 마지막 체크포인트까지의 기록이 남고 `진행 중`, `중단됨`, `완료` 상태를 구분합니다.
- `준비·모델 로드`, `OCR`, `AI 번역`, `글자·폰트 맞춤`, `원문 지우기` 5단계와 페이지 합계·전체 합계를 0.01초 단위로 표시합니다. 준비 시간에는 실행 전 저장, 설정·출력 준비, 모델/API·폰트·인페인팅 런타임 준비와 결과 저장이 포함됩니다.
- 완료된 페이지를 다시 번역하면 이전 번역 시간 대신 새 기록으로 교체하고, 중단된 작업을 이어가면 기존 기록에 누적합니다. 별도 인페인팅은 기존 번역 기록을 유지한 채 원문 지우기 시간만 합칩니다.

## 페이지 내보내기와 자동 저장

- 여러 페이지를 수동 내보낼 때 렌더링을 최대 4개까지 병렬 처리합니다. 페이지 순서와 기존 파일명 규칙은 유지합니다.
- 연결된 작업 폴더의 결과 자동 저장도 최대 4개까지 병렬 처리합니다. 한 페이지가 재시도되는 동안 다른 페이지 저장은 계속 진행됩니다.
- 취소·오류가 발생하면 새 작업 예약을 중단하고 열린 렌더러와 부분 출력물을 정리합니다. 자동 저장 중 새 편집이 들어오면 이전 렌더링을 취소하고 최신 결과만 게시합니다.

## Apple Silicon macOS

- 말풍선 레이아웃 ONNX 추론을 전용 WASM 워커로 격리하고 스레드를 최대 4개로 제한했습니다. 워커 오류는 앱 프로세스 종료 대신 해당 요청 실패로 처리되며 취소도 워커까지 전달됩니다. Windows는 기존 네이티브 ONNX 추론을 유지합니다.
- PDF/RAR 가져오기 실행 파일과 필요한 ONNX WebAssembly 자산을 arm64 앱에 포함하고 패키지 검증 단계에서 실제 기능 조회까지 확인합니다.

## 배포 재현성

- FFmpeg, ONNX Runtime, Windows 설치 도구와 Protocol Buffers의 설치 스크립트를 정확한 패키지 버전으로 승인해, 새 환경의 `npm ci`에서도 필요한 네이티브 실행 파일이 빠지지 않도록 고정했습니다.
