# v2.4.2 패치노트

## 여러 블록 서식 편집

- 캔버스에서 마우스로 여러 텍스트 블록을 드래그 선택하면 현재 페이지 블록 목록 대신 개별 블록 편집의 `서식` 탭을 바로 엽니다.
- 선택한 블록들의 글꼴·크기·정렬·줄바꿈·방향·강조·간격·색상·외곽선·효과·투명도 값이 서로 다르면 혼합 상태로 표시합니다. 혼합 상태에서도 값을 고르면 선택한 모든 블록에 같은 서식이 빠짐없이 적용됩니다.
- 토글, 선택 목록, 숫자 입력, 슬라이더와 색상 입력이 혼합 상태를 같은 방식으로 처리하도록 정리해 일부 서식만 바뀌지 않던 문제를 수정했습니다.

## 조건부 일괄 편집

- `속성 바꾸기` 작업을 속성과 적용 결과 중심으로 다시 구성했습니다. 켜짐/꺼짐 속성은 `켜기`·`끄기`·`해제` 중 결과를 직접 고르고, 숫자 속성은 단위와 허용 범위를 함께 확인할 수 있습니다.
- 속성을 여러 개 추가해도 편집 영역이 가로로 잘리지 않도록 각 속성을 세로형 행으로 배치하고, 좁은 창에서는 속성 추가와 프리셋 입력도 한 열로 정렬합니다.
- 결과 영역에서 `조건 일치`, `실제 변경`, `변경 없음` 개수를 구분해 표시하고, 목록에는 실제로 값이 달라지는 항목만 나온다는 점을 안내합니다. 반복 목록은 적용할 결과만 간단히 보여주며 정확한 변경 전·후 값은 상세 영역에서 확인할 수 있습니다.
- 저장값이 생략된 굵게·기울임 등의 속성을 화면에 보이는 기본 상태와 동일하게 판정합니다. 이미 꺼진 속성을 다시 끌 때 불필요한 값을 기록하거나 변경 대상으로 세지 않으며, 연속 실행에서도 변경 없는 조건 일치 항목을 정확히 집계합니다.

## 기본 서식 글꼴

- 설정의 `기본 서식` 글꼴 목록에 실제 글꼴 모양 미리보기, 검색, 즐겨찾기와 글꼴 관리 버튼을 적용해 블록 편집기의 글꼴 선택 방식과 통일했습니다.
