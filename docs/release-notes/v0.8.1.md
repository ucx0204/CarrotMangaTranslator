# v0.8.1 패치노트

기준 범위: `v0.8.0` 이후부터 `v0.8.1`까지의 변경 사항입니다.
포함 커밋: `24e95e6`, `316daa6`, `d2aa08e`, `f48c1c5`, `5618d69`, `600f160`, `6cad981`, `16325a1`, `6bf2235`, `ed0cb33`, `8a2e2af`, `e9a1817`.

## 새 기능

### 텍스트 블록 편집 강화

- 번역 블록 안에서 간단한 마크다운 서식을 사용할 수 있습니다.
  - `**굵게**`는 굵은 글자로 표시됩니다.
  - `*기울임*`은 기울임 글자로 표시됩니다.
  - 화면 미리보기와 PNG 출력 모두 같은 서식을 반영합니다.
- `장평` 조절을 추가했습니다.
  - 글자를 좌우로 살짝 좁히거나 넓혀서 말풍선 안에 더 자연스럽게 맞출 수 있습니다.
  - 블록 편집 패널, 기본 서식, 서식 일괄 적용에 함께 반영됩니다.
- 현재 화 편집 내용에 실행 취소 흐름을 추가했습니다.
  - 블록 이동, 크기 조절, 텍스트 수정, 서식 변경 같은 작업을 되돌리기 쉬워졌습니다.
  - 기존 단축키 설정 흐름과 연결되어 편집 중 실수 복구가 더 편해졌습니다.

### 읽기 영역 확대/축소 개선

- 읽기 영역 확대/축소 단축키를 추가했습니다.
- 일반 키보드의 `+`, `-`뿐 아니라 텐키의 `+`도 확대 단축키로 동작하도록 보강했습니다.
- 확대된 페이지에 스크롤이 생겼을 때 마우스 휠 동작을 자연스럽게 바꿨습니다.
  - 아래로 휠을 돌리면 먼저 현재 이미지를 아래로 스크롤합니다.
  - 이미지가 맨 아래에 닿은 상태에서 한 번 더 아래로 휠을 돌리면 다음 페이지로 넘어갑니다.
  - 위로 휠을 돌릴 때도 먼저 이미지를 위로 스크롤하고, 맨 위에 닿은 뒤 이전 페이지로 넘어갑니다.
  - 다음/이전 페이지로 넘어가면 새 페이지는 맨 위에서 시작합니다.

### 업데이트 확인 안내 추가

- 설정의 설치/확인 화면에서 현재 앱 버전을 볼 수 있습니다.
- 같은 화면에서 GitHub Releases 페이지를 열어 새 버전을 확인할 수 있습니다.
- 업데이트 안내 문서를 추가했습니다.
  - 새 설치 파일을 기존 위치에 그대로 설치해도 모델, 보관함, OCR 런타임, 로그, 캐시는 유지됩니다.
  - 제거할 때 “데이터도 함께 삭제” 항목을 직접 선택하지 않으면 데이터 루트는 지워지지 않습니다.
- 설치 파일 빌드 시 `latest.yml`과 `.blockmap` 업데이트 메타데이터도 함께 생성되도록 정리했습니다.

## 개선 및 수정

### UI와 PNG 출력 일치도 개선

- PNG 출력의 텍스트 렌더링을 화면 미리보기와 더 가깝게 맞췄습니다.
- 출력할 때도 UI와 같은 DOM/CSS 구조로 텍스트 블록을 그리도록 정리했습니다.
- 화면에서 보이는 줄바꿈과 PNG 출력의 줄바꿈이 다르게 나오는 문제를 줄였습니다.
- 장평이 적용된 블록은 UI와 같은 폭 계산으로 줄을 나누도록 수정했습니다.
- 글자 확대/축소, 줄 간격, 자간, 굵게/기울임, 외곽선 효과가 출력에 더 안정적으로 반영됩니다.
- 에디터 테두리나 선택 표시를 켜고 끄더라도 실제 텍스트 배치가 흔들리지 않게 했습니다.

### 긴 페이지 PNG 출력 수정

- 전체 페이지 PNG 출력에서 이미지 하단이 잘릴 수 있던 문제를 수정했습니다.
- 긴 페이지는 숨은 창 크기에 의존하지 않고, 원본 페이지 전체 영역을 캡처하도록 바꿨습니다.
- 기본 캡처 경로가 실패하는 환경에서는 기존 캡처 방식으로 한 번 더 시도합니다.

### README와 화면 안내 보강

- README의 v0.8.0 설명을 최신 화면 기준으로 보강했습니다.
- 번역 시작, 용어/기억, 기본 서식, 단축키, 서식 일괄 적용, OCR 설정 관련 예시 이미지를 갱신했습니다.
