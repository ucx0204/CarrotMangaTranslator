# v3.9.1

## 백업 복원

- 백업 ZIP을 검사하는 동안 설정을 닫거나 다른 탭으로 이동해도 검사가 끝나면 복원 확인창이 열립니다. 대용량 백업의 마지막 파일 검사도 진행률에 표시합니다.
- 전체 복원이 어려운 백업에서는 복구 가능한 작품과 페이지를 현재 보관함에 추가할 수 있습니다. 작품·화·페이지 ID가 손상된 경우 새 ID로 복구합니다.
- 용어집만 남은 경우 기존 작품을 골라 붙이거나 새 작품으로 추가할 수 있습니다.
- 복원 확인창의 경로와 백업 정보는 **자세히**에서 확인할 수 있습니다.

## 설치 파일

- Windows 10/11 x64 — `CarrotMangaTranslator-Setup-v3.9.1.exe`. 코드 서명 없음.
- Apple Silicon macOS 14 이상 — `CarrotMangaTranslator-3.9.1-macOS-arm64.dmg` 또는 `.zip`. Ad-hoc 서명, Apple 공증 없음.
