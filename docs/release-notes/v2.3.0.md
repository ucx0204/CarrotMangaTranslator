# v2.3.0 패치노트

## 텍스트 일괄 편집

- 기존 검색·치환을 조건, 여러 작업, 실제 페이지 미리보기를 갖춘 일괄 편집기로 확장했습니다. 미리 선택한 블록, 현재 페이지 또는 현재 화 전체를 범위로 지정할 수 있습니다.
- 원문·번역문뿐 아니라 화자, 텍스트·폰트 역할, 쓰기 방향, 정렬, 검수 상태, OCR·글꼴 신뢰도, 글자 크기와 간격, 색상과 효과, 페이지·블록 번호, 영역 크기와 비율을 조건으로 사용할 수 있습니다. 빈 번역, 원문과 같은 번역, 숫자 불일치, 괄호·따옴표 불균형, 의심스러운 공백, 용어집 불일치도 바로 찾을 수 있습니다.
- 포함·제외·일치·불일치·시작·끝·정규식, 목록 포함 여부, 숫자 범위·대소 비교, 근접 색상, 참·거짓 비교를 지원합니다. 조건을 `모두` 또는 `하나라도` 방식으로 묶고, 별도 조건 그룹을 추가해 복합 대상을 만들 수 있습니다.
- `찾아 바꾸기`와 `말줄임표·공백 정리` 규칙을 기본 제공합니다. 일반 문자와 정규식, 첫 항목만 또는 모두 치환, 삭제, 캡처 그룹 치환을 지원하며 원문과 번역문을 함께 바꿀 수도 있습니다.
- 한 규칙에 텍스트 치환, 블록 속성 설정·초기화, 저장된 서식 프리셋 적용, 번역문의 전체 또는 특정 글자에 부분 서식 적용을 순서대로 여러 개 넣을 수 있습니다. 작업과 조건은 켜기·끄기, 복제, 순서 변경이 가능합니다.
- 실제 원고에서 변경 전·후를 전환하고, 전체 후보를 앞뒤로 이동하며, 적용하지 않을 결과를 개별 또는 전체 제외할 수 있습니다. 조건별 판정값, 바뀌는 속성, 작업별 중간 결과도 확인할 수 있으며 작업이 없는 규칙은 검수 검색기로 동작합니다.
- 미리보기 뒤 다른 편집으로 값이 달라진 블록은 덮어쓰지 않고 충돌로 건너뜁니다. 여러 페이지 변경은 하나의 기록으로 저장되어 한 번에 실행 취소할 수 있습니다.
- 규칙은 자동 저장되며 즐겨찾기, 복제, 이름·설명 편집을 지원합니다. 여러 규칙을 정해진 순서로 실행하는 연속 실행을 만들 수 있고, 규칙 하나 또는 전체를 YAML로 가져오고 내보내거나 고급 화면에서 직접 편집할 수 있습니다.
- `Ctrl+H`, 텍스트 모아보기, 명령 팔레트와 편집 패널에서 같은 일괄 편집 화면을 열 수 있습니다. 단순한 번역문 수정 뒤에는 해당 변경을 반복할 일괄 편집 규칙도 바로 제안합니다.

## HayaiOCR과 효과음 번역

- OCR 방식에 HayaiOCR을 추가하고 기존 PaddleOCR 경로를 별도 호환 모드로 유지했습니다. GPU 환경의 새 기본값은 HayaiOCR이며, CPU 기본값은 PaddleOCR입니다. NVIDIA CUDA, AMD ROCm, CPU용 HayaiOCR 런타임을 서로 분리해 설치·검증합니다.
- HayaiOCR은 일반 대사와 효과음 후보를 분리합니다. 효과음은 일반 번역에 섞지 않고 페이지 위의 `효과음?` 검토 상자와 화 단위 실행 버튼에 보관합니다.
- 검토 화면에서 페이지와 후보를 선택·해제하고, 후보 영역을 이동·크기 조절하거나 누락된 영역을 직접 추가할 수 있습니다. 잘못 감지된 후보는 검토 대상에서 제외할 수 있으며 기존 번역문 표시와 전체 페이지 표시를 필요할 때만 켤 수 있습니다.
- 효과음 한 개만 즉시 번역하거나 선택한 후보를 묶어 번역할 수 있습니다. 묶음 번역에서는 효과음 전용 자동 폰트 맞춤과 번역 후 원문 지우기를 선택하고 다음 실행의 기본값으로 저장할 수 있습니다.
- 번역은 사용자가 확정한 영역을 고정한 채 페이지 문맥, 용어집, 캐릭터, 번역 규칙과 최근 스토리 메모리를 함께 사용합니다. 모델이 새 영역을 만들거나 위치를 바꾸지 못하게 하고, 유효한 결과만 효과음 블록과 검토 이력에 함께 저장합니다.
- 일부 후보의 번역이나 인페인팅이 실패해도 이미 만든 효과음 블록은 유지하고 남은 후보를 대기 상태로 남깁니다. 기존 인페인팅 결과가 있으면 새 효과음 영역만 추가로 지워 이전 결과를 보존합니다.
- 분리된 한 문장의 OCR 조각과 내부 중첩 조각은 근거가 충분할 때 다시 연결하되, 서로 다른 말풍선의 세로 문장과 가까운 일반 대사는 합치지 않도록 경계를 강화했습니다. 희박한 꼬리 픽셀과 페이지를 가로지르는 잘못된 마스크도 잘라내거나 제외합니다.
- 전체 페이지 영역 검출을 마치면 검출기 메모리를 해제한 뒤 HayaiOCR을 실행하고, OCR 프로세스가 완전히 종료된 뒤 번역 모델을 올리도록 실행 순서를 분리했습니다.

## 글자 크기와 서식

- 글자별 서식에 밑줄, 취소선, 강조점, 장평, 글자색·배경색, 안쪽·바깥 외곽선, 광선과 투명도를 추가했습니다. 블록 전체에도 밑줄·취소선·강조점, 글자 영역 배경, 두 번째 바깥 외곽선과 독립적인 그림자·광선을 적용할 수 있습니다.
- 확장된 서식은 편집 화면, 곡선·세로쓰기 렌더링, PNG와 PSD 출력에서 같은 값으로 처리됩니다. 중첩된 부분 서식을 해제할 때 바깥 서식과 선택하지 않은 내부 서식은 보존합니다.
- AI 글자 크기 맞춤은 OCR 조각의 실제 글자 면적, 반복되는 행·열 간격과 같은 페이지의 안정적인 본문 크기를 함께 사용합니다. 좁고 긴 세로 한 줄, 분리된 HayaiOCR 조각, 후리가나가 섞인 영역에서 과도하게 작거나 크게 잡히는 값을 교정하면서 실제 작은 글씨와 의도적인 크기 차이는 유지합니다.
- `기존 블록 유지` 재번역에서도 유효한 원문 크기 추정값을 기존 블록에 적용합니다. 사용자가 편집 화면이나 일괄 편집에서 글자 크기를 직접 정하면 그 값이 우선하며, 자동 맞춤을 다시 켜더라도 저장된 수동 크기를 임의로 덮어쓰지 않습니다.
- 글자 크기 입력란은 자동 맞춤 중인 블록의 초기 저장값 대신 현재 캔버스에 보이는 계산 크기를 표시합니다. 세로쓰기의 짝 구두점은 하나의 바로 선 묶음으로 배치합니다.
- 새 블록의 기본 줄바꿈은 한국어 단어 단위를 우선하면서 긴 문자열의 넘침을 막는 방식으로 바뀌었습니다. 자연스러운 줄 정리의 새 설치 기본값은 꺼짐이며 필요할 때 번역 실행별로 켤 수 있습니다.

## 편집 화면과 관리 도구

- 여러 블록을 선택한 뒤 하나를 드래그하면 모든 선택 블록이 상대 위치를 유지한 채 같은 거리로 이동합니다. 페이지 밖으로 나가지 않도록 공통 이동량을 제한하고, 드래그 중 모든 블록의 실제 위치를 미리 보여 줍니다.
- 분리한 편집 패널에서도 여러 블록의 공통값과 서로 다른 서식값을 구분해 표시하고, 선택한 블록 전체에 글자 크기와 모든 서식 속성을 적용합니다. 선택이 바뀐 뒤 도착한 오래된 명령은 새 선택에 적용하지 않습니다.
- 새 블록을 만들면 텍스트 탭을 열고, 변형 도구를 선택하면 배치 탭을 여는 등 현재 작업에 맞는 편집 탭으로 이동합니다. 도킹 패널과 분리 창은 각자의 내부 영역만 스크롤해 작업 화면 전체가 밀리는 문제를 막았습니다.
- 서식 프리셋을 편집 패널에서 바로 만들고 적용하며, 현재 서식으로 덮어쓰기, 이름 변경, 삭제와 관리 화면 열기를 지원합니다. 프리셋은 확장된 글자 배경·바깥 외곽선·광선까지 보존합니다.
- 폰트 관리에서 즐겨찾기 순서를 드래그해 바꾸고, 자주 쓰지 않는 폰트를 목록에서 숨기거나 다시 표시할 수 있습니다. 사용자 등록 폰트는 관리 화면에서 삭제할 수 있으며 현재 기본 폰트는 숨길 수 없습니다.
- 마우스 휠 한 칸의 확대·축소 폭을 1~10%로 설정할 수 있습니다. 사각 지우개를 추가하고, 도형·보정 영역을 만드는 동안 채움 형태의 실시간 미리보기를 표시합니다.
- 네이티브 색상 선택기를 연속으로 움직일 때 값 갱신이 재귀적으로 반복되던 문제를 수정했습니다.

## 번역 실행과 기본 설정

- 번역 페이지 선택 창에서 현재 작업 중인 페이지를 표시하고 자동으로 보이게 이동합니다. 첫 페이지를 누른 뒤 `Shift`를 누른 채 다른 페이지를 선택하면 같은 화의 연속 범위를 한 번에 선택하거나 제외할 수 있습니다.
- 범위 선택은 각 페이지의 `이어서 처리`, `새로 번역`, `제외` 상태를 유지합니다. 이어서 처리할 수 없는 페이지가 범위 안에 섞이면 해당 페이지만 새 번역으로 전환합니다.
- `번역만`을 선택했을 때 말풍선 맞춤을 사용할 수 없다는 상태를 명확히 표시하고 이번 실행에서는 끄되, 저장된 선호값은 유지해 원문 지우기를 다시 고르면 복원합니다.
- 새 Gemma 설정은 QAT 속도형 Q4_K_M 프리셋을 사용합니다. Windows에서는 16GB 이상 VRAM도 26B 속도형을 기본으로 선택해 24GB 환경에서 31B를 자동 선택하던 부담을 줄였습니다. 기존에 저장한 모델과 사용자가 지정한 사용자 모델은 강제로 바꾸지 않습니다.
- 저장된 OCR 장치·백엔드·방식을 하드웨어 재감지 결과로 조용히 바꾸지 않으며, 이전 글자 크기 자동 맞춤 설정은 새 AI 글자 크기 맞춤 설정으로 이어받습니다.

## 자동 저장과 작업 공유

- 연결 작업공간의 `result`, `originals`, `inpainted`, `mask` 폴더가 각각 최종 이미지, 복구용 원본, 원문 제거본, 지운 영역을 담는다는 역할을 설정 화면에 표시합니다.
- 복구용 원본은 실제 이미지 형식에 맞는 `.jpg`, `.jpeg`, `.png`, `.webp` 확장자로 저장합니다. 이전에 잘못된 확장자로 저장된 복사본은 내용이 검증된 경우에만 안전하게 이름을 고칩니다.
- 사용자가 복구용 원본을 수정했거나 새 경로에 다른 파일이 있으면 덮어쓰지 않고 앱 관리 결과물 폴더로 전환합니다.
- 편집 블록이 많은 대형 화도 작업 공유 파일로 내보내고 미리 볼 수 있도록 화 메타데이터 한도를 20MiB에서 128MiB로 분리했습니다. 로컬 전용 인페인팅 마스크 경로와 출처 정보는 공유 파일에 넣지 않습니다.

## 사용 안내

- README를 설치, 첫 설정, 가져오기, 번역, 편집, 텍스트 일괄 편집, 효과음 검토, 원문 지우기, 폰트, 내보내기, 문제 해결 순서로 다시 작성했습니다.
- 실제 앱의 넓은 화면과 좁은 화면에서 새로 캡처한 40장의 화면으로 주요 UI와 다섯 가지 일괄 편집 규칙 예시를 설명합니다.
