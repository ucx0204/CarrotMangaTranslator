# v3.8.1

편집기와 설정 화면의 작은 표시 오류를 다듬고, 키보드 이동과 접근성을 개선했습니다.

## 표시와 조작 일관성

- 숫자 입력칸에서 긴 값이 단위와 겹치지 않도록 수정하고, 단위 글자의 대비를 높였습니다.
- 설정·편집기·텍스트 모아보기·서식 프리셋·조건 일괄 처리의 줄 간격 표시를 %로 통일했습니다. 저장된 서식 값은 그대로 유지됩니다.
- 편집기·분리창·보관함·페이지 목록·채팅 등의 가장자리에서 키보드 포커스 테두리가 잘리는 문제를 수정했습니다.
- 페이지의 완료·실패 상태 글자 대비를 개선하고, 서식 미리보기 영역에 키보드 포커스 표시와 접근성 이름을 추가했습니다.
- 명령 팔레트에서 사용자 지정 설정을 반영한 단축키를 함께 표시합니다.
- 조건 일괄 처리와 연결 안내 등의 문구·번역을 정리하고, 툴팁과 화면 간 컨트롤 표현을 맞췄습니다.

## 키보드 이동과 오류 안내

- 모달을 연 직후 Shift+Tab을 눌러도 포커스가 배경으로 빠지지 않도록 수정했습니다.
- 숨긴 오른쪽 패널에 키보드 포커스가 들어가지 않으며, 패널을 열고 닫을 때 보이는 컨트롤로 포커스가 이동합니다.
- 숫자의 최솟값·최댓값 확정 후 Tab 이동과 Escape 취소 시 포커스 유지를 개선했습니다.
- 숫자 증가·감소 버튼, 가져올 화 제목 입력칸, 패널 크기 조절 손잡이의 접근성 정보를 보완하고 페이지 이름 오류를 해당 입력칸에 연결했습니다.
- 오류 알림은 직접 닫을 때까지 유지되며, 설정 화면 오류는 해당 패널을 닫아 복구할 수 있도록 개선했습니다.
