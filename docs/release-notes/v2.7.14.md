# v2.7.14 — 화 이동 후 페이지 저장 충돌 수정

## 페이지 저장 안정성

- 효과음 번역을 실행한 뒤 다른 화로 이동해 편집하면, 이전 화의 번역 완료 응답 때문에 현재 화의 자동 저장이 계속 충돌하던 문제를 수정했습니다.
- 늦게 도착한 번역·저장 응답은 해당 화의 저장 기준만 갱신합니다. 현재 화의 미저장 편집을 이미 저장된 내용으로 잘못 취급하지 않도록 했습니다.
- 실제로 다른 작업이 먼저 변경한 내용에 대한 저장 충돌 보호는 유지합니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다. 각 플랫폼의 릴리스 절차에서 패키지와 실행 여부를 검증합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
