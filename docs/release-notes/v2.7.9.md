# v2.7.9

## AMD ROCm 런타임 설치 실패 수정

- RX 6700 XT 등 gfx103X GPU에서 Gemma QAT 모델용 ROCm 런타임 설치가 `hipblaslt/library` 누락 오류로 중단되던 문제를 수정했습니다. ([#108](https://github.com/ucx0204/CarrotMangaTranslator/issues/108))
- 실제 b1317 gfx103X 배포물에 포함된 파일 구성에 맞춰 검증합니다. 이 배포물에는 rocBLAS 커널과 hipBLASLt DLL이 있지만 별도의 hipBLASLt 커널 데이터는 없습니다.
- 예외는 해당 고정 배포물에만 적용합니다. 다른 AMD 런타임의 필수 파일 검사, 다운로드 SHA-256·크기 검증과 설치 파일 무결성 검증은 유지합니다.

## 고해상도 PSD 출력 수정

- 큰 이미지를 PSD로 저장할 때 일반 캡처 제한에 걸려 출력이 실패하던 문제를 수정했습니다. ([#109](https://github.com/ucx0204/CarrotMangaTranslator/issues/109))
- 합성 이미지, 원본 배경, 정리 배경과 투명 텍스트 레이어 모두 원본 해상도 타일 캡처 경로를 사용합니다. 이미지를 임의로 축소하지 않고 레이어 좌표와 원본 크기를 유지합니다.
- 원본 이미지와 개별 타일에 대한 기존 안전 제한은 유지하며, 글자 제외 출력에도 같은 해상도 설정을 적용합니다.

## 검증

- 실제 런타임 설치 함수를 사용해 빈 폴더에서 b1317 gfx103X 다운로드·설치, 필수 파일과 설치 무결성 검증을 확인했습니다.
- 빌드된 Electron 렌더러와 PSD 출력 코드로 4299 × 6071 및 4961 × 7016 합성 이미지의 출력을 확인했습니다. 원본 크기, 5개 레이어, 텍스트 투명도와 타일 경계 픽셀을 검증했습니다.
- ROCm 배포물별 필수 파일 검사, PSD 전체 레이어·글자 제외 출력과 고해상도 입력 검증의 회귀 테스트를 추가했습니다.
- AMD GPU에서의 실제 모델 추론은 이번 NVIDIA 테스트 PC에서 검증하지 않았습니다. 고해상도 출력 검증은 신고자의 원본이 아닌 합성 이미지로 수행했습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 Developer ID·공증 자격 정보가 없는 경우 ad-hoc 서명으로 배포되며, 이 경우 Apple 공증은 포함하지 않습니다.
