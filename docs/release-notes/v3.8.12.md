# v3.8.12

저장된 API 인증정보를 복호화할 수 없을 때 옵션이 열리지 않던 문제와 Windows 제거 과정에서 암호화 키와 인증정보가 따로 남던 문제를 수정했습니다.

## 설정 복구

- 설정을 읽지 못해도 옵션에서 복구 화면을 열고 다시 불러오기와 로그 확인을 할 수 있습니다.
- 복호화 실패가 확인된 경우, 사용자가 확인하면 기존 설정 두 세대를 백업하고 API 인증정보만 초기화합니다. 번역·글꼴·화면 설정과 작품 데이터는 유지됩니다. API 키는 다시 입력해야 합니다.
- 백업 실패, 파일 무결성 오류, 일시적인 OS 암호화 기능 사용 불가 상황에서는 인증정보를 초기화하지 않습니다.
- 인증정보 백업은 Git 및 배포 파일에서 제외합니다.

## Windows 제거

- 제거 화면에서 ‘설정/로그 등 기타 앱 데이터 삭제’를 선택하면 암호화 키와 관련 인증정보, 설정 세대 파일 및 복구 백업을 함께 정리합니다. 이전 버전의 데이터 위치에도 적용됩니다.
- 일반적인 앱 제거와 작품·모델·글꼴 데이터의 별도 삭제 선택은 유지됩니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.12.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.12-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
