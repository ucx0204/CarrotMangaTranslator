# v2.8.3 — 효과음 번역 누락 수정

## 기존 블록의 효과음 번역

- OCR 원문과 블록이 있고 AI도 번역문을 반환했지만, 효과음 응답의 신뢰도가 `1.00` 미만이라는 이유로 번역문이 사라지던 문제를 수정했습니다. 기존 블록 유지 번역에서는 `0.99` 등의 신뢰도로 반환된 효과음 번역도 해당 블록에 반영합니다.
- 기존 블록의 읽을 수 있는 효과음을 빠뜨리지 않도록 번역 지침을 맞췄습니다. 새 영역을 자동으로 발견하는 경로의 효과음 필터는 유지합니다.

## 번역 누락 확인과 이어서 실행

- 페이지 작업에서 번역문이 비어 남으면 성공한 번역을 저장하고 누락을 알립니다. 같은 작업의 원문 제거는 해당 페이지에서 보류하여 원문만 지워지는 상황을 방지합니다.
- 이어서 실행하면 기본 설정에서 번역이 빈 블록을 다시 처리하며, 이미 저장한 번역과 수동으로 입력한 번역은 유지합니다. 번역 덮어쓰기를 선택한 경우에는 해당 설정을 따릅니다.
- 번역이 빈 채 완료로 기록된 이전 작업과 효과음 번역을 제외한 중간 저장 결과를 다시 확인하도록 보완했습니다. 원문 제거만 별도로 실행하는 기능은 유지합니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
