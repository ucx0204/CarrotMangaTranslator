# v2.5.1 패치노트

## 수정

- Windows 텍스트·말풍선 영역 검출(DirectML)에 고성능 GPU 설정을 반영합니다. GPU/CUDA OCR에서 연산 장치를 직접 지정하면 영역 검출에도 같은 GPU를 사용합니다. [#89](https://github.com/ucx0204/CarrotMangaTranslator/issues/89)
- Windows에서 Visual C++ x64 런타임 누락으로 앱이 시작되지 않으면 Microsoft 설치 링크를 안내합니다. [#88](https://github.com/ucx0204/CarrotMangaTranslator/issues/88)
- 글꼴 자동 맞춤에서 굵은 고딕으로 판별한 원문에 사용 가능한 도현체를 우선 선택해 강조를 유지합니다.
- GPU 설정 화면의 설명을 간소화했습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다.
- Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다.
- [Code signing policy](https://github.com/ucx0204/CarrotMangaTranslator/blob/master/CODE_SIGNING_POLICY.md)
