# v2.6.0

## 글꼴 자동 맞춤

- 일본어→한국어 번역에서 한 화의 원문 글자 형태와 굵기를 함께 분석해 비슷한 스타일의 대사에 일관된 글꼴을 적용합니다. 필요한 폰트 AI 파일은 첫 사용 시 자동으로 내려받습니다.
- 꾸불림체·금면성실체·신라문화체를 추가하고 한국어 글꼴 구성을 정리했습니다. 기존 작업에서 사용하던 글꼴은 추가 글꼴로 보존합니다.
- 글꼴 굵기와 문장부호 표시, 원문 크기에 맞춘 글자 크기 계산을 개선했습니다.

## Codex 이미지 도구

- 일반 번역 엔진과 별도로 Codex 이미지 모델과 이미지 생성 추론 강도를 선택할 수 있습니다. 기본값은 Astra·낮음이며, Codex 연결 전에도 기능과 연결 안내를 확인할 수 있습니다.
- 영역 번역·SFX 검토·원문 지우기·마스크 붓에서 Codex로 원문을 지우거나 번역문 이미지를 생성할 수 있습니다.
- 이미지 생성 전 확인창에서 번역문, 영역의 위치와 크기, 영역별 제외 부분, 스타일 묶음을 편집할 수 있습니다. 실행 취소·다시 실행, 확대·이동, 겹친 영역 선택을 지원합니다.
- 원문 제거의 경계·색조 합성과 생성 글자의 원문 스타일 반영을 개선했습니다. 제외 영역이 완성된 글자 이미지까지 잘라내던 문제를 수정했습니다.
- 전송 이미지에서 노출 부위 등 가리고 싶은 부분을 직접 칠해 가릴 수 있습니다. 생성된 글자 이미지에도 붓으로 수정할 수 있습니다.

## 작업 화면과 설정

- 중간 결과를 큰 화면에서 확대해 보고, 이전 결과 목록을 오가며 확인할 수 있습니다. 이미지 작업의 진행 상황과 부분 실패도 작업 센터에 표시합니다.
- SFX 검토 대상이 0개여도 회색 아이콘으로 검토창을 열 수 있습니다. 검토 초기화 버튼과 설명 툴팁을 추가했습니다.
- OCR·인페인팅·GPU 배정 설정을 AI 섹션으로 모았습니다. 하드웨어 권장 설정은 번역·인터넷 조사에 사용하는 로컬 Gemma 사양에도 적용됩니다.
- 새 설정의 OCR 기본값은 HayaiOCR입니다. GPU 인페인팅을 지원하지 않는 환경의 기본값은 AOT이며, 이미 저장된 OCR·인페인팅 선택은 유지합니다.
- API 최소 요청 간격을 설정할 수 있습니다. 이전 요청에 걸린 시간을 포함해 간격을 계산하며, 기본값은 추가 대기 없는 0초입니다.

## 오류 수정

- 영역 번역을 반복할 때 페이지가 바뀌었다는 오류가 발생하거나 편집 내용이 유실되던 문제를 수정했습니다.
- 이미지 작업 실패·취소 시 완료된 번역문 저장을 보강하고, 일괄 원문 지우기에서 일부 페이지의 실패로 이후 페이지까지 중단되던 문제를 수정했습니다.
- 두꺼운 외곽선이 다른 줄의 글자를 가리던 문제와 일괄 편집에서 일부 변경이 누락되던 문제를 수정했습니다.
- Codex 실행·취소, Windows 네이티브 런타임 진단, DirectML 임시 폴더 처리의 오류를 수정했습니다.
- 설정 동시 저장, 작품 메모리·인터넷 조사 결과 저장, 외부 폴더 연동과 내보내기의 안정성을 개선했습니다.
- 로컬 작업 데이터와 개발용 자료가 설치 파일에 포함되지 않도록 배포 범위를 제한했습니다.
