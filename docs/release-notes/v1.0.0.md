# v1.0.0 패치노트

기준 범위: `v0.10.1` 이후부터 `v1.0.0`까지의 변경 사항입니다.
주요 포함 변경: `fix: shorten managed model cache paths on Windows`, `feat: add multilingual application interface`, `refactor: enforce architecture boundaries` 및 v1.0.0 릴리즈 준비 변경.

## 새 기능 및 개선

### 5개 언어 앱 인터페이스

- 앱 화면 언어로 한국어, 일본어, 영어, 중국어 간체, 중국어 번체를 지원합니다.
- 설정에서 앱 언어를 바꾸면 메인 창과 보조 창, 설정, 진행 상태, 오류와 안내 문구가 같은 언어로 즉시 전환됩니다.
- 저장된 언어 코드와 Windows/BCP 47 로캘을 지원 언어로 안전하게 정규화하며, 중국어 지역·문자권 코드는 간체와 번체를 구분합니다.
- 앱 화면 언어와 번역 원문·대상 언어는 서로 독립적으로 유지해, 화면은 원하는 언어로 보면서 다른 언어쌍을 번역할 수 있습니다.

### 다국어 만화 폰트 24종

- 영어, 일본어, 중국어 간체, 중국어 번체용 무료 만화·손글씨 폰트를 언어별 6종씩 번들에 추가했습니다.
- 폰트 목록은 `기본`을 항상 첫 번째에 두고, 현재 앱 언어에 맞는 폰트 그룹을 그다음에 우선 표시합니다. 나머지 언어 그룹과 사용자가 직접 등록한 TTF/OTF도 이어서 사용할 수 있습니다.
- 화면 미리보기와 PNG 출력이 같은 공용 폰트 카탈로그와 대체 폰트 규칙을 사용해, 선택한 번들 폰트가 내보내기에서도 일관되게 적용됩니다.
- 모든 번들 폰트의 원본 출처, 라이선스 전문, 정확한 upstream revision과 SHA-256 체크섬을 `third_party/fonts`에 기록했습니다.

### 다국어 서식 조절 레이아웃

- 기울기, 투명도, 줄 간격, 자간, 장평 슬라이더가 현재 언어에서 가장 긴 항목명 너비를 함께 사용하도록 정렬했습니다.
- 짧은 번역은 불필요하게 넓은 여백을 만들지 않고, 긴 번역은 정해진 최대 너비 안에서 자연스럽게 줄바꿈되어 슬라이더와 값 표시가 가지런히 맞습니다.

### 읽기 쉬운 다국어 문서

- README를 초보자도 설치와 첫 번역 흐름을 따라갈 수 있도록 텍스트 중심으로 다시 구성했습니다.
- 한국어, 영어, 일본어, 중국어 간체, 중국어 번체 README가 같은 기능·설정·문제 해결·개발·라이선스 정보를 제공합니다.
- 기존 01~46번 안내 이미지를 정리하고, 로고와 실제 사용 흐름을 보여 주는 예제 화면 4장만 남겨 문서 탐색을 간결하게 만들었습니다.

## 안정성 및 내부 개선

### Windows 모델 캐시 경로 단축

- 앱이 관리하는 Hugging Face 모델 파일에 짧고 충돌하지 않는 해시 기반 이름을 사용해, Windows의 긴 경로 제한 때문에 Gemma 모델을 실행하지 못하던 가능성을 줄였습니다.
- v0.10.1까지 사용하던 기존 대용량 모델 파일은 가능한 경우 이름 변경 또는 하드 링크로 새 경로에 연결해, 불필요한 복사나 재다운로드를 피합니다.
- 저장 위치 자체가 여전히 너무 길거나 안전하지 않은 저장소·파일 경로가 입력되면 원인을 포함한 오류를 표시하도록 검증을 보강했습니다.

### 코드 경계와 품질 검사 강화

- renderer, preload, main, shared 도메인의 의존 방향과 facade 경계를 자동 검사하도록 아키텍처 규칙을 추가했습니다.
- 빈 오류 처리, 무시된 Promise 실패, 암묵적인 sentinel 반환, 미사용 export, 복잡도와 파일 크기 예산을 릴리즈 전 검사에 포함했습니다.
- 장시간 유지되는 GPU·native 리소스의 lease와 종료 정리를 명확히 하고, 저장·가져오기·작업 큐·OCR·번역 파이프라인의 실패 및 rollback 테스트를 보강했습니다.
- Windows GitHub Actions에 별도 설치되지 않은 `rg`에 의존하지 않고 오류 처리 검사 대상 파일을 찾도록 CI 검사를 이식 가능하게 정리했습니다.

## 내부 정리 및 테스트

- 5개 언어 UI 문구 카탈로그의 누락 키, 설정 저장과 즉시 전환, 메인·렌더러 프로세스의 언어 동기화를 검증하는 테스트를 추가했습니다.
- 언어별 폰트 순서, 번들 파일과 CSS 등록, 라이선스 파일과 SHA-256 체크섬, 화면·PNG 출력의 폰트 해석 일치를 검증합니다.
- Windows의 짧은 모델 캐시 경로, v0.10.1 캐시 마이그레이션, 긴 경로 거부와 기존 캐시 재사용을 회귀 테스트로 고정했습니다.
- 의존 경계, 오류 처리 정책, 미사용 코드와 번들 경계 검사를 `npm run check`에 통합했습니다.
