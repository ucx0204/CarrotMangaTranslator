# v2.7.3

- 텍스트 블록을 Ctrl+C / Ctrl+V(macOS: Cmd+C / Cmd+V)로 붙여넣을 때 글자 크기와 줄 배치가 달라지는 문제를 수정했습니다. 원문 크기 측정값, 자동 맞춤 설정, 말풍선 배치와 서식을 보존합니다.
- 다른 페이지·화·작품으로 붙여넣어도 복사한 페이지의 글자 크기 기준을 유지합니다. 붙여넣은 블록이 대상 페이지의 주변 글자 크기에 영향을 주거나 받지 않도록 했으며 반복 복사에서도 같은 기준을 유지합니다.
- 원문 인식 상자보다 자동으로 크게 표시되던 텍스트가 붙여넣기 후 작아지는 문제를 수정하고, 검수 상태와 메모도 함께 보존하도록 했습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
