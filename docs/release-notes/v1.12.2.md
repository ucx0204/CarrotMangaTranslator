# v1.12.2 패치노트

기준 범위: `v1.12.1` 태그의 최종 상태와 `v1.12.2`의 최종 상태를 비교했습니다.

v1.12.2는 파일 탐색기에서 원본을 앱으로 바로 끌어 놓아 보관함 가져오기를 시작할 수 있게 하는 사용성 개선 릴리즈입니다.

## 앱 전역 드래그 앤 드롭 가져오기

- 첫 화면과 작품·화 열람 화면 어디서든 여러 PNG, JPG, JPEG, WEBP 이미지를 한꺼번에 놓으면 기존 `보관함에 추가` 준비 창이 열립니다.
- 이미지가 들어 있는 폴더 하나 또는 ZIP/CBZ 압축파일 하나도 바로 놓을 수 있습니다. 기존 가져오기 미리보기와 작품·화 선택 흐름을 그대로 사용하므로 적용 전에 제목과 대상을 확인할 수 있습니다.
- `새 원본 추가` 선택 창이 열려 있을 때도 드롭을 허용하며, 성공하면 선택 창을 닫고 가져오기 준비 창으로 전환합니다.

## 잘못된 조합과 작업 충돌 안내

- 지원하지 않는 확장자가 이미지와 섞였거나 폴더·압축파일이 다른 항목과 함께 놓인 경우 일부만 가져오지 않고 전체 입력을 거부합니다.
- 폴더와 ZIP/CBZ는 각각 하나만 놓도록 안내하고, 지원하지 않는 파일은 최대 두 개의 파일명을 포함한 우하단 토스트로 원인을 알려 줍니다.
- 다른 모달, 번역·인페인팅 작업, 보관함 변경 또는 실행 중인 앱 작업이 있으면 새 가져오기를 시작하지 않습니다. 드래그 중에는 현재 허용 여부를 전체 화면 오버레이로 표시합니다.
- 한 번에 전달할 수 있는 경로 수를 2,000개로 제한하고, 렌더러가 전달한 실제 로컬 경로를 메인 프로세스에서 파일·폴더·압축파일로 다시 검사합니다.

## 다국어 UI와 검증

- 드롭 안내, 차단 안내와 오류 토스트를 한국어·영어·일본어·중국어 간체·중국어 번체에 추가했습니다.
- 여러 이미지, 단일 폴더, 단일 ZIP/CBZ, 지원하지 않는 파일 혼합, 폴더·압축파일 혼합, 경로 누락, 작업 충돌과 모달 예외를 회귀 테스트로 고정했습니다.
- 실제 프로덕션 컴포넌트를 Chromium 1440×900 및 520×760 화면으로 캡처해 허용·차단 오버레이와 우하단 토스트의 잘림, 겹침과 가로 오버플로가 없는지 확인했습니다.
- TypeScript·JavaScript 타입 검사, Prettier, ESLint, 구조·의존성·dead-code 검사, Vitest 전체 커버리지, 프로덕션 빌드, 페이지 출력 픽셀 일치 QA와 이미지 프로토콜 smoke를 통과했습니다.

## 업그레이드 안내

- 기존 작품·페이지·번역문·서식, 설정과 모델 캐시는 그대로 유지됩니다.
- 기존 `새 원본 추가` 버튼과 파일 선택 방식도 변경 없이 계속 사용할 수 있습니다.
