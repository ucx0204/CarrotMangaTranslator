# v3.8.11

Windows에서 FLUX 인페인팅에 **Vulkan 백엔드**를 추가했습니다. Radeon 사용자는 설정의 FLUX 백엔드에서 기존 AMD ROCm과 Vulkan을 선택할 수 있습니다. ([#179](https://github.com/ucx0204/CarrotMangaTranslator/issues/179))

## FLUX Vulkan

- 기존 ROCm 실행 경로와 자동 추천은 유지합니다. Vulkan은 사용자가 직접 선택하는 대안이며 설정을 저장하고 다시 열어도 유지됩니다.
- 필요한 Vulkan 실행기와 라이브러리를 처음 사용할 때 내려받고 파일 크기·SHA-256을 검증합니다. Vulkan 경로는 CUDA·ROCm 런타임을 설치하지 않습니다.
- 선택한 GPU를 Vulkan에 전달하고, 해당 장치를 사용할 수 없으면 오류를 표시합니다. CPU로 자동 전환하지 않습니다.
- 기존 FLUX 모델, 마스크 처리와 최종 합성 경로를 사용합니다. LaMa·AOT 백엔드는 변경하지 않습니다.
- Vulkan을 지원하는 GPU와 그래픽 드라이버가 필요합니다. NVIDIA에서도 수동 선택할 수 있으며 macOS는 기존 Metal 경로를 유지합니다.

## 검증 범위

- RTX 4090에서 Vulkan 장치 인식, 실제 FLUX 추론과 앱 최종 합성을 확인했습니다. 마스크 밖 픽셀은 원본과 동일합니다.
- 새 런타임을 게시 후 재다운로드해 파일명·크기·해시를 대조하고 빈 런타임 캐시에서 설치·추론을 검증했습니다.
- AMD 설정 선택·저장·복원과 ROCm 기본값 유지, GPU 선택, 런타임 무결성 및 넓은/좁은 설정 화면을 검증했습니다.
- **Radeon 실기 성능·품질은 아직 측정하지 않았습니다.** GPU·드라이버에 따라 호환성과 속도가 달라질 수 있으며 ROCm보다 빠르다고 보장하지 않습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.11.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.11-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
