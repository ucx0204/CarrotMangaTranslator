# v2.7.8

## 효과음 검출 정보로 인한 번역 중단 수정

- 효과음 영역에 연결된 원본 검출 ID가 32개를 넘으면 번역 체크포인트 검증에 실패하던 문제를 수정했습니다. 검출 ID를 잘라 버리지 않고 최대 1,000개까지 보존하며, 잘못된 값과 과도한 입력에 대한 검증은 유지합니다. ([#107](https://github.com/ucx0204/CarrotMangaTranslator/issues/107))
- 특정 페이지의 체크포인트 데이터 검증에 실패하면 해당 페이지의 실패 상태를 저장하고 다음 페이지를 처리합니다. 동일한 데이터를 불필요하게 재번역하지 않으며 실패한 페이지의 문맥을 다음 페이지에 반영하지 않습니다.
- 저장이 확인된 페이지 단위 검증 실패는 다음 화의 대기 작업을 중단하지 않습니다. 실패한 페이지와 작업은 성공으로 표시하지 않고 실패 기록을 유지합니다.
- 자동 지우기·말풍선 맞춤을 함께 실행할 때 정상적으로 저장된 선택 페이지만 후처리합니다. 실패 페이지와 선택 범위 밖 페이지는 제외합니다.
- 사용자 취소, 저장 충돌, 디스크 쓰기 오류, 전역 오류와 후처리 실패에 대한 기존 중단 동작은 유지합니다. 실패 상태 저장이 끝난 뒤 해당 페이지의 편집 잠금을 해제합니다.

## 이번 번역에서 제외한 효과음 후보 보존

- 효과음 검토에서 이번 실행에 포함하지 않은 후보를 나중에 다시 검토할 수 있도록 보존합니다. 사용자가 명시적으로 삭제·기각한 후보와 구분합니다.
- 이번 실행에서 제외한 수동 추가 후보와 영역 수정도 저장하며, 모든 후보를 제외한 경우 불필요한 번역 작업을 시작하지 않습니다.

## 검증 보강

- 33개 이상의 검출 ID를 실제 영역 생성 코드로 병합하는 경우와 구버전 검토 데이터, 체크포인트 저장·복원을 회귀 테스트로 확인합니다.
- 중간 페이지 실패 후 앞뒤 페이지 완료, 다음 화 진행, 정상 페이지만 후처리, IPC 응답 검증, 저장 오류·충돌·취소 시 중단을 테스트합니다.
- OCR·영역 병합·폰트 알고리즘은 변경하지 않았으며 기존 입력 검증과 체크포인트 크기 제한을 유지합니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
