# v3.8.8

RAM에 여유가 있는 사용자를 위한 `26B (8GB)` 보조 프리셋을 추가했습니다. 기존 `12B (8GB)`는 첫 번째 옵션과 기본값으로 유지합니다. ([#177](https://github.com/ucx0204/CarrotMangaTranslator/issues/177))

## 26B 보조 옵션

- 설정 → 번역 → Gemma 로컬 → 속도(추천)에서 두 번째 옵션인 `26B (8GB)`를 선택할 수 있습니다.
- 모델의 전문가 가중치를 시스템 RAM에 두고 실행합니다. RAM 24GB 이상, 여유 RAM 약 16GB를 권장하며 CPU와 메모리 성능에 따라 12B보다 느릴 수 있습니다.
- RAM 권장 사항은 기존 툴팁으로 안내합니다. 저장한 모델 선택은 앱을 다시 열어도 유지되며, 기존 26B 프리셋과 모델 파일을 공유합니다.
- 기존 12B 및 26B (16GB) 설정과 추천 기본값은 유지합니다.

## 검증 범위

- 실제 만화 10작품 50장에서 기존 12B와 새 옵션의 번역문을 대조하고, 그중 45장은 양쪽 최종 이미지까지 확인했습니다. 번역 품질은 작품과 문장에 따라 달랐으며 누락·오역이 발생할 수 있습니다.
- 실제 실행 검증은 RTX 4090 24GB에서 CPU 전문가 분산을 강제한 결과입니다. 실물 8GB GPU의 메모리 한도와 성능을 보증하는 결과는 아닙니다.
- 설정 저장·복원, 기본값 유지, 모델 전환과 런타임 인자에 대한 회귀 검증을 포함합니다. 상세 조건은 [운영 문서](https://github.com/ucx0204/CarrotMangaTranslator/blob/v3.8.8/docs/gemma4-26b-qat-mtp.md)에 있습니다.
