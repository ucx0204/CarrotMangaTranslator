# v1.18.1 패치노트

기준 범위: `v1.18.0` 태그와 이번 `v1.18.1` 최종 트리를 직접 비교했습니다.

v1.18.1은 v1.18.0의 기능은 그대로 유지하면서 Apple Silicon macOS 패키지의 자동 검증 안정성을 개선한 패치 릴리스입니다.

## macOS 패키지 검증 안정화

- GitHub macOS 러너에서 서명된 앱을 검증할 때 LaunchServices의 `open -W` 대기 상태에 의존하지 않고, 패키지 안의 실제 앱 실행 파일을 직접 실행하도록 바꿨습니다. 앱의 가져오기, 저장, 재시작, 내보내기 및 런타임 검증 범위는 그대로 유지합니다.
- 대형 패키지의 최초 검증 지연을 수용하도록 앱 스모크 테스트 제한 시간을 5분으로 조정했습니다. 제한 시간은 계속 유한하며 실패 시 프로세스 출력과 진단 자료를 보존합니다.
