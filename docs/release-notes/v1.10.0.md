# v1.10.0 패치노트

기준 범위: `v1.9.0` 이후부터 `v1.10.0`까지의 변경 사항입니다.
주요 포함 변경: 원문 글자 모양을 보고 블록마다 한글 폰트를 자동으로 맞추는 학습된 폰트 매칭 런타임, 한국어 만화 폰트 카탈로그 확장, 앱 그래픽과 로컬 AI 연산 GPU 분리, Ollama 로컬 공급자와 모델별 생성 한도, 인페인팅 부분 완료 보존과 번역 중 UI 응답성, 패키징 환경 빌트인 폰트 렌더링 수정.

## 자동 폰트 맞춤

### 학습된 폰트 매칭 런타임

- 원문 텍스트의 모양·굵기·손글씨 느낌을 보고 대사·내레이션·생각·말풍선 옆글·효과음·강조에 어울리는 한글 폰트를 블록마다 자동으로 적용합니다.
- SigLIP 비전 인코더와 프로토타입 조건 랭커로 구성된 학습된 런타임이 후보 폰트를 정렬하며, 인코더·랭커·프로토타입 세 자산 모두 SHA-256으로 묶인 뒤에만 동작합니다.
- 런타임 자산이 없거나 해시가 바뀌면 자동 폰트 맞춤을 적용하지 않고 사용자가 직접 고정한 글꼴만 유지합니다. 시각 모델 없이 의미만으로 폰트를 추론하거나 프로필을 강제 적용하는 폴백은 허용하지 않습니다.
- 번역 옵션의 `폰트 자동 맞춤` 설정으로 켜고 끌 수 있으며, 같은 화의 본문 일관성은 약하게만 참고하고 이 텍스트의 시각 특징이 다르면 개별 예측이 우선합니다.
- 검증 기준을 통과하지 못한 결과는 적용하지 않고 기존 폰트를 유지합니다.

### 화 단위 일관성과 작품 정책

- 같은 화 안에서 비슷한 대사 글꼴을 약한 사전 신호로 참고해 화 전체의 어색한 폰트 섞임을 줄입니다.
- 작품 글꼴 정책과 현재 텍스트의 시각 특징을 함께 반영해, 작품 전체 톤을 유지하면서도 개별 텍스트에 맞는 선택을 합니다.
- 자동으로 선택된 블록은 서식 패널에 `자동 맞춤` 배지로 표시하고, 선택 근거(이 화의 비슷한 대사·이 텍스트의 모양·작품 정책·사용자 고정)를 안내합니다.

### 자동 선택 되돌리기

- 자동으로 적용된 폰트는 `자동 선택 되돌리기`로 한 번에 원래 폰트로 되돌릴 수 있으며, 되돌리기도 하나의 편집 기록으로 남아 실행 취소할 수 있습니다.
- 자동 폰트 맞춤은 텍스트 외곽선 두께와 색을 바꾸지 않고 폰트 선택만 담당하므로, 기존 서식이 의도치 않게 변경되지 않습니다.

## 한국어 만화 폰트 카탈로그

- 일반 대사·내레이션·효과음·강조·손글씨 느낌까지 두루 아우르는 한국어 만화 폰트 카탈로그를 확장했습니다.
- 도현체, 개구레, 구기, 주아, 나눔고딕, 나눔붓글씨, 리디바탕, 싱글데이, 스타오버, 가석원, 검은한샘, 흑백사진, 카페24 고운밤, 기랑해랑체 등 OFL·공개 라이선스 폰트를 추가했습니다.
- 빌트인 폰트는 `mgt-font://` 커스텀 프로토콜로 라우팅해 Vite 해시 자산으로 가공하지 않고, asar 내부에서 Node `fs`로 직접 읽어 패키징 환경에서도 안정적으로 표시합니다.

## 로컬 AI와 하드웨어

### GPU 할당

- 설정의 하드웨어 영역에 앱 그래픽 GPU와 로컬 AI 연산 GPU를 각각 지정할 수 있는 항목을 추가했습니다.
- 앱 그래픽 GPU는 자동(운영체제 설정 사용) 또는 고성능 GPU 우선(RTX·외장)으로 선택할 수 있고, 변경 사항은 앱을 다시 시작한 뒤 적용됩니다.
- 로컬 AI 연산 GPU는 자동(권장) 또는 0~15번 연산 장치 중 직접 지정할 수 있으며, CUDA·HIP·Vulkan 백엔드 기준 번호라 Windows 작업 관리자의 GPU 0/1 번호와 다를 수 있습니다.
- Intel 내장 그래픽과 RTX가 섞인 PC에서는 앱 그래픽을 고성능으로 두고 연산 GPU는 자동을 먼저 권장한다는 안내를 표시합니다.

### Ollama 로컬 공급자

- API 공급자 빠른 선택에 `Ollama (로컬)`을 추가해 로컬에서 실행 중인 Ollama 모델을 번역에 사용할 수 있습니다.
- 기본 포트(`11434`)를 자동으로 인식하고, 모델 라이브러리 페이지로 바로 이동하는 링크를 제공합니다.
- localhost뿐 아니라 LAN 호스트 주소도 Ollama 공급자로 인식합니다.

### 모델별 생성 한도

- 공개 문서의 컨텍스트·출력 토큰 한도를 모델별로 관리해, 모델이 지원하는 범위 안에서 생성 토큰과 프롬프트 메모리 예산을 자동으로 조정합니다.
- 앱 작업 기본값은 모델의 출력 상한을 넘지 않도록 제한하며, 사용자가 직접 설정한 값은 기존처럼 유지됩니다.

## 인페인팅과 번역 안정성

- 인페인팅 중 일부 블록이 실패해도 이미 완료된 블록의 결과를 보존하고, `부분 완료` 상태로 어느 블록이 남았는지 표시합니다.
- 번역·원문 지우기가 섞인 선택이나 번역 완료 워크플로가 서로 다른 페이지를 한 작업으로 처리할 수 없는 경우 사전에 안내합니다.
- 번역 중에도 UI가 멈추지 않고 취소·스크롤·줌이 즉시 반응하도록 작업 이벤트 처리를 개선했습니다.
- 오버레이 항목이 비어 있어 번역 결과가 누락되는 경우 강화된 변형으로 재시도를 이어가도록 했습니다.
- 로컬 AI 워커가 JSON이 아닌 표준 출력을 내보내도 깨지지 않고, 프로세스 시작 실패 원인을 더 자세히 보고합니다.

## 빌트인 폰트 렌더링 수정

- 패키징 환경에서 `ko/`·`en/`·`ja/`·`zh-hans/`·`zh-hant/` 같은 하위 디렉터리 빌트인 폰트가 기본 폰트로 표시되던 문제를 수정했습니다.
- `standard` 스키마로 등록된 `mgt-font://` URL에서 Chromium이 첫 경로 세그먼트를 호스트로 옮기는 정규화 동작 때문에, 하위 디렉터리 폰트 경로가 잘려 404로 떨어지는 근본 원인을 잡았습니다.
- 호스트와 경로를 합쳐 전체 상대 경로를 복원하도록 처리해 정규화된 형태와 일반 형태 모두 올바른 폰트로 연결됩니다.
- 커스텀 폰트 응답에 CORS 헤더를 추가해 `file://` origin에서 교차 출처로 fetch할 때 차단되지 않도록 했습니다.
