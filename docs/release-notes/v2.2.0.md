# v2.2.0 패치노트

기준 범위: `v2.1.0` 태그(`eb849f79`)와 `v2.2.0` 릴리스 커밋의 직접 diff입니다. 최종 제품에 남은 변경만 기록했습니다.

## 중단된 화 번역 이어서 처리

- 각 페이지의 모델 번역이 끝나면 폰트 맞춤과 결과 반영 전에 준비된 번역 결과를 페이지별 체크포인트로 저장합니다. 앱 종료, 작업 취소 또는 뒤 페이지의 실패로 화 번역이 중단되어도 이미 승인된 체크포인트는 남습니다.
- 다시 실행할 때 원본 페이지 revision, 원문·번역 언어, 블록 생성 방식이 같은 체크포인트는 OCR과 모델 번역을 건너뛰고 폰트 맞춤부터 계속합니다. 조건이 달라졌거나 파일 크기·SHA-256·저장 경로·내용 검증에 실패한 체크포인트는 재사용하지 않고 해당 페이지만 새로 번역합니다.
- 번역과 폰트 설정은 끝났지만 원문 지우기나 말풍선 맞춤이 중단된 페이지는 기존 번역 결과를 유지하고 후처리부터 계속합니다. 일부 블록만 지운 기록이 있으면 완료된 블록은 건너뛰고 남은 블록만 처리합니다.
- 번역 실행 창은 재사용할 페이지를 대시 상태로 표시하고, `번역 결과 재사용`, `번역·폰트 설정 재사용`, `완료된 지우기 결과 재사용` 중 어느 단계에서 이어지는지 툴팁과 선택 요약으로 보여 줍니다. 페이지를 반복 선택하면 `이어서 처리 → 새로 번역 → 제외` 순서로 바꿀 수 있어 한 번의 실행에 재개 페이지와 새 번역 페이지를 섞을 수 있습니다.
- 재개한 앞 페이지의 문맥을 뒤 페이지 번역에 다시 반영하고, 자동 폰트 맞춤은 선택 범위 앞의 완료 페이지에서 검증된 폰트 결정을 복원해 화 단위 일관성을 유지합니다. 저장 정보가 없으면 기존 페이지를 바꾸지 않는 읽기 전용 추론으로 연속성을 복구합니다.
- 체크포인트는 페이지당 하나의 앱 관리 영역에 원자적으로 교체하며 최대 8 MiB로 제한합니다. 번역 결과가 정상 반영되거나 페이지·화가 삭제되면 함께 정리하고, 공유 파일 내보내기·가져오기에는 포함하지 않습니다.

## 원문 글자 크기 자동 맞춤

- 여러 세로·가로 OCR 줄을 감싸는 올바른 번역 영역이 대표 OCR 한 줄로 축소되어 일반 본문이 지나치게 작아지던 문제를 수정했습니다. 모델 영역 안에서 원문과 대응하고 다른 말풍선에 속하지 않는 OCR 줄을 복원해 코드 소유 기하 정보로 유지합니다.
- 원문 글자 크기는 복원된 각 OCR 줄의 실제 글자 수와 래스터를 따로 측정한 뒤 중앙값으로 정합니다. 줄별 추정 차이가 큰 경우에는 기존 합친 영역 측정으로 되돌아가며, 짧은 후리가나 줄과 회전 효과음 등 기존 제외 조건도 유지합니다.
- 전역 최소 글자 크기는 추가하지 않았습니다. 잘못 축소된 일반 본문과 합친 영역 때문에 과대 추정된 글자는 교정하지만, 실제로 작은 후리가나·속삭임·측면 문구는 그대로 보존합니다.
- 새 모델이나 배포 자산은 추가하지 않았습니다. 기존 보관함의 저장된 블록을 자동 변경하지 않으며, 새 번역이나 해당 페이지 재번역부터 교정된 측정이 적용됩니다.

## Codex 인터넷 조사 복구

- Codex 인터넷 조사는 격리된 App Server 세션에서 호스팅된 `web_search`를 직접 사용하도록 실행 설정과 지시를 맞췄습니다. 셸·앱·플러그인 등 다른 도구는 계속 차단합니다.
- 선택한 Codex 모델이 검색을 한 번도 수행하지 못하면 현재 계정에서 사용할 수 있는 `gpt-5.5`로 자동 재시도합니다. 선택한 추론 강도를 지원하지 않는 경우 대체 모델의 기본 지원 강도를 사용하고, 재시도 진행 상태와 실제 사용 모델을 경고에 남깁니다.
- 선택 모델과 대체 모델 모두 검색을 사용하지 못하면 검색 없는 결과를 채택하지 않고 명확한 오류로 종료합니다. 오류 보고서에는 비밀값 없이 인터넷 조사 모델과 추론 강도를 포함합니다.
