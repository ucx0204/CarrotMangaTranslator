# v2.3.2 패치노트

## Codex 인터넷 조사

- GPT-5.6 Sol·Terra·Luna가 사용하는 프로그램형 도구 호출 방식에 맞춰 인터넷 조사 세션을 연결했습니다. 이제 선택한 GPT-5.6 모델이 직접 웹 검색을 수행하며, 검색 호출이 실제로 없을 때만 호환 모델로 재시도합니다.
- 조사 세션은 읽기 전용으로 유지하고 셸, 파일, 앱, 플러그인과 검색 이외의 도구를 계속 차단합니다. 일반 번역과 작품 분석 세션도 기존처럼 도구 없이 사용자가 선택한 Codex 모델로 실행됩니다.
- 재시도 안내가 특정 모델에 웹 검색 기능이 없다고 단정하지 않고, 실제 검색 호출이 확인되지 않았다는 상태를 정확히 표시하도록 바꿨습니다.

## 설치 앱 안정성

- 설치된 앱의 인터넷 조사 후처리 워커가 Electron 메인 프로세스 전용 모듈을 불러오다 `Cannot find module 'electron'`로 실패하던 의존 경계를 분리했습니다.
- 보관함 사용량 계산은 메인 프로세스가 명시적으로 전달한 저장소 인터페이스만 사용하며, 조사 후처리 워커는 설치 패키지에서도 독립적인 Node.js 워커로 실행됩니다.

## HayaiOCR 런타임 재사용

- 첫 설치 뒤 고정 버전의 pip·setuptools·wheel을 업데이트한 정상 상태를 Python 런타임 훼손으로 오인해, 다음 작품에서 Python과 `get-pip.py`를 다시 다운로드하던 문제를 수정했습니다.
- Python 본체와 경로 설정의 무결성 검사는 유지하면서 의도적으로 갱신되는 pip 관리 영역만 분리했습니다. 기존 설치의 무결성 표식도 그대로 인식하므로 OCR 모델과 패키지를 다시 받을 필요가 없습니다.
