# v3.9.0

## 원문 제거와 번역

- Qwen Image 2.1을 추가했습니다. 지울 글자 주변을 잘라 처리하고 원본의 선과 인쇄 무늬를 활용해 배경을 복원합니다. 지원 GPU에서는 기본으로 선택되며, 설정에서 FLUX Klein도 선택할 수 있습니다.
- FLUX 일반·경량 모드에서 말풍선 경계와 그라데이션을 보존하도록 합성을 개선했습니다. 경량 모드는 함께 처리할 수 있는 영역을 묶어 모델 호출을 줄입니다.
- Codex가 돌려준 이미지의 구도가 어긋나면 원본과 다시 맞춥니다. 복원에 실패한 영역이 있어도 같은 페이지에서 성공한 영역은 적용합니다.
- OCR로 글자가 없다고 확인된 페이지에 번역 모델이 대사를 만들어 넣던 문제를 수정했습니다.

## Windows Intel GPU

- Vulkan 장치가 확인된 Intel GPU에서 Qwen과 FLUX를 선택할 수 있습니다. Intel Arc에서는 HayaiOCR의 Intel XPU 옵션도 제공합니다. Iris Xe와 UHD의 OCR 기본값은 CPU입니다. Intel 실기기 검증은 아직 남아 있습니다.
- Windows에서 사용 중인 파일이 일시적으로 잠겨 AI 런타임 설치가 실패하던 경우를 개선했습니다.

## 편집·백업·파일 전송

- 텍스트 모아보기의 서식 편집창에서 작은 화면에서도 하단 설정과 버튼을 사용할 수 있습니다.
- 환경 백업을 복원할 때 검증 진행 상황을 표시하고, 복원 미리보기를 유지합니다.
- 작업 화면이 비정상 종료되면 복구를 위한 재시작을 선택할 수 있습니다. 이미지·PSD 출력 실패 시 원인을 확인할 수 있도록 로그를 보강했습니다.
- MCP 파일 업로드는 한 번에 최대 4 MiB를 보냅니다. 42 MiB ZIP에 필요한 쓰기 호출이 1,344회에서 11회로 줄었습니다.

## 설치 파일과 서명

- Windows 10/11 x64 — `CarrotMangaTranslator-Setup-v3.9.0.exe`. 코드 서명 없음.
- Apple Silicon macOS 14 이상 — `CarrotMangaTranslator-3.9.0-macOS-arm64.dmg`와 `.zip`. Ad-hoc 서명, Apple 공증 없음.
- 플랫폼별 SHA-256 체크섬과 빌드 출처 파일을 함께 제공합니다.
