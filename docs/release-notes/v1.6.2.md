# v1.6.2 패치노트

기준 범위: `v1.6.1` 이후부터 `v1.6.2`까지의 변경 사항입니다.
주요 포함 변경: v1.6.0·v1.6.1 Windows 설치 실패 수정, 빠른 직접 ZIP 설치 유지, 부분 설치와 파일 잠금 회귀 방지.

## 긴급 설치 수정

### 마지막 실행 파일에서 설치가 중단되던 문제 수정

- v1.6.0과 v1.6.1 설치 파일이 앱 본체를 거의 전부 푼 뒤 `Error opening output file(s)`와 함께 중단될 수 있던 문제를 수정했습니다.
- 원인은 ZIP 안의 `당근망가번역기.exe`라는 한국어 파일명을 설치용 압축 해제 플러그인이 잘못 해석한 것이었습니다.
- Windows 내부 실행 파일명을 ASCII 전용 `CarrotMangaTranslator.exe`로 고정했습니다.
- 앱 이름, 설치 파일 이름, 시작 메뉴와 바탕 화면 바로가기, 제어판 표시 이름은 계속 `당근망가번역기`로 표시됩니다.
- 기본 설치 폴더는 이전 버전과 같은 `carrot-manga-translator`로 유지해 부분 설치의 데이터와 경로를 그대로 이어받습니다.

### 실패한 v1.6.0·v1.6.1 설치 복구

- 설치가 실패했더라도 설치 폴더 안의 `data`와 `data-root.txt`는 보존됩니다.
- 설치 폴더를 수동 삭제하지 말고 v1.6.2 설치 파일을 그대로 실행해 같은 위치에 덮어 설치하면 앱 실행 파일과 제거 프로그램, 설치 정보가 복구됩니다.
- `data` 폴더를 직접 지우면 보관함, 모델, OCR 런타임, 설정과 로그가 함께 삭제될 수 있으므로 주의해 주세요.

## 설치 속도와 안정성

### 빠른 직접 ZIP 설치 유지

- v1.6.1에서 적용한 임시 폴더 전체 복사 제거와 빠른 Deflate ZIP 압축 해제는 그대로 유지합니다.
- 설치 중 앱 파일을 인터넷에서 다시 다운로드하지 않으며, 단계별 설치 로그도 계속 표시합니다.
- 실행 파일의 내부 이름만 안전한 ASCII 이름으로 바꿔 기존 속도 개선을 되돌리지 않았습니다.

### 잠긴 파일 자동 재시도

- 백신 검사나 다른 프로세스 때문에 설치 대상 파일이 잠깐 잠기면 자동으로 세 번 다시 시도합니다.
- 자동 재시도 후에도 파일을 쓸 수 없을 때는 앱을 닫고 다시 시도할 수 있는 안내를 표시합니다.
- 새 설치 파일은 기존 버전을 제거하기 전에 설치 경로 길이를 검사해, 너무 긴 경로로 인한 부분 설치를 막습니다.

## 재발 방지

- 빠른 ZIP에 들어갈 모든 파일과 폴더 경로가 ASCII인지 Windows 패키징 단계에서 검사합니다.
- 가장 긴 패키지 상대 경로가 설치 플러그인의 안전 길이 예산을 넘으면 릴리스 빌드를 중단합니다.
- 패키지된 실행 파일이 `CarrotMangaTranslator.exe`인지 확인하고, 제거 프로그램은 새 이름과 이전 한국어 이름을 모두 정리합니다.
- GitHub Actions 릴리스 과정에서 완성된 실제 NSIS 설치 파일을 자동 실행합니다.
- 격리된 임시 경로에서 신규 설치, 파일이 잠긴 상태의 재설치·업그레이드, 사용자 데이터 보존 제거를 모두 통과해야만 릴리스 자산을 업로드합니다.
