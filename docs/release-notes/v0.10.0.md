# v0.10.0 패치노트

기준 범위: `v0.9.3` 이후부터 `v0.10.0`까지의 변경 사항입니다.
포함 커밋: `feat: add configurable translation language pairs`, `feat: support current Codex models and ultra reasoning`, `chore: release v0.10.0`.

## 새 기능

### 번역 원문·대상 언어 선택

- 설정에 번역 엔진과 독립적인 `원문 언어`와 `번역 언어` 선택 항목을 추가했습니다.
- 일본어, 한국어, 영어, 중국어 간체/번체를 포함한 40개 이상의 언어 프리셋을 제공하며, `⇄` 버튼으로 원문과 번역 언어를 바로 바꿀 수 있습니다.
- 목록에 없는 언어는 `직접 입력…`에서 `eo`, `pt-BR` 같은 언어 코드를 넣어 사용할 수 있습니다.
- 언어 코드는 BCP 47 형태에 맞춰 대소문자를 정규화하고, 중국어 지역 코드는 간체/번체 프로필로 연결합니다.
- 기존 설정에는 이전과 같은 일본어 → 한국어 기본값을 적용해 업데이트 후에도 기존 번역 흐름이 유지됩니다.

### 다국어 번역 파이프라인

- 선택한 언어쌍을 전체 페이지 번역, 선택 영역 번역, 기존 블록 유지 번역, 작품 메모리 분석과 스타일 가이드 생성까지 전달합니다.
- 일본어 → 한국어에서는 기존 만화 특화 프롬프트와 `jp`/`ko` 응답 계약을 유지하고, 다른 언어쌍에서는 `source`/`target` 기반의 다국어 프롬프트와 응답 계약을 사용합니다.
- PaddleOCR에 원문 언어를 전달하고, 언어별 OCR 모델 선택과 OCR 힌트 캐시를 원문 언어 기준으로 분리했습니다.
- 일본어에 맞춘 잡음 제거와 `OCR 텍스트 없음` 페이지 건너뛰기는 일본어 원문에만 적용해, 다른 언어에서 OCR 오탐 때문에 번역이 누락될 가능성을 줄였습니다.
- 일본어와 RTL 언어를 포함한 원문 읽기 방향을 텍스트 모아보기, 검수표, 기존 블록 참조 순서에 반영했습니다.
- 화면과 내보내기 형식의 `한국어` 고정 표현을 `번역문` 중심의 중립 표현으로 정리했습니다.

### 최신 Codex 모델 선택

- Codex 모델 입력을 드롭다운으로 바꾸고 GPT-5.6-Sol, GPT-5.6-Terra, GPT-5.6-Luna, GPT-5.5, GPT-5.4, GPT-5.4-Mini, GPT-5.3-Codex-Spark를 표시합니다.
- 계정 또는 배포 상태에 따라 목록에 없는 모델은 `Custom (직접 입력)…`으로 기존처럼 모델 ID를 입력할 수 있습니다.
- 새 설치의 기본 Codex 모델을 `gpt-5.6-sol`로 갱신했으며, OpenAI 호환 API 엔진의 기본 모델은 `gpt-5.5`로 독립 유지합니다.

### 모델별 생각 단계

- 목록에서 선택한 Codex 모델은 실제로 지원하는 생각 단계만 표시하고, Custom 모델에는 모든 단계를 표시합니다.
- 기존 `none`, `low`, `medium`, `high`, `xhigh`에 `max`와 `ultra`를 추가했습니다.
- GPT-5.6-Sol/Terra는 `ultra`, GPT-5.6-Luna는 `max`까지 선택할 수 있습니다.
- 모델을 바꿨을 때 현재 생각 단계가 새 모델에서 지원되지 않으면 그 모델의 기본 단계로 자동 보정합니다.

## 내부 정리 및 테스트

- 설정, IPC, 메인 프로세스와 렌더러가 같은 언어 코드 정규화 및 검증 규칙을 사용하도록 공통 언어 도메인을 추가했습니다.
- 런타임 프롬프트용 언어 프로필을 분리하고, 기존 일본어 → 한국어 프롬프트가 바뀌지 않는지 계약 테스트를 보강했습니다.
- 언어 설정 저장, 직접 입력, RTL 읽기 순서, OCR 언어 캐시, overlay 응답 파싱, 기존 블록 유지, 작품 메모리 프롬프트 테스트를 추가했습니다.
- Codex 모델 선택, 모델별 생각 단계 보정, 설정 IPC와 실제 요청 body 테스트를 추가했습니다.
- 고코어 환경에서 파일 기반 테스트가 과도하게 동시에 실행되지 않도록 Vitest 워커를 4개로 제한하고, Windows 호스티드 러너에서 첫 실행이 느린 PowerShell ZIP 해제 테스트에만 30초 제한을 적용했습니다.
- README의 주요 기능, 설정 설명, 릴리즈 요약과 설치 파일 예시를 `v0.10.0` 기준으로 갱신했습니다.
