# v3.8.15

## Codex 원문 제거

- 생성한 배경의 가로세로 비율이 달라 원문 제거가 보류되던 경우를 개선했습니다. 앱이 같은 이미지의 중앙을 원본 비율로 잘라 한 번 더 맞춰 봅니다. 주변 선과 무늬가 맞으면 추가 생성 없이 적용하고, 여전히 어긋나면 해당 영역을 보류합니다.
- 긴 말풍선을 나눠 처리할 때 조각을 붙이는 자리에 원래 글자의 획이 남던 문제를 고쳤습니다.
- 추론 강도가 쓰이는 단계를 설정에 표시합니다. 이미지 모델을 직접 선택하면 Codex 검수에, 자동 선택하면 이미지 생성과 검수에 적용됩니다.

## 로컬 Gemma 번역

- Gemma가 입력을 읽거나 번역문을 생성하는 동안 진행 상황을 표시합니다. 한 페이지에 5분이 넘게 걸려도 처리가 진행 중이면 계속 기다립니다.
- 5분 동안 아무 진전이 없으면 이유를 표시하고 해당 페이지의 자동 재시도를 멈춥니다.

## 검증

서로 다른 작품 10편에서 본문을 한 페이지씩 골라 대사·본문 38개와 효과음 6개를 테스트했습니다. RTX 4090에서 Gemma 4 12B가 10페이지를 페이지당 한 번의 요청으로 번역했습니다. Codex 원문 제거는 44곳 중 43곳을 첫 시도에 적용했고, 보류한 한 곳은 다시 생성해 적용했습니다. 10페이지 모두 지정 영역 밖에서 바뀐 픽셀은 0개였습니다.
