# v1.13.0 패치노트

기준 범위: `v1.12.2` 태그의 최종 상태와 `v1.13.0`의 최종 상태를 비교했습니다.

v1.13.0은 공개 웹 페이지에서 만화 이미지를 찾아 필요한 페이지만 골라 보관함으로 가져오는 기능을 추가한 기능 릴리즈입니다.

## 링크에서 이미지 가져오기

- `새 원본 추가`에 `링크로 열기`를 추가했습니다. 원본 선택지는 일반 창에서 강조 카드 없이 같은 크기의 2×2 격자로 보이고, 폭 640px 이하에서는 한 줄씩 배치됩니다.
- 공개 HTTP/HTTPS 주소를 입력하면 격리된 숨김 브라우저가 페이지를 점진적으로 스크롤하며 일반 이미지, `srcset`, 흔히 쓰이는 지연 로딩 속성, CSS 배경 이미지, 열린 Shadow DOM과 로드된 프레임의 이미지를 수집합니다. 직접 이미지 주소도 지원합니다.
- 후보는 페이지의 위→아래, 왼쪽→오른쪽, DOM 발견 순서로 정렬하고 URL과 실제 파일 SHA-256이 같은 중복 이미지는 처음 발견한 위치만 남깁니다.
- 실제 이미지 크기를 기준으로 `전체`, `중간이상`(40,000픽셀 이상), `최대`(480,000픽셀 이상) 필터를 제공합니다. 기본값은 `최대`이며 보이는 후보를 모두 선택하고, 직접 해제한 선택 상태는 필터를 오가도 유지합니다.
- 미리보기에서 순번, 크기, 포맷을 확인하고 체크박스나 키보드로 이미지를 선택할 수 있습니다. 최종 선택 이미지만 기존 `보관함에 추가` 창으로 넘기므로 작품·화 선택과 제목 입력 방식은 그대로입니다.
- 선택한 이미지는 표시 순서대로 다시 번호를 매겨 `1.jpg`, `2.png`처럼 빈 번호 없이 저장합니다. JPEG는 JPG, PNG는 PNG로 저장하고 WEBP는 기존 보관함 규칙에 따라 PNG로 변환합니다. 기존 로컬 이미지·폴더·ZIP/CBZ 가져오기의 파일명 규칙은 바뀌지 않습니다.

## 보안과 임시파일 관리

- 사용자 정보가 포함된 URL, 로컬 파일, localhost, 사설·루프백·링크 로컬 주소와 그 주소로 향하는 DNS 및 리다이렉트를 탐색·서브리소스·다운로드 단계에서 차단합니다.
- 스캔 창은 비영구 세션, sandbox와 context isolation, Node 비활성화 상태로 실행합니다. 권한 요청, 팝업, 새 창, 다운로드와 외부 앱 실행은 허용하지 않습니다.
- 확장자가 아니라 실제 이미지 헤더로 PNG·JPEG·WEBP 포맷과 크기를 검증합니다. GIF·SVG·AVIF·깨진 이미지 등은 후보에서 제외하고 미리보기 상단에 제외 이유별 개수를 안내합니다.
- 렌더러에는 원격 URL이나 임시 경로 대신 불투명 후보 ID와 전용 미리보기 주소만 제공합니다.
- 발견 URL 5,000개, 후보 2,000장, 전체 임시 데이터 2GiB, 스캔 90초, 동시 다운로드 6개로 제한하며 기존 이미지당 256MiB·120MP 제한도 적용합니다. 한도에 도달하면 확보된 후보를 먼저 보여 주고 일부만 불러왔음을 알립니다.
- 스캔별 전용 임시 폴더를 사용하고 취소, 새 스캔, 미리보기 폐기, 가져오기 성공, 30분 만료, 창·앱 종료와 다음 앱 시작 시 정리합니다. 선택 확정 시에는 선택하지 않은 파일을 즉시 제거합니다.

## 호환성과 검증

- 모든 공개 웹 사이트의 자동 가져오기를 보장하지는 않습니다. 로그인, 봇 차단, 핫링크 차단, DRM 또는 페이지 자체 정책으로 이미지 접근을 제한하는 사이트에서는 후보가 없거나 일부만 표시될 수 있습니다.
- URL·리다이렉트 보안, 크기 경계값, 위치 정렬, URL·해시 중복 제거, 헤더 기반 포맷 판정, 필터 전환과 선택 기억, 연속 번호 부여를 단위 테스트로 고정했습니다.
- 지연 로딩, `srcset`, 배경 이미지, 프레임, 직접 이미지 주소, 중복·리다이렉트·깨진 이미지·지원하지 않는 포맷을 로컬 fixture와 통합 테스트로 검증했습니다.
- 스캔 실패·취소·교체, 미리보기 폐기, 만료와 가져오기 성공 시 임시파일 수명을 검증하고, 웹 가져오기만 숫자 파일명을 사용하며 기존 가져오기 이름은 유지되는지 회귀 테스트했습니다.
- 실제 프로덕션 컴포넌트를 Chromium의 넓은 화면과 좁은 화면으로 캡처해 2×2/1열 원본 선택 격자, 링크 가져오기 모달, 선택 상태, 포커스, 잘림과 가로 오버플로를 확인했습니다.
- TypeScript·JavaScript 타입 검사, Prettier, ESLint, 구조·의존성·dead-code 검사, Vitest 전체 커버리지, 프로덕션 빌드, 페이지 출력 픽셀 일치 QA, 이미지 프로토콜 smoke와 내장 Hugging Face 자산 검증을 통과했습니다.

## 업그레이드 안내

- 기존 작품·페이지·번역문·서식, 설정과 모델 캐시는 그대로 유지되며 라이브러리 마이그레이션은 없습니다.
- 웹에서 가져온 원본 페이지 주소는 보관함에 영구 저장하지 않습니다.
