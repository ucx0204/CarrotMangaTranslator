# v1.17.1 패치노트

기준 범위: `v1.17.0` 태그와 `v1.17.1` 태그의 최종 트리를 직접 비교했습니다. 아래에는 두 최종 버전 사이에 실제로 남은 차이만 기록했습니다.

v1.17.1은 내장 Radeon과 외장 Radeon 또는 eGPU를 함께 사용하는 Windows 환경에서 잘못된 GPU가 자동 감지되던 문제를 수정한 호환성 릴리즈입니다.

## AMD 다중 GPU 자동 감지

- Windows가 비활성화됐거나 현재 연결되지 않은 AMD 장치를 반환하더라도 자동 감지 후보에서 제외합니다. 디스플레이 장치가 아닌 일반 AMD PnP 항목도 GPU로 오인하지 않습니다.
- Windows 비디오 컨트롤러와 PnP 목록에 같은 GPU가 중복 노출되면 PnP 장치 ID를 기준으로 하나로 병합합니다.
- Radeon 780M 같은 내장 GPU와 Radeon RX 외장 GPU 또는 eGPU가 함께 있으면 활성 외장 GPU를 자동 감지 기준으로 우선합니다. Windows가 전용 VRAM 대신 공유 메모리나 축약된 `AdapterRAM` 값을 보고해도 내장 GPU가 잘못 우선되지 않습니다.
- Radeon RX 6000·7000·9000 계열의 데스크톱, 모바일 `M`·`M XT`, 소형 시스템용 `S`, `XT`·`XTX`·`GRE` 이름을 세대별 실행 대상으로 인식합니다. 특정 RX 7600M XT 모델만 예외 처리하지 않고 같은 계열의 다른 모델에도 적용합니다.
- 운영체제 정보가 부족해 런타임 자체 탐지로 넘어가는 경우에도 내장 GPU보다 활성 외장 Radeon의 아키텍처를 우선합니다.

## 하드웨어 설정 표시

- 하드웨어 요약에서 `자동 감지 기준 GPU`와 `로컬 AI 연산 장치`를 분리해 표시합니다. 자동 선택인지 사용자가 지정한 런타임 장치 번호인지 바로 구분할 수 있습니다.
- 로컬 AI 연산 장치 번호는 Windows의 GPU 번호가 아니라 선택한 AI 런타임이 매긴 번호이며, 장치를 비활성화하거나 연결 상태를 바꾸면 번호가 달라질 수 있다는 안내를 명확히 했습니다.
- GPU 이름을 인식했더라도 현재 Windows AI 런타임이 공식 지원하지 않는 조합은 기존처럼 지원되는 CPU 경로를 기본값으로 사용합니다. 감지 개선이 미지원 연산 경로를 임의로 활성화하지는 않습니다.
