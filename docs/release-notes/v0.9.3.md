# v0.9.3 패치노트

기준 범위: `v0.9.2` 이후부터 `v0.9.3`까지의 변경 사항입니다.
포함 커밋: `chore: release v0.9.3`.

## 개선 및 수정

### BeeLlama CUDA 13.1 런타임 ZIP 설치 실패 수정

- RTX 50 / CUDA 13 계열에서 쓰는 BeeLlama CUDA 13.1 런타임 ZIP 설치 중 런타임 폴더가 비어 남을 수 있던 문제를 수정했습니다.
- PowerShell `Expand-Archive` 실행에 `$ErrorActionPreference = 'Stop'`과 `-ErrorAction Stop`을 적용해, ZIP 해제 중 발생한 오류가 성공처럼 지나가지 않도록 했습니다.
- `Expand-Archive`가 실패하면 임시 추출 폴더를 다시 비운 뒤 Windows 기본 `tar.exe`로 ZIP을 한 번 더 풀도록 fallback을 추가했습니다.
- `tar.exe` fallback에서는 먼저 `tar.exe -tf`로 ZIP 항목을 읽고, 절대 경로, 드라이브 경로, 상위 폴더 이동 경로처럼 안전하지 않은 항목을 차단한 뒤 추출합니다.
- ZIP 해제 자체가 실패한 상황이 `No runtime files matched`라는 후속 검증 에러로만 보이던 문제를 줄였습니다.

### 런타임 ZIP 설치 진단 개선

- 런타임 파일 선택 결과가 0개일 때 에러 detail에 `archivePath`, 임시 `extractDir`, 해제 stdout/stderr, 사용한 해제 도구, 해제 시도 목록을 포함하도록 했습니다.
- ZIP 해제 뒤 최상위 추출 항목 목록을 `extractedTopLevelEntries`로 남겨, 실제로 어떤 파일 또는 폴더가 풀렸는지 확인할 수 있게 했습니다.
- PowerShell 또는 `tar.exe` 실행 실패 시 각 시도의 exit code, stderr, spawn 오류를 함께 보관해 사용자가 ZIP 다운로드 문제와 앱 해제 로직 문제를 구분하기 쉽게 했습니다.

## 내부 정리 및 테스트

- 런타임 ZIP 해제 명령 실행을 공통 helper로 정리하고, 프로세스 출력은 stdout/stderr 스트림이 닫힌 뒤 수집하도록 했습니다.
- `No runtime files matched` 에러에 해제 진단 정보가 포함되는지 검증하는 테스트를 추가했습니다.
