# v1.5.0 패치노트

기준 범위: `v1.4.0` 이후부터 `v1.5.0`까지의 변경 사항입니다.
주요 포함 변경: 페이지별 누적 컨텍스트 번역, 이미지 기반 장면 요약, 근거가 확인된 용어·캐릭터 자동 기억, 사용 통계와 관리 UI 개선 및 v1.5.0 릴리즈 준비 변경.

## 새 기능 및 개선

### 페이지마다 이어지는 누적 컨텍스트 번역

- 번역 방식을 `빠른 1회`, `누적 컨텍스트 (권장)`, `정밀 2차`의 세 가지 모드로 나누고 누적 컨텍스트를 기본값으로 변경했습니다.
- 누적 모드는 한 페이지를 번역하는 이미지 모델 호출에서 장면 요약, 용어 후보와 캐릭터 후보를 함께 수집하고 다음 페이지부터 바로 참고합니다.
- 앞 페이지에서 확정된 번역과 기억이 같은 화의 다음 페이지뿐 아니라 이후 화의 번역에도 이어져, 이름·호칭·용어와 이야기 흐름의 일관성을 높입니다.
- 빠른 1회 모드는 기존처럼 페이지를 한 번만 처리하며, 정밀 2차 모드는 `1차 번역 → 범위 분석 → 전체 재번역` 흐름을 최고 품질 선택지로 유지합니다.
- 기존 설정에 새 번역 방식 값이 없어도 누적 컨텍스트로 안전하게 정규화하며, 기존 보관함과 공유 파일을 그대로 열 수 있습니다.

### 이미지를 직접 읽는 페이지 장면 요약

- 페이지 이미지와 확정 번역을 바탕으로 장면, 행동과 핵심 대사를 1~2문장으로 정리한 이미지 요약을 페이지 기억에 저장합니다.
- 이미지 요약은 기존 텍스트 메모와 분리해 메모리 화면에서 우선 표시하며, 사용자가 직접 수정한 요약은 이후 자동 번역이 덮어쓰지 않습니다.
- 대사가 없는 페이지도 누적 모드에서는 이미지 모델로 장면을 파악해 요약을 남기고, 번역 블록은 빈 상태로 정상 완료합니다.
- 불명확한 인물, 관계와 의도는 단정하지 않도록 프롬프트와 응답 검증을 보강했습니다.

### 근거가 확인된 용어·캐릭터 자동 기억

- 새 용어와 캐릭터는 현재 페이지 원문, OCR 또는 확정 번역에서 실제 근거를 찾은 경우에만 자동으로 추가합니다.
- 기존 원문·별칭·이름과 겹치거나 모호하게 충돌하는 후보를 제외해 비슷한 항목이 반복해서 쌓이는 문제를 줄였습니다.
- AI가 만든 항목에는 출처를 기록하고, 사용자가 한 번이라도 편집하면 수동 항목으로 전환해 이후 자동 분석으로부터 보호합니다.
- 기존 항목의 번역값과 캐릭터 말투는 자동으로 덮어쓰지 않으며, 저장 최대치에 도달해도 기존 데이터를 삭제하지 않고 신규 추가만 중단해 경고합니다.

## 사용성 개선

### 용어집·캐릭터 사용 통계와 정리 도구

- 용어집과 캐릭터 화면에 검색, 많이 등장한 순서·최근 등장·이름·저장 순서 정렬을 추가했습니다.
- `AI 생성`, `사용 안 함`, `0~1쪽 등장`, `비활성` 필터와 다중 선택 후 확인 삭제를 지원하며 자동 삭제는 하지 않습니다.
- 각 행에는 실제 언급 횟수만 작은 숫자로 표시하고, 숫자에 마우스를 올리거나 키보드로 포커스하면 등장한 쪽 수와 최근 위치를 함께 확인할 수 있습니다.
- 선택 체크박스와 활성 상태를 분리하고 활성 여부는 오른쪽의 작은 스위치로, 개별 삭제는 절제된 휴지통 아이콘으로 정리했습니다.
- 용어집과 캐릭터 표의 행 높이, 열 간격과 좁은 화면의 내부 가로 스크롤을 다듬어 많은 항목도 더 빠르게 훑을 수 있습니다.

### 번역에 필요한 기억을 우선 사용하는 프롬프트

- 현재 OCR과 직접 일치하는 용어·캐릭터를 가장 먼저 넣고, 남는 공간은 등장 페이지 수와 최근 사용 순서로 채웁니다.
- 기존 용어 80개·캐릭터 40개 제한과 토큰 예산을 유지하면서 현재 페이지와 관련성이 높은 기억이 먼저 선택되도록 개선했습니다.
- 이전 화의 살아 있는 페이지 기억도 정리해 다음 화의 첫 페이지부터 필요한 줄거리와 이름을 참고할 수 있습니다.

## 성능 및 안정성 개선

### 번역 결과와 컨텍스트 저장의 실패 분리

- 모델 응답에서 페이지 컨텍스트를 먼저 분리한 뒤 기존 번역 파서를 실행해, 컨텍스트 JSON이 없거나 깨져도 정상 번역은 그대로 저장합니다.
- 컨텍스트 분석 실패만으로 페이지를 재시도하지 않으며, 저장 실패도 페이지 번역을 실패시키지 않고 경고로 남깁니다.
- 번역 재시도 중에는 기억을 누적하지 않고 최종 성공 결과가 승인된 뒤 페이지당 한 번만 저장해 중복 항목과 통계 증가를 방지합니다.
- 번역·컨텍스트 응답 처리, OCR 준비, 재시도 로깅과 페이지 결과 조립을 작은 단계로 분리해 실패 지점을 더 정확히 다룹니다.

### 페이지 순서와 사용 통계의 정확성 강화

- 선택 번역과 미번역 페이지만 번역할 때도 작업 목록의 상대 번호가 아니라 화 전체의 실제 페이지 순번을 사용합니다.
- 각 페이지 기억에 확인된 용어·캐릭터 ID를 스냅샷으로 저장하고, 재번역 시 기존 스냅샷을 교체해 등장 쪽 수와 언급 횟수가 중복되지 않도록 했습니다.
- 페이지를 삭제하면 연결된 기억을 함께 제거하고, 순서를 바꾸면 저장된 페이지 인덱스를 다시 계산해 오래된 참조가 남지 않습니다.
- 기존 `schemaVersion: 1`을 유지하고 신규 필드를 선택 사항으로 추가해 이전 작품 데이터와의 호환성을 유지합니다.

## 내부 정리 및 테스트

- 1페이지의 용어·캐릭터·이미지 요약이 저장되고 2페이지 프롬프트에 들어가는 누적 흐름을 통합 테스트로 검증합니다.
- 잘못된 컨텍스트 JSON, 무대사 페이지, 재시도·재번역·취소·재개, 기존 수동 항목 보호와 최대 항목 수 처리를 회귀 테스트로 고정했습니다.
- 선택 페이지의 실제 순번, 페이지 삭제·재정렬, 오래된 기억 제거와 페이지별 사용 통계 집계를 검증합니다.
- 세 번역 모드의 설정 마이그레이션과 실행 흐름, 검색·정렬·필터·ID 기반 수정·다중 삭제 UI를 테스트합니다.
- 누적 컨텍스트와 관리 화면의 안내를 한국어, 영어, 일본어, 중국어 간체와 번체에 추가했습니다.
