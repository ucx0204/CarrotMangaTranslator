# v3.8.13

## RX 7600에서 HayaiOCR GPU 선택

Windows에서 Radeon RX 7600을 사용하면 **설정 → OCR → HayaiOCR → AMD ROCm**을 선택할 수 있습니다. 이전 버전은 구형 PaddleOCR의 지원 목록을 HayaiOCR에도 적용해서 버튼을 비활성화했습니다. 새 설정에서는 HayaiOCR가 GPU를 기본으로 사용합니다. 기존에 CPU를 저장한 경우에는 AMD ROCm을 선택하고 저장하세요.

RX 7600용 Windows 패키지 세 개를 내려받아 무결성을 확인하고, 설정 저장 후 Hayai용 ROCm 10 설치 경로가 선택되는 것을 검증했습니다. RX 7600 실물에서의 글자 인식은 아직 확인하지 못했습니다. PaddleOCR(레거시)는 이 카드에서 CPU를 사용합니다.

## FLUX 인페인팅과 긴 작품의 폰트 자동 맞춤

- FLUX에서 Vulkan을 선택하면 실행기에 모델 파일 경로가 전달되도록 수정했습니다. 모델 인수가 빠져 첫 인페인팅이 실패하던 문제를 해결했습니다.
- 폰트 자동 맞춤의 작업 제한 시간을 페이지 수에 따라 늘려, 200페이지가 넘는 작품이 처리 도중 고정 시간 제한에 걸리던 문제를 개선했습니다.
