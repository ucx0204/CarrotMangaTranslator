# v1.18.2 패치노트

기준 범위: `v1.18.1` 태그와 이번 `v1.18.2` 최종 트리를 직접 비교했습니다.

v1.18.2는 v1.18.1에서 발견된 Electron 시작 오류를 수정한 패치 릴리스입니다.

## 앱 시작 및 패키지 검증 수정

- 관리형 Python 설치를 호스트의 pip 설정과 격리하는 공용 런타임 모듈이 Electron 메인 프로세스 출력에서 누락되던 문제를 수정했습니다. 이 문제로 개발 앱 또는 설치 앱이 시작할 때 `python-pip-environment.cjs`를 찾지 못하고 종료될 수 있었습니다.
- Electron 컴파일과 개발 빌드 캐시가 해당 공용 모듈의 입력·출력을 명시적으로 추적하고, 파일이 누락되면 빌드를 성공으로 캐시하지 않도록 보강했습니다.
- Windows 패키지 검증에서 격리된 데이터 폴더로 실제 설치 앱을 실행하고 전체 Electron 메인 모듈 그래프가 로드됐는지 확인해, 같은 종류의 런타임 의존성 누락이 설치파일 검증을 통과하지 못하도록 했습니다.
