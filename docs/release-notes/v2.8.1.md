# v2.8.1 — 작업 환경 백업과 이미지 모델 선택

## 백업 및 PC 이관

- 설정 → 일반에 **백업 및 이관**을 추가했습니다. 보관함 원본과 편집 데이터, 재개용 체크포인트, 설정, 추가 폰트, 프리셋과 가리기 초안을 ZIP으로 내보내고 가져올 수 있습니다.
- 가져올 백업을 먼저 검증하고 기존 환경을 보존한 뒤 앱을 재시작해 복원합니다. 같은 화면에서 이전 환경으로 되돌릴 수 있습니다.
- 백업 전에 진행 중인 편집을 저장하고 작업 충돌을 방지합니다. API 키·로그인 세션·서비스 계정 파일, 사용자 지정 API 헤더·추가 요청 본문, 모델·런타임·로그·캐시는 백업에서 제외합니다.
- 외부 연결 폴더와 별도 출력물은 따로 옮겨 다시 연결해야 합니다. 복원 후 인증과 PC별 모델·GPU 설정을 확인하세요.

## Codex 이미지 작업

- 이미지 생성 모델로 **GPT Image 2.5 Flare**, **GPT Image 2.5 Sunburst**, **Codex 기본**을 선택할 수 있습니다. 기본값은 Flare이며 작업을 지시하는 Codex 모델과 별도로 설정합니다.
- 이미지 작업을 지시하는 모델 선택을 계정 카탈로그의 GPT-5.6 이상 모델로 확대했습니다. GPT-5.6 계열에는 이미지 작업 품질 안내를 유지합니다.
- Codex 런타임을 0.156.1로 업데이트했습니다. 이미지 생성 스트림의 완료·실패·취소 처리를 보강했습니다.
- Images 2.5 연결은 기존 ChatGPT 로그인을 사용합니다. ChatGPT 백엔드 변경에 영향을 받을 수 있으며 요청 실패 시 다른 모델로 자동 전환하지 않습니다.

## 편집 및 키보드 동작

- 모달과 드롭다운에서 Escape를 처리할 때 뒤쪽 작업 화면이나 다른 모달에 동시에 전달되는 문제를 수정했습니다.
- 효과음 검토의 선택 영역 삭제와 키보드 처리를 현재 모달 범위로 제한하고, 텍스트 입력 중 삭제 키와 조합 입력 처리를 보완했습니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다. 각 플랫폼의 릴리스 절차에서 패키지와 실행 여부를 검증합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
