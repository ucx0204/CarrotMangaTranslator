# v1.2.1 패치노트

기준 범위: `v1.2.0` 이후부터 `v1.2.1`까지의 변경 사항입니다.
주요 포함 변경: 통합 실행 취소·다시 실행, 현재 페이지 중심 자동 지우기, 인페인팅 작업 전환 및 패널 UI 개선, 이미지 리비전 안정성 강화와 v1.2.1 릴리즈 준비 변경.

## 새 기능 및 개선

### 텍스트와 인페인팅을 하나의 실행 취소 기록으로 통합

- 텍스트 블록 편집, 블록 이동과 크기 조절, 자동 지우기 제외 설정, 마스크 그리기, 그린 영역 지우기, 브러시·복원 보정, 자동 지우기와 원본 초기화를 하나의 시간순 기록으로 통합했습니다.
- 캔버스의 같은 실행 취소·다시 실행 버튼과 `Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+Y`가 현재 도구와 관계없이 가장 최근 작업을 순서대로 되돌립니다.
- 버튼에 다음으로 취소하거나 다시 실행할 작업명을 표시해 어떤 변경이 적용될지 미리 확인할 수 있습니다.
- 현재 화에서 최대 60단계를 유지하며, 타이핑과 드래그처럼 짧은 시간에 이어지는 같은 작업은 한 단계로 묶습니다.
- 여러 페이지 자동 지우기는 선택한 전체 결과를 한 번에 되돌리며, 취소 시 일부 페이지만 완료된 경우에도 완료된 결과를 한 단계로 취소할 수 있습니다.
- `원본으로 초기화`도 실행 취소와 다시 실행을 지원해, 자동 지우기 결과가 좋지 않을 때 원본으로 돌아간 뒤 필요하면 다시 복원할 수 있습니다.

### 현재 페이지 중심의 자동 지우기

- 자동 지우기 주 버튼을 누르면 별도의 페이지 선택창 없이 현재 페이지를 바로 확인하고 실행합니다.
- 여러 화·페이지를 처리할 때만 보조 메뉴의 `여러 페이지 선택…`을 사용하도록 작업 흐름을 분리했습니다.
- 여러 페이지 선택창의 시작 버튼을 최종 확인으로 사용해 중복 확인 창을 제거했습니다.
- 선택창을 취소하거나 자동 지우기가 끝나도 선택한 텍스트 블록과 편집 패널을 그대로 유지합니다.
- 자동 지우기 실행 중에만 편집 입력을 잠그고, 완료 직후 현재 블록을 다시 편집할 수 있습니다.

## 사용성 개선

### 캔버스와 오른쪽 패널 정리

- 실행 취소, 다시 실행, 원본 비교와 원본 초기화를 캔버스 오른쪽의 세로 아이콘 작업 막대로 배치해 원고를 가리지 않도록 했습니다.
- 자동 지우기 보조 메뉴에서 긴 설명을 제거하고 `여러 페이지 선택…`, `자동 지우기 사용 안내` 두 작업만 간결하게 표시합니다.
- 오른쪽의 표시 기능을 배경·테두리, 블록 표시, 텍스트 모아보기, 용어·기억 아이콘 한 줄로 통합했습니다.
- 운영체제 기본 툴팁 대신 앱 전용 툴팁을 사용하고, 좁은 화면에서도 작업 막대와 패널이 원고 위에 겹치지 않도록 반응형 배치를 다듬었습니다.
- 블록 편집기의 `자동 지우기에서 제외`를 한 줄 스위치로 줄이고, 제외된 블록은 글자를 가리지 않는 작은 아이콘으로 표시합니다.
- 선택 블록의 크기 조절 손잡이를 바깥쪽 모서리 형태로 바꿔 좁은 세로 블록에서도 글자가 가려지지 않도록 했습니다.

## 성능 및 안정성 개선

### 안전한 이미지 실행 취소와 다시 실행

- 자동 지우기, 그린 영역 지우기와 브러시 결과를 고유한 불변 이미지 파일로 저장해 새 작업이 이전 결과를 덮어쓰지 않도록 했습니다.
- 여러 페이지 작업을 하나의 이미지 리비전 트랜잭션으로 관리하고, 실행 취소·다시 실행 전에 각 페이지의 현재 이미지 상태를 검증합니다.
- 여러 화를 갱신하는 작업은 하나의 보관함 잠금 안에서 처리하며, 중간 저장이 실패하면 이미 적용한 변경을 이전 상태로 되돌립니다.
- 되돌리기까지 실패한 경우 보관함의 실제 상태를 다시 읽고 더 이상 안전하게 사용할 수 없는 기록만 폐기합니다.
- 새 작업으로 다시 실행 기록이 사라지거나 60단계 기록에서 오래된 작업이 빠질 때, 더 이상 참조되지 않는 중간 이미지 파일을 정리합니다.
- 앱 종료 시 진행 중인 인페인팅 작업과 리비전 정리가 충돌하지 않도록 종료 순서를 보강했습니다.

## 내부 정리 및 테스트

- 텍스트·마스크·이미지 작업이 섞인 기록 순서, 600ms 작업 합치기, 다시 실행 폐기와 60단계 제한을 순수 기록 모델 테스트로 고정했습니다.
- 자동·수동 인페인팅의 이전 결과 복원, 배치 전체 취소, 부분 완료, 경로 충돌, 저장 실패 롤백과 참조 이미지 정리를 main/IPC 테스트로 검증합니다.
- 현재 페이지 실행과 여러 페이지 선택 흐름, 선택·입력 유지, 제외 스위치와 배지, 원본 초기화, 버튼과 세 단축키의 동일 기록 사용을 UI 테스트로 검증합니다.
- 실제 Chromium에서 1600×980, 1240×760, 1120×760 화면을 조작하고 작업 막대, 메뉴, 편집기와 반응형 레이아웃을 확인했습니다.
