# v2.6.2

## 영역 번역

- 원문 지우기에서 **기본**을 선택했을 때 작은 영역에 글자가 남거나 단색으로 채워지던 문제를 수정했습니다. 설정된 인페인팅 모델이 주변 배경을 참고하며, 결과는 선택 영역 안에만 반영합니다.

## 일괄 편집

- 줄바꿈 선택지를 일반 서식과 통일했습니다. **단어 단위+넘침 방지**를 포함해 같은 이름의 옵션이 같은 방식으로 적용됩니다.
- 줄 간격·장평·글자 투명도 등의 이름을 일반 서식과 맞췄습니다. 조건, 부분 서식, 적용 값과 결과에서 `%`, `px`, `em` 등의 단위를 일관되게 표시합니다.
- 기본 글꼴을 조건으로 선택했을 때 대상이 제대로 잡히지 않던 문제를 수정했습니다.
- 글꼴 굵기가 저장된 서식 프리셋을 적용할 수 없던 문제를 수정했습니다. 굵기만 바꾸는 경우도 미리보기와 실제 적용에 반영됩니다.
- 글꼴이나 굵게 속성을 수동 변경해도 이전 자동 지정 굵기가 남던 문제를 수정했습니다.
- 비활성화한 프리셋 작업에서 프리셋을 바꾸면 작업이 다시 켜지던 문제를 수정했습니다. 작업 메모도 유지됩니다.
- 부분 서식에서 밑줄·취소선·강조점 등이 꺼진 글자를 조건으로 선택할 때 일부 대상이 누락되던 문제를 수정했습니다.
- 고급 정규식 치환에서 일치하지 않은 선택 캡처의 참조 기호가 번역문에 남던 문제를 수정했습니다.
- 용어집을 불러오기 전이나 불러오기에 실패했을 때 빈 용어집으로 조건을 판정하던 문제를 수정했습니다. 작품을 바꾼 뒤 이전 작품의 용어집으로 판정하는 것도 방지합니다.
- 규칙 삭제 후 연결된 연속 실행에 비활성 단계만 남으면 삭제가 실패하던 문제를 수정했습니다.

- Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다.
