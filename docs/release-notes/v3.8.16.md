# v3.8.16

## 환경 백업 복원

- 백업 ZIP에 작품과 화 파일이 있어도 보관함 목록에서 누락되던 문제를 수정했습니다. 파일을 검증한 뒤 기존 순서를 유지하면서 누락된 작품과 화를 목록 끝에 추가합니다. 가져오기 확인창에도 복구할 작품과 페이지 수가 표시됩니다.
- 앱 시작 시 목록에서 빠진 작품·화 폴더에 파일이 남아 있으면 그대로 보존합니다.
- v3.8.15에서 백업을 가져온 뒤 목록이 비었다면, v3.8.16으로 업데이트한 후 **설정 → 일반 → 백업 및 이관**에서 기존 ZIP을 다시 선택하세요. 확인창의 작품·페이지 수를 확인하고 **복원하고 앱 다시 시작**을 누르면 됩니다.

## 설치 파일과 서명

- Windows 10/11 x64 — `CarrotMangaTranslator-Setup-v3.8.16.exe`. 코드 서명 없음.
- Apple Silicon macOS 14 이상 — `CarrotMangaTranslator-3.8.16-macOS-arm64.dmg`와 `.zip`. Ad-hoc 서명, Apple 공증 없음.
- 플랫폼별 SHA-256 체크섬과 빌드 출처 파일을 함께 제공합니다.
