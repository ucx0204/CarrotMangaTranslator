# v2.4.3 패치노트

## 곡선 텍스트 서식

- 텍스트 블록을 곡선 배치로 바꿔도 굵기와 기울임이 유지되도록 수정했습니다.
- 곡선 텍스트의 밑줄과 취소선을 글자 기준선에 맞춰 직접 그리도록 변경해 밑줄이 글자 위에 나타나거나 장식된 글자가 겹쳐 그려지던 문제를 해결했습니다.
- 블록 전체 서식과 글자별 서식이 같은 장식 판정 로직을 사용하도록 통합하고, 결합 문자와 조합형 이모지가 곡선에서 여러 글자로 분리되지 않도록 수정했습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다.
- Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다.
