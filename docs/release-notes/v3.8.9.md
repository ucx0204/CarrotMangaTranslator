# v3.8.9

MCP 작업에서 기다려도 해결되지 않는 제한 초과를 일시적인 작업 충돌로 안내하던 문제를 수정했습니다. 오류 원인에 맞춰 재시도 가능 여부와 다음 조치를 구분합니다. ([#178](https://github.com/ucx0204/CarrotMangaTranslator/issues/178))

## MCP 오류 안내 개선

- **작업 진행 중:** 기존 작업이 끝난 뒤 재시도하도록 안내합니다.
- **계획 크기 초과:** 같은 요청의 재시도를 중단하고 요청 대상을 나누도록 안내합니다.
- **계획 보관 한도:** 작업 종료만 기다리는 대신 보관 계획의 만료·해제 후 재시도하도록 안내합니다.
- **작업 이력 한도:** 현재 저장 상태를 확인하고 남은 변경만 새로 계획하도록 안내합니다.
- **이미지 복구 참조 한도:** 단순 대기로 해결되지 않음을 알리고, 필요한 복구를 마친 뒤 편집 세션을 다시 열도록 안내합니다. 완료한 편집을 반복하거나 복구 데이터를 삭제하도록 유도하지 않습니다.
- 외부 MCP와 앱 내 대화의 공통 안내를 함께 갱신했습니다. 기존 보호 한도와 저장·복구 동작은 유지합니다.

## 검증 범위

- 크기 초과 요청의 반복 실패와 대상 분할, 계획 만료 후 재시도, 중복 요청의 추가 저장 방지를 검증했습니다.
- 격리된 보관함에서 실제 이미지 편집 64회 후 한도 도달, 기존 편집의 실행 취소·다시 실행, 대기 후에도 유지되는 참조 한도를 검증했습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.9.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.9-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
