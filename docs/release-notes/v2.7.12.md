# v2.7.12 — 자동 저장 안정화와 작업 중 편집·반응성 개선

## 자동 저장 중에도 편집 계속하기

- 결과물을 자동 저장하는 동안 같은 페이지의 텍스트·서식을 계속 수정할 수 있습니다. 저장을 시작할 때의 사본으로 결과물을 만들고, 그동안 추가한 수정은 다음 저장에 반영합니다.
- 입력할 때마다 진행 중인 결과물 렌더링을 취소하던 동작을 개선했습니다. 저장 준비 중 내용이 바뀌었을 때도 정상적인 편집을 저장 실패로 처리하지 않습니다.
- 최신 결과물이 이미 저장됐는데 이전 버전의 실패 기록 때문에 계속 **자동 저장 실패**로 표시되던 문제를 수정했습니다. 앱을 다시 시작할 때 완료된 항목을 정리하고, 아직 저장되지 않은 최신 수정은 대기열에 남깁니다.
- 실제 저장 오류와 재시도 한도는 유지합니다. 실패한 화·페이지와 상세 원인을 로그에 남기며, 삭제된 화의 오래된 동기화 연결도 정리합니다.

## 보관함 로딩과 삭제

- 보관함을 열 때 변경되지 않은 원본·복구용 이미지의 전체 내용을 반복해서 읽고 해시하던 작업을 줄였습니다. 파일이 변경되면 다시 검증합니다.
- 동기화 대상의 소유 작품을 알고 있을 때 다른 작품까지 매번 검색하던 비용을 줄였습니다.
- 작품·화 삭제 시 기본 결과 폴더의 해당 생성 파일도 함께 정리합니다. 직접 지정한 폴더의 생성 파일 삭제는 확인창에서 기본 선택되며, 체크를 해제하면 보존할 수 있습니다.
- 삭제 대상의 동기화가 종료된 뒤 파일을 정리해 늦게 도착한 결과가 폴더를 다시 만드는 문제를 방지합니다. 원본과 다른 작품의 파일을 보호하고, 삭제 도중 실패하거나 앱이 종료되면 복구 기록을 바탕으로 처리합니다.

## 작업 중에도 관련 없는 조작 계속하기

- 처리 중인 페이지와 관계없는 페이지의 편집·저장, 다른 화의 서식 적용, 웹 원본 검색·가져오기 준비가 불필요하게 막히던 경로를 개선했습니다.
- 문맥 분석이 사용하는 입력과 결과 적용 범위에 맞춰 잠금을 설정합니다. OCR·번역·인페인팅 등 무거운 모델 작업은 계속 직렬로 실행하며, 같은 페이지·공유 문맥·출력 경로의 충돌 보호도 유지합니다.
- 처리 중인 페이지에서도 블록 선택과 텍스트 확인·복사가 가능합니다. 실제 내용을 바꾸는 조작은 계속 보호합니다.
- 작업 중에도 번역·인페인팅 옵션을 열어 확인할 수 있습니다. 모델을 실행하는 시점에는 기존 자원 충돌 검사를 적용합니다.

## 작업센터와 반응성

- 여러 작업이 함께 표시될 때 완료 기록 때문에 진행 중인 작업이 목록에서 사라지지 않도록 수정했습니다. 배경 작업의 완료도 기록하고, 뒤늦게 도착한 진행 이벤트가 완료 상태를 되돌리지 않도록 했습니다.
- 반복되는 진행률 갱신을 묶어 화면 갱신과 통신 부담을 줄였습니다. 완료·오류·취소는 즉시 반영합니다.
- 긴 페이지 목록에서 화면 밖 행의 렌더링과 스크롤 중 불필요한 갱신을 줄였습니다. 페이지 내용이 갱신될 때 스크롤 위치가 선택 페이지로 되돌아가던 문제도 수정했습니다.
- 페이지 이동 시 잠금 목록과 파생 정보를 반복 계산하던 비용, 저장 응답의 중복 비교, 검수표 가져오기의 반복 페이지 복사를 줄였습니다.

## 설정과 편집 화면 정돈

- 설정과 서식 화면의 반복 설명·제목·테두리·여백을 정리하고, 관련 컨트롤에서 마우스나 키보드 포커스로 도움말을 확인할 수 있게 했습니다.
- OCR 실행 장치, 인페인팅 백엔드, GPU 배정 등 설정을 불필요하게 접어 숨기던 구성을 정리했습니다. 창 크기에 맞춰 설정 본문과 하단 조작 영역을 조정했습니다.
- 설정을 저장할 수 없을 때 원인을 표시하고 해당 설정으로 이동할 수 있게 했습니다.
- 숫자 입력·슬라이더·선택 버튼의 정렬과 표시를 맞추고, 비활성 컨트롤의 도움말 접근을 개선했습니다.
- 작업 기록 등에 번역 키가 그대로 표시되던 문제와 효과음 버튼의 반복 애니메이션을 수정했습니다.
- 좁은 화면이나 확대 상태에서 좌우 패널을 열면 캔버스가 잘못된 열로 밀려 사라지던 배치 문제를 수정했습니다.

## 글자별 장평과 변형 워프

- **블록 → 번역문 → 편집 → 글자별 서식 → 장평**이 일부 글꼴에서 실제 글자 폭에 반영되지 않던 문제를 수정했습니다. 편집기와 페이지 출력의 글자·외곽선 폭을 함께 맞추고, 글꼴 로드 후에도 다시 반영합니다.
- 변형 워프 프리셋에 **아치 왼쪽**, **아치 오른쪽**을 추가했습니다. 기존 저장 형식을 그대로 사용합니다.

## 검증 범위

격리된 일반·긴 원고로 페이지 이동, 진행 이벤트 집중 발생, 다른 페이지 편집·자동 저장과 확대 화면을 확인했습니다. 모델 직렬 실행, 입력 마무리, 저장 중 추가 편집, 오래된 실패 기록 복구, 삭제 실패·복구, 취소와 늦은 응답에 대한 회귀 검사를 수행했습니다. 모델 추론 자체의 속도 개선이나 장시간 모델 실행 검증은 이번 변경에 포함하지 않습니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS용 DMG·ZIP을 제공합니다. 각 플랫폼의 릴리스 절차에서 패키지와 실행 여부를 검증합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
