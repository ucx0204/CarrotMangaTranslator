# v0.9.0 패치노트

기준 범위: `v0.8.4` 이후부터 `v0.9.0`까지의 변경 사항입니다.
포함 커밋: `de879fd`, `4cdea50`, `52fcca0`, `ba0334a`, `935a5cf`.

## 새 기능

### 번역 범위 선택 강화

- 번역 시작 모달에서 작품 안의 화와 페이지를 직접 선택할 수 있습니다.
- `전체 선택`, `미번역만`, `전체 해제` 버튼으로 큰 범위를 빠르게 잡을 수 있습니다.
- 화를 펼치면 페이지 썸네일이 표시되고, 필요한 페이지 하나하나를 체크해 번역할 수 있습니다.
- 선택 요약에 몇 개 화와 몇 페이지가 번역 대상인지 표시됩니다.
- 현재 화가 아닌 다른 화의 페이지 목록은 필요할 때만 불러와, 큰 작품에서도 모달을 가볍게 열 수 있습니다.
- 직접 선택한 페이지 묶음은 새 `page-set` 실행 모드로 처리되어, 선택하지 않은 페이지의 상태와 편집 결과를 건드리지 않습니다.

### 기존 블록 유지 번역 모드

- 번역 옵션에 `블록` 선택을 추가했습니다.
  - `자동 생성`: 기존 방식처럼 OCR과 AI 분석으로 블록을 새로 만듭니다.
  - `기존 블록 유지`: 이미 있는 블록의 위치, 크기, 방향, 폰트, 색상, 외곽선 같은 레이아웃/서식을 유지하고 텍스트만 다시 채웁니다.
- `기존 블록 유지`는 수동으로 말풍선 배치와 서식을 손본 페이지를 다시 번역할 때 유용합니다.
- 블록이 있는 페이지는 각 블록 영역을 잘라 OCR 힌트를 만들고, 모델 응답을 기존 블록에 다시 매핑합니다.
- 모델이 기존 후보 id를 돌려주지 못해도 bbox 겹침 기준으로 가능한 블록에 연결합니다.
- 기존 블록과 연결되지 않는 새 항목은 버려, 사용자가 이미 정리한 레이아웃이 갑자기 늘어나거나 흐트러지는 일을 줄였습니다.
- 블록이 없는 페이지는 `기존 블록 유지`를 골라도 자동 생성 경로로 처리됩니다.

### 페이지 재번역 흐름 추가

- 현재 페이지만 다시 번역하는 `페이지 재번역` 모달을 추가했습니다.
- 페이지 재번역에서도 `자동 생성`과 `기존 블록 유지`를 선택할 수 있습니다.
- 재번역 전 현재 페이지 이름과 블록 수를 보여주어, 어떤 페이지가 덮어써질지 확인할 수 있습니다.
- `기존 블록 유지`를 선택하면 현재 페이지의 블록 영역과 서식을 그대로 두고 각 영역의 텍스트만 다시 채웁니다.
- `자동 생성`을 선택하면 현재 페이지의 기존 블록을 지우고 새 OCR/AI 분석 결과로 다시 만듭니다.

### 작업 영역 도구 모음

- 페이지 작업 영역 왼쪽에 `선택`, `블록`, `손바닥` 도구 모음을 추가했습니다.
- `선택` 도구는 기존처럼 블록 선택, 이동, 크기 조절에 사용합니다.
- `블록` 도구는 페이지 위를 드래그해 새 텍스트 블록을 직접 추가합니다.
- `손바닥` 도구는 확대된 작업 영역에서 블록을 건드리지 않고 페이지를 끌어 이동합니다.
- 도구 모음은 접거나 다시 펼칠 수 있습니다.
- 기본 단축키는 `1` 선택, `2` 블록, `3` 손바닥, `4` 도구 모음 표시 전환입니다.

### 블록 편집기 분리

- 오른쪽 블록 편집기를 앱 안의 떠 있는 패널로 띄울 수 있습니다.
- 편집기를 별도 OS 창으로 분리할 수도 있습니다.
- 떠 있는 패널은 드래그와 크기 조절을 지원합니다.
- 별도 창은 닫거나 도킹 버튼을 누르면 다시 오른쪽 패널 자리로 돌아갑니다.
- 별도 창의 위치와 크기는 저장되어 다음에 열 때 최대한 같은 위치를 사용합니다.
- 분리한 편집기에서도 선택 블록, 서식 적용, 복제, 삭제, 영역 번역 같은 기존 편집 동작을 그대로 사용할 수 있습니다.

### TXT 왕복 편집 개선

- `텍스트 모아보기`에서 `한국어만` 형식으로 저장한 TXT를 다시 불러올 수 있습니다.
- TXT 불러오기는 줄 순서 기준으로 번역문만 업데이트하고, OCR 원문과 블록 위치는 바꾸지 않습니다.
- 페이지 머리말이 있는 파일은 현재 페이지/전체 화 구조에 맞춰 페이지별로 반영합니다.
- 머리말이 없는 파일은 현재 표시 범위가 한 페이지일 때만 안전하게 적용합니다.
- 줄 수가 맞지 않는 페이지, 알 수 없는 페이지 머리말, 비어 있는 파일은 경고로 알려주고 무리하게 적용하지 않습니다.
- TXT 불러오기 결과는 하나의 편집 단계로 처리되어 실행 취소 흐름과 함께 다루기 쉽습니다.

## 개선 및 수정

### 번역 진행 상태와 선택 페이지 처리

- `미번역만`, 단일 페이지, 페이지 묶음 실행에서 실제 요청한 페이지만 실행 중 상태로 표시되도록 정리했습니다.
- 빈 페이지 묶음 요청은 화 상태를 건드리지 않도록 처리했습니다.
- 번역 작업 중 들어오는 라이브 갱신이 사용자가 방금 고친 완료 페이지를 덮어쓰지 않도록 보존 로직을 보강했습니다.
- 페이지 재번역, 선택 페이지 번역, 2차 번역이 같은 선택 구조를 공유하도록 UI와 실행 옵션을 정리했습니다.

### 텍스트 모아보기와 검수표 안정성

- 텍스트 모아보기의 검색/하이라이트 계산을 분리해, 표시 줄과 검색 결과가 더 일관되게 맞도록 정리했습니다.
- TXT 불러오기에서 한국어 Windows 환경의 CP949/Windows-949 텍스트도 읽을 수 있게 보강했습니다.
- 검수표 가져오기에서 같은 `block_id`가 여러 페이지에 있을 때 `page_id`와 함께 더 안전하게 찾도록 했습니다.
- OCR 원문 불일치, 잘못된 검수 상태, 없는 block id 같은 문제를 경고로 유지하면서 적용 가능한 행은 계속 처리합니다.

### 작업 영역 조작 개선

- 새 블록을 드래그로 만들 때 너무 작은 영역은 생성하지 않고 상태 메시지로 알려줍니다.
- 확대된 작업 영역에서 휠/드래그 이동이 페이지 전환이나 블록 조작과 덜 충돌하도록 정리했습니다.
- 선택 도구, 블록 도구, 손바닥 도구가 각자의 pointer 처리만 담당하도록 hook을 나눴습니다.

### 패널 창 안정성

- 분리한 편집기 창과 메인 창 사이에 필요한 상태와 명령만 주고받도록 panel bridge를 추가했습니다.
- 분리 창이 열려 있을 때도 메인 창의 선택 블록과 편집 명령이 동기화됩니다.
- 저장된 패널 창 위치가 현재 연결된 모니터 밖에 있으면 위치는 버리고 크기만 재사용해 창이 화면 밖에 생기는 일을 막았습니다.
