# v1.2.0 패치노트

기준 범위: `v1.1.0` 이후부터 `v1.2.0`까지의 변경 사항입니다.
주요 포함 변경: API 공급자 빠른 설정, 이미지 입력 모델 자동 검색, 여러 API 키 순환 재시도, Google AI Studio 모델 검색 수정 및 v1.2.0 릴리즈 준비 변경.

## 새 기능 및 개선

### API 공급자 빠른 설정

- 설정의 API 번역 엔진에 NVIDIA NIM, Google AI Studio, Google Vertex AI, OpenRouter 템플릿을 추가했습니다.
- 템플릿을 선택하면 공급자에 맞는 API Base URL을 자동으로 입력하고, Vertex AI는 Google Cloud 프로젝트 ID와 리전을 받아 OpenAI 호환 엔드포인트를 구성합니다.
- 공급자별 API 키 발급 페이지 또는 Vertex 인증 안내를 설정에서 바로 열 수 있습니다.
- 템플릿을 사용하더라도 Base URL과 모델 ID는 언제든 직접 입력할 수 있어 사설·셀프호스트 OpenAI 호환 API도 계속 사용할 수 있습니다.

### 이미지 입력 모델 자동 검색

- 각 공급자의 현재 모델 목록을 조회하고 이미지 입력을 확인할 수 있는 모델만 드롭다운에 표시합니다.
- NVIDIA NIM은 라이브 모델 목록과 NVIDIA Image-to-Text 카탈로그를 교차 확인합니다.
- OpenRouter는 모델 메타데이터에서 이미지 입력과 텍스트 출력을 모두 선언한 모델만 표시합니다.
- Google AI Studio와 Vertex AI는 실제 1×1 PNG가 포함된 `countTokens` 요청에서 이미지 토큰이 확인된 모델만 표시합니다.
- 드롭다운에서 모델을 고르면 해당 Base URL과 모델 ID를 자동으로 채우며, 선택 후에도 두 값을 직접 수정할 수 있습니다.
- Google 네이티브 모델 목록과 OpenAI 호환 모델 목록 사이의 `models/` 접두사 차이를 정규화해 AI Studio 검색 결과가 0개가 되던 문제를 수정했습니다.

### 여러 API 키 순환 재시도

- API 키 입력을 여러 줄 textarea로 바꾸고 한 줄에 키 하나씩 설정할 수 있게 했습니다. 빈 줄과 중복 키는 자동으로 무시합니다.
- 요청이 실패하면 다음 줄의 키로 이동하고, 모든 키를 한 번씩 사용한 뒤 다시 첫 키로 돌아가는 순환 재시도를 적용했습니다.
- 키별 최대 시도 횟수와 재시도 대기 시간을 설정할 수 있습니다.
- 일반 번역, 작품 컨텍스트 분석, 모델 연결 테스트에 같은 키 순환 정책을 적용했습니다.
- 인증 실패, 할당량·속도 제한, 일시적인 서버·전송 오류에서는 다음 키를 시도하고, 잘못된 일반 요청은 불필요하게 다른 키로 반복하지 않습니다.

## 안정성 및 안전성 개선

- 모델 연결 테스트가 실제 1×1 PNG 이미지를 보내도록 바꿔 이미지 입력을 지원하지 않는 모델을 미리 확인할 수 있습니다.
- 여러 줄에 입력한 모든 API 키를 오류 메시지와 구조화된 응답 정보에서 마스킹합니다.
- 사용자 정의 헤더가 순환 중인 `Authorization` 헤더를 덮어쓰지 못하도록 검증과 병합 순서를 강화했습니다.
- 모델 검색에 요청별 제한 시간, 전체 60초 제한, 페이지 반복 방지, 후보 수와 동시성 제한을 추가했습니다.
- NVIDIA Image-to-Text 카탈로그를 확인하지 못하면 검증되지 않은 정적 목록을 사용하지 않고 안전하게 검색을 중단합니다.
- API 키는 로컬 `settings.json`에 평문으로 저장된다는 안내를 설정 화면에 표시합니다.
