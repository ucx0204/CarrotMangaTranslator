# v1.18.0 패치노트

기준 범위: `v1.17.2` 태그와 이번 `v1.18.0` 최종 트리를 직접 비교했습니다. 아래에는 두 최종 버전 사이에 실제로 남은 차이만 기록했습니다.

v1.18.0은 말풍선·텍스트 감지와 원문 지우기 마스크를 KoharuLayout 기반으로 교체하고, 페이지와 화 단위의 폰트 일관성 및 고정 블록 번역의 완결성을 개선한 품질 업데이트입니다.

## KoharuLayout 말풍선·텍스트 감지

- 기존 만화 말풍선 감지 모델을 KoharuLayout RF-DETR 세그먼테이션 모델로 완전히 교체했습니다. 원본 페이지에서 텍스트, 효과음, 말풍선, 패널의 영역과 윤곽을 함께 찾으며 기존 감지기로 되돌아가는 fallback은 없습니다.
- 말풍선 자동 맞춤은 검출 사각형이 아니라 KoharuLayout의 실제 instance mask를 사용합니다. 글자 크기와 외곽선 두께를 반영한 안전 여백을 안쪽에 적용하고, 이어진 말풍선을 여러 블록이 공유하면 소유 영역을 나눠 서로 침범하지 않도록 했습니다.
- 모델은 첫 사용 시 체크섬을 검증해 데이터 폴더에 내려받고 이후 캐시를 재사용합니다. 한 번의 인페인팅 작업에서는 페이지마다 모델을 다시 올리고 내리지 않고 같은 세션을 재사용하며, 작업이 끝나면 세션을 해제합니다.
- Windows에서는 DirectML을 먼저 사용하고 사용할 수 없으면 최대 8개 논리 스레드의 CPU 경로로 전환합니다. Apple Silicon macOS에서는 CPU 경로를 사용합니다.

## 텍스트·효과음 중심 원문 지우기

- KoharuLayout의 텍스트·효과음 세그먼트를 원문 지우기의 최종 합성 마스크에 연결했습니다. 검은 글자의 두꺼운 흰 테두리까지 남지 않도록 완전 삭제 코어를 먼저 충분히 확장하고, 그 바깥에 별도의 feather 영역을 적용합니다.
- 코어와 feather 폭은 고정 픽셀이 아니라 페이지 짧은 변, 글자 크기, 현재 외곽선 두께를 함께 사용해 계산하므로 해상도가 다른 만화 페이지에서도 비슷한 비율로 동작합니다.
- 인페인팅 모델에는 주변 문맥을 포함한 넓은 영역을 전달하되, 생성 결과는 텍스트·효과음 코어와 feather 영역을 따라 원본에 합성합니다. 이어진 말풍선의 공유 작업 창은 하나로 묶어 블록 경계에서 이음새가 생기는 문제를 줄였습니다.

## 폰트 자동 맞춤과 페이지 일관성

- 기본 폰트 자동 맞춤 런타임을 R33으로 갱신했습니다. 각 블록의 픽셀 후보뿐 아니라 같은 페이지의 일반 대사와 같은 화에서 누적된 신뢰도 높은 본문 선택을 함께 사용해, 나눔 계열·리디바탕 계열 같은 본문 폰트가 불필요하게 오가는 현상을 줄였습니다.
- 페이지 공통 폰트는 각 블록의 원래 픽셀 후보 상위 3개 안에서만 선택합니다. 일부 블록이 공통 후보를 지지하지 않아도 지지하는 다수 블록에는 합의를 적용할 수 있으며, 지지하지 않는 블록은 개별 시각 선택을 유지합니다. 효과음과 명확한 강조 표현은 페이지 본문 합의 대상에서 제외합니다.
- 원문 글자 모양과 한국어 후보 글꼴을 직접 비교하는 cross-script 시각 프록시를 일반 문장에 추가했습니다. 출력 후보는 기존 한국어 폰트 21종으로 유지하며 일본어 글꼴을 결과 후보로 추가하지 않습니다.
- 자동 맞춤이 보정 단계에서 보류되더라도 정상 렌더된 모델 후보가 있으면 기본 서식 폰트를 그대로 남기지 않고 최상 후보를 선택합니다. 사용자가 직접 고정한 서식은 계속 우선합니다.
- 자동 맞춤은 글꼴과 굵게·기울임 선택만 적용하며 사용자가 정한 외곽선 두께를 학습값이나 과거 기본값으로 덮어쓰지 않습니다.

## 번역 누락 방지와 제한적 조판 의도

- 고정 블록 번역에서 빈 한국어, 일본어 잔존, 중복·누락 블록, 잘못된 역할이나 형식이 발견되면 문제가 있는 블록만 최대 3회 다시 요청합니다. 이미 정상 번역된 문장은 재시도 과정에서 다시 쓰지 않습니다.
- 역할·조판 판단만 충돌하고 번역문 자체는 정상인 블록은 보존한 문장을 가로 조판으로 안전하게 복구합니다. 끝까지 해결되지 않은 블록은 조용히 빼고 부분 결과를 저장하지 않고 해당 요청을 실패 처리합니다.
- 한국어 일반 대사와 말풍선은 가로 조판을 기본으로 유지합니다. 세로 조판은 말풍선 밖 페이지 외곽의 길고 좁은 설명문·내레이션이며 모델 역할 신뢰도가 충분한 경우에만 적용됩니다. 사용자가 방향을 직접 바꾸거나 기본 서식으로 지정한 선택은 이후 번역에서도 모델 권고보다 우선합니다.

## 설치 용량과 런타임 안정성

- 폰트 매칭 본체와 cross-script 프록시 모델은 설치파일에 포함하지 않습니다. 자동 폰트 맞춤을 처음 사용할 때 고정된 GitHub 자산에서 내려받아 크기와 SHA-256을 검증하고, 동일한 기존 캐시가 있으면 다시 다운로드하지 않고 재사용합니다.
- Windows 패키지에 DirectML·CPU용 native ONNX Runtime을 짧은 전용 경로로 배치해 긴 설치 경로에서도 KoharuLayout과 폰트 프록시가 로드되도록 했습니다. 개발 실행에서 외부 폰트 자산의 소유 파일을 컴파일 산출물로 오인해 시작이 중단되던 문제도 수정했습니다.
- 앱이 관리하는 OCR·Flux Python 환경은 사용자 또는 시스템의 전역 `pip` 설정과 `PIP_*` 환경 변수를 상속하지 않습니다. NVIDIA PyIndex 같은 외부 추가 저장소가 등록된 PC에서 관계없는 DNS 재시도 경고가 반복되던 문제를 막았습니다.
