# v2.5.0 패치노트

## 자동 식자

- 원문 이미지의 글자 크기 추정을 보완해 한 글자 대사와 말줄임표가 포함된 문장을 더 정확하게 처리합니다. 원문 크기 맞춤에 글꼴의 실제 글자 크기를 반영한 시각 보정을 적용했습니다.
- 자동 가로 식자에서 실제 글꼴 폭과 말풍선 내부 공간을 함께 계산해 어절 분리, 한 글자만 남는 줄, 문장부호만 남는 줄을 줄이고 줄 길이의 균형을 맞춥니다. 필요한 경우 글자 크기를 조정해 문장이 자연스럽게 들어가도록 했습니다.
- 연결된 말풍선은 말풍선 모양과 원문 위치를 기준으로 각 대사의 배치 영역을 나눕니다.
- 원문 크기 맞춤에서는 글꼴이 로드된 뒤 줄바꿈을 계산하며, 자동 줄바꿈 끝의 공백 때문에 정렬이 어긋나는 문제를 수정했습니다.

## 조건부 일괄 편집

- 글자 크기와 자동 외곽선 두께 조건을 화면에 실제로 표시되는 값으로 판정합니다. 미리보기의 변경 전·후 값도 같은 기준으로 표시합니다.
- 별도로 지정하지 않은 자간·장평·회전·불투명도·색상·외곽선·그림자·광채 등의 조건에 실제 기본값을 반영합니다. 말풍선 가로세로 비율도 이미지의 실제 너비와 높이를 기준으로 계산합니다.
- 글자 크기를 지정하면 원문 크기 맞춤을 해제하고 지정한 크기를 적용합니다. 자동 맞춤만 끄는 경우에는 현재 표시 크기를 유지합니다.
- 글꼴 로드가 끝난 뒤 미리보기와 적용을 활성화합니다. 크기 숫자가 같아도 자동 맞춤 상태가 바뀌면 변경으로 처리하고, 적용 전에 크기·배치 상태가 달라진 항목의 충돌 검사를 보완했습니다.
