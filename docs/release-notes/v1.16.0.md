# v1.16.0 패치노트

기준 범위: `v1.15.0` 태그와 `v1.16.0` 태그의 최종 트리를 직접 비교했습니다. 아래에는 두 최종 버전 사이에 실제로 남은 차이만 기록했습니다.

v1.16.0은 텍스트 서식 값을 더 넓고 정밀하게 직접 조절할 수 있게 하고, 외곽선을 절대 픽셀 단위로 편집하며, 대용량 공식 Llama 런타임을 보안 검증 후 정상 설치하도록 개선한 편집·호환성 릴리즈입니다.

## 서식 직접 입력과 범위 확장

- 글자 크기, 글자 투명도, 줄 간격, 자간, 장평을 숫자로 직접 입력할 수 있습니다. `-`·`+`는 클릭하면 한 단계씩 바뀌고, 누른 채 좌우로 드래그하면 연속 조절됩니다. 입력은 Enter 또는 포커스 이동으로 확정하고 Esc로 취소할 수 있습니다.
- 글자 크기는 `1~512px`(0.5px), 글자 투명도는 `0~100%`(1%), 줄 간격은 `0.1~10`(0.01), 자간은 `-1~5em`(0.01em), 장평은 `10~500%`(1%) 범위를 지원합니다.
- 편집 패널의 글자 크기 슬라이더를 제거하고, 글자 투명도·줄 간격·자간·장평을 2×2 숫자 필드로 정리했습니다. 줄바꿈 방식 아래의 긴 설명도 편집 패널에서는 표시하지 않습니다.
- 같은 숫자 입력 방식을 기본 서식, 스타일 프리셋, 텍스트 모아보기의 일괄 서식에도 적용해 저장 위치에 따라 조절 방식이나 허용 범위가 달라지지 않게 했습니다.
- 세로쓰기에서 일반 공백은 0.5em, 전각 공백은 1em으로 측정하고 표시합니다. 음수 자간을 포함한 새 간격 범위가 일반·세로·곡선·왜곡·원근 렌더링과 출력 측정에 함께 적용됩니다.

## 픽셀 단위 글자 외곽선

- 편집 패널에 `외곽선 사용` 체크박스를 추가하고, 외곽선 굵기를 `0~64px`, 0.5px 단위로 직접 입력하거나 스크러빙할 수 있게 했습니다.
- 새로 수정한 외곽선은 선택 필드 `outlineWidthPx`에 절대 픽셀값으로 저장됩니다. 기존 작품의 비율 기반 `outlineWidthScale`은 사용자가 외곽선을 수정하기 전까지 그대로 읽어 이전 출력 모양을 유지합니다.
- 일반 텍스트의 다중 그림자 외곽선을 실제 글자 stroke로 교체하고, 곡선 SVG 글자에도 둥근 조인과 캡을 적용해 굵은 외곽선의 겹침과 조각을 줄였습니다.
- 픽셀 외곽선은 기본 서식, 스타일 프리셋, 일괄 적용, 화면 렌더링, PNG와 PSD 출력에서 같은 값으로 처리됩니다.
- 자동 폰트 매칭 결과를 설명하고 되돌리던 별도 안내 카드는 제거했습니다. 자동 폰트 선택과 자동 맞춤 자체는 유지되며, 기존 작업에 저장된 안내용 메타데이터는 외곽선 색을 보존한 뒤 더 이상 다시 저장하지 않습니다. 원문 글자 크기를 추정하는 동작은 변경하지 않았습니다.

## Llama 런타임 설치 안정성

- Windows CUDA 12에서 공식 BeeLlama 압축 파일의 `ggml-cuda.dll`이 공통 1GiB 항목 제한보다 커 설치가 중단되던 [#72](https://github.com/ucx0204/CarrotMangaTranslator/issues/72)를 수정했습니다.
- 특정 DLL 이름마다 예외를 추가하지 않고, 앱에 내장된 모든 Llama 런타임 자산에 SHA-256과 정확한 압축 파일 크기를 함께 고정했습니다. 다운로드 파일이 두 값과 모두 일치하고 선택된 런타임의 자산 목록에도 정확히 포함될 때만 단일 항목 한도를 전체 압축 해제 한도까지 확장합니다.
- CUDA 12·CUDA 13·Vulkan·BeeLlama HIP·7개 Lemonade ROCm 타깃과 Apple Silicon Metal TAR가 같은 검증 계약을 사용합니다. 미검증 ZIP/TAR의 1GiB 항목 제한과 항목 수·전체 4GiB·압축률·경로 안전성 검사는 그대로 유지됩니다.
- TAR 메타데이터 검사에서 제한 위반이 비동기 예외로 빠지지 않고 설치 오류로 안전하게 종료되도록 보강했습니다.
- 런타임 바이너리와 다운로드 URL은 바꾸지 않았습니다. 이미 정상 설치된 캐시는 그대로 재사용합니다.
