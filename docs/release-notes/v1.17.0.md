# v1.17.0 패치노트

기준 범위: `v1.16.1` 태그와 `v1.17.0` 태그의 최종 트리를 직접 비교했습니다. 아래에는 두 최종 버전 사이에 실제로 남은 차이만 기록했습니다.

v1.17.0은 번역문을 가벼운 WYSIWYG 편집기처럼 다루는 글자별 서식, 기존 작업을 보존하면서 선택할 수 있는 줄바꿈·세로조판, 텍스트 그림자·글로우, 현재 화면의 블록 모양을 정확히 따르는 다중 선택을 추가한 편집 기능 릴리즈입니다.

## 번역문 글자별 서식 편집

- 번역문 입력에 `편집`과 `코드` 보기를 추가했습니다. 편집 보기에서는 실제 서식이 적용된 글자를 보며 수정하고, 코드 보기에서는 저장되는 마크업을 직접 확인하거나 편집할 수 있습니다. 두 보기를 오가도 번역문과 서식이 유지됩니다.
- 선택한 글자에 글자 크기, 글꼴, 투명도, 굵게, 기울임을 적용할 수 있습니다. 글자 크기는 `1~512px` 범위에서 0.5px 단위를 지원하고, 선택 영역이 없을 때 바꾼 서식은 블록 전체를 덮어쓰지 않고 이후 입력할 글자에 적용됩니다.
- 커서가 놓인 글자의 실제 서식을 도구에 반영하며, 글꼴을 선택하면 목록이 닫히고 바로 입력을 이어갈 수 있게 했습니다. 번역문 안의 모든 강조와 글자별 서식은 전용 전체 초기화 버튼으로 제거할 수 있습니다.
- 굵게·기울임과 글자별 크기·글꼴·투명도를 함께 중첩할 수 있습니다. 일반·세로·곡선 텍스트의 화면 표시와 PNG·PSD 출력이 같은 스타일 런을 사용합니다.

## 줄바꿈과 세로조판

- 줄바꿈 선택지를 `표준`, `표준+넘침 방지`, `글자 단위`, `단어 단위`, `단어 단위+넘침 방지` 순서로 정리했습니다. 기존 `단어 단위` 동작과 저장값은 그대로 유지하고, 한 줄보다 긴 단어만 글자 단위로 나누는 새 모드를 별도로 추가했습니다.
- 화면 측정, 자동 맞춤, 말풍선 배치와 출력이 같은 줄바꿈 규칙을 사용해 긴 URL이나 공백 없는 문자열이 포함된 블록의 결과가 서로 어긋나지 않게 했습니다.
- 세로쓰기에서 말줄임표, 장음선·대시, 물결표가 일본어 세로조판에 맞는 방향과 위치로 표시되도록 보정했습니다. 같은 대시가 이어질 때 간격을 없애고, 굵은 글자에서는 대시 굵기도 함께 반영합니다.
- 기호 입력 버튼으로 넣은 `!!`, `!?`, `?!`, `??`는 한 칸에 묶을 수 있으며, 이어서 입력하는 일반 글자까지 같은 묶음에 들어가지 않게 했습니다. 저장되는 원문 문자열은 표시 변환 때문에 바뀌지 않습니다.

## 텍스트 그림자·글로우

- 텍스트 효과 사용 여부, 색상, X/Y 위치 `-64~64px`, 블러 `0~64px`, 불투명도 `0~100%`를 직접 조절할 수 있습니다. X와 Y를 모두 0으로 두면 같은 효과를 글로우로 사용할 수 있습니다.
- 효과를 현재 블록뿐 아니라 기본 서식과 스타일 프리셋에도 저장할 수 있습니다. 일반·세로·곡선·회전·왜곡·원근 텍스트와 PNG·PSD 출력에서 같은 값과 합성 순서를 사용합니다.
- 기존 작업에는 효과 필드가 없으면 아무 효과도 적용하지 않으며, 기능을 사용한 블록과 설정에만 새 선택 필드를 저장합니다.

## 다중 선택 정확도와 표시

- 말풍선 맞춤이나 수동 이동 후 다중 선택할 때 과거 OCR 영역이 아니라 현재 화면에 표시된 `renderBbox`를 기준으로 선택합니다. 회전·원근·왜곡된 블록은 단순 사각형이 아닌 실제 변형 경계를 검사합니다.
- 이미지 밖으로 일부 이동한 블록도 바깥 편집 영역에서 드래그 선택할 수 있고, 과거 픽셀 좌표로 저장된 블록은 저장 시 안전한 정규화 좌표로 보정합니다. 좌표순 정렬은 기존처럼 원본 영역을 기준으로 유지합니다.
- 다중 선택 시 주 블록은 빨간 실선과 변형 핸들로, 함께 선택된 나머지 블록은 빨간 점선으로 구분해 현재 조작 기준을 알아보기 쉽게 했습니다.
