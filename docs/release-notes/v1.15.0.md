# v1.15.0 패치노트

기준 범위: `v1.14.0` 태그와 `v1.15.0` 태그의 최종 트리를 직접 비교했습니다. 아래에는 두 최종 버전 사이에 실제로 남은 차이만 기록했습니다.

v1.15.0은 이미지 경계 밖 텍스트 편집, 변형 핸들, 화면 맞춤과 작업 영역 조작을 개선하고 Windows ROCm 런타임의 중첩 라이브러리 구조를 정상적으로 인식하도록 수정한 사용성·호환성 릴리즈입니다.

## 이미지 경계 밖 텍스트 배치

- v1.14.0에서는 수동 텍스트 배치가 이미지 경계 안으로 제한됐지만, v1.15.0에서는 OCR·인페인트용 `bbox`와 화면 배치용 `renderBbox`를 분리해 텍스트 블록을 이미지 밖으로 이동하거나 늘릴 수 있습니다.
- 회전·원근·왜곡·워프까지 반영한 실제 외곽선을 기준으로 블록이 완전히 사라지는 배치만 막습니다.
- 편집 화면에서는 이미지 밖의 글자와 핸들을 계속 조작할 수 있고, PNG·PSD 출력에서는 이미지 경계를 넘은 부분만 잘립니다.
- 기존 작품은 `renderBbox`가 없으면 이전 `bbox`를 그대로 사용하므로 일괄 데이터 변환이 필요하지 않습니다.

## 변형 핸들과 회전 포인터

- 보이는 크기 조절점은 프로그램 창 크기에 비례하는 작은 원으로 바뀌었고, 마우스로 잡을 수 있는 범위는 v1.14.0과 같은 24×24 화면 픽셀을 유지합니다.
- 크기 조절점을 가리키거나 키보드 포커스를 줬을 때 나타나던 확대와 원형 테두리를 제거했습니다.
- 회전 핸들은 회전 전용 아이콘 커서를 사용하며, 회전 드래그가 끝날 때까지 같은 커서를 유지합니다.
- 선택 외곽선과 변형점을 하늘색 계열로 통일해 여러 종류의 선택선이 겹쳐 보이지 않게 했습니다.

## 화면 맞춤과 작업 영역 UI

- 화면 맞춤 배율을 실제 작업 뷰포트로 계산해 이미지를 중앙에 놓습니다. 맞춤 상태에서는 스크롤을 잠그고, 확대 결과가 뷰포트를 넘을 때만 스크롤을 허용합니다.
- 창 크기가 달라진 뒤 화면 맞춤을 다시 누르면 현재 뷰포트 크기로 배율을 다시 계산합니다.
- v1.14.0의 별도 고정 폭 오른쪽 도구 열을 없애고 작업 영역 안의 빠른 도구 모음으로 바꿨습니다. 왼쪽 도구 모음과 폭·간격·표면 스타일을 맞췄으며, 위·아래 아이콘 그룹을 패널과 별개로 접을 수 있습니다.
- 확대 조절은 세로 고정 목록 대신 가로 팝오버로 열리고, 바깥을 클릭하거나 포커스를 옮기면 닫힙니다. 화면 맞춤 설명은 버튼 아래에 표시됩니다.
- 보관함과 페이지의 꺾쇠는 서로 인접한 영역을 접고 펼치며 현재 상태에 맞춰 방향이 바뀝니다.
- 텍스트 블록 크기 조절 중에는 잡은 핸들의 방향 커서가 드래그가 끝날 때까지 유지됩니다.

## Windows ROCm 런타임 호환성

- ROCm 런타임 검증기가 `rocblas/library`와 `hipblaslt/library` 아래의 중첩 디렉터리를 안전하게 재귀 탐색하도록 수정했습니다.
- 이에 따라 중첩 구조를 쓰는 `gfx103X`, `gfx1150`, `gfx1151`, `gfx908`, `gfx90a` 계열에서도 정상적인 라이브러리 묶음을 누락으로 오인해 설치가 실패하던 문제가 해결됩니다.
- 심볼릭 링크는 따라가지 않고 탐색 디렉터리 수를 제한해, 런타임 파일 검증의 경로 안전성은 유지했습니다.
- 배포 중인 ROCm 런타임 자산의 파일명·크기·SHA-256은 바꾸지 않았습니다. 이미 완전하게 설치된 캐시는 그대로 재사용합니다.
