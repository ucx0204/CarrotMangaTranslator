# v0.9.2 패치노트

기준 범위: `v0.9.1` 이후부터 `v0.9.2`까지의 변경 사항입니다.
포함 커밋: `chore: release v0.9.2`.

## 개선 및 수정

### CPU OCR과 풀로드 품질 조합 방지

- `풀로드` OCR 품질(PaddleOCR-VL)이 CPU 장치와 함께 저장되거나 실행되지 않도록 정규화했습니다.
- 설정 파일에 `ocr.device: cpu`와 `ocr.qualityMode: full` 조합이 남아 있어도 앱 시작 시 `절약` 품질로 자동 보정합니다.
- 런타임 옵션을 만들 때 환경 변수나 자동 다운그레이드 흐름 때문에 OCR 장치가 CPU로 내려가면, 풀로드 품질 대신 PP-OCRv6 텍스트라인 경로를 사용합니다.
- GPU 메모리 기준으로 Gemma 31B 풀로드 모드가 선택되더라도, OCR GPU를 쓸 수 없는 AMD GPU처럼 OCR 장치가 CPU인 환경에서는 OCR 품질 기본값을 `절약`으로 둡니다.
- 설정 창에서 OCR 장치를 CPU로 바꾸면 풀로드 품질이 즉시 절약 품질로 바뀌도록 guard를 추가했습니다.
- OCR 품질 옵션 설명과 README FAQ에 CPU에서는 풀로드 OCR을 쓰지 않는다는 안내를 보강했습니다.

### GPU OCR 실패 후 CPU 폴백 경로 개선

- PaddleOCR-VL GPU 실행이 실패해 CPU 폴백으로 넘어갈 때, VL 레이아웃 파이프라인을 CPU에서 그대로 돌리지 않고 PP-OCRv6 텍스트라인 OCR 경로로 낮춰 실행합니다.
- 단일 페이지 OCR, 배치 OCR, 세션 단위 CPU override, 배치 복구 경로가 모두 같은 CPU 폴백 옵션을 사용하도록 정리했습니다.
- CPU 폴백에서는 `ocrBboxMode`를 `ocr`, `ocrVersion`을 `PP-OCRv6`, merge mode를 `conservative`, recognition batch를 `1`로 맞춰 느린 VL CPU 실행을 피합니다.
- CUDA/일반 VL 경로는 CPU 폴백 때 텍스트라인 OCR로 내려가지만, 원래부터 OCR-only로 동작하는 `rocm-transformers` 경로는 기존 OCR 엔진 설정을 유지합니다.
- VL 실행에서 이미 쓰는 PP-OCRv6 detector/recognizer 모델을 재사용할 수 있어, CPU 폴백 때문에 별도 모델 다운로드가 늘어나지 않습니다.

### 선택 영역 번역 저장 충돌 완화

- 선택 영역 번역 결과는 기존 페이지 전체를 덮어쓰지 않고, 최신 페이지 상태 위에 새 분석 블록만 원자적으로 append하도록 변경했습니다.
- 영역 번역 도중 사용자가 같은 페이지의 기존 블록을 편집해 저장했더라도, 새 영역 번역 블록이 저장 충돌로 사라지지 않도록 했습니다.
- 라이브 챕터 병합에서 dirty로 보존된 로컬 페이지에도 영역 번역으로 새로 생긴 block id만 덧붙일 수 있는 옵션을 추가했습니다.
- dirty 페이지의 기존 로컬 편집 내용은 그대로 유지하면서, 영역 번역이 만든 새 블록만 라이브 결과에서 가져옵니다.
- 영역 번역 완료 후 저장 기준 버전을 새 디스크 상태에 맞춰 동기화해, 다음 자동 저장이 방금 append된 결과와 충돌하지 않도록 했습니다.
- 선택 영역 번역 저장 처리를 library mutation 계층으로 옮겨, 파일 변경과 work updatedAt 갱신이 같은 mutation lock 안에서 처리되도록 했습니다.

### 영역 번역 결과 필터링 조정

- 영역 번역 크롭은 사용자가 직접 고른 영역이므로, 전체 페이지용 잡음 필터가 유일한 결과 블록까지 버리지 않도록 별도 검증 모드를 추가했습니다.
- 전체 페이지 분석에서는 기존처럼 `merged_ui_list`, 짧은 fragment noise, OCR 후보 불일치 같은 휴리스틱을 유지합니다.
- 영역 번역 모드에서는 원문이 완전히 비어 있는 항목만 제외하고, 짧은 텍스트나 UI 목록처럼 보이는 결과도 사용자가 선택한 영역의 결과로 보존합니다.
- 페이지 결과 생성기가 region crop 실행 여부를 overlay 검증 단계까지 전달하도록 연결했습니다.

## 내부 정리 및 테스트

- 영역 번역 append 저장 로직을 `libraryAnalysisMutations` 모듈로 분리했습니다.
- 라이브 챕터 병합 옵션에 `appendLiveBlocks`를 추가하고, dirty page 보존 흐름과 함께 테스트했습니다.
- CPU OCR 폴백 옵션 생성을 `buildCpuFallbackOcrOptions` helper로 정리하고 런타임 테스트에서 직접 검증할 수 있게 export했습니다.
- CPU+풀로드 OCR 설정 정규화, 하드웨어 기본값, 런타임 OCR 옵션 테스트를 보강했습니다.
- GPU OCR 실패 후 CPU 폴백이 VL 대신 PP-OCRv6 텍스트라인 경로로 내려가는지 테스트를 추가했습니다.
- 영역 번역 모드의 overlay item 검증 테스트를 추가했습니다.
- README의 설치 파일 예시와 AMD OCR FAQ 설명을 `v0.9.2` 기준으로 갱신했습니다.
