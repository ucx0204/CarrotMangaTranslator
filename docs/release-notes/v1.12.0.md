# v1.12.0 패치노트

기준 범위: `v1.11.1` 태그의 최종 상태와 `v1.12.0`의 최종 상태를 비교했습니다.

v1.12.0은 자동 폰트 맞춤 런타임을 v2로 교체하고, 검색 및 치환·블록 읽기 순서·다중 선택·레이어 PSD 출력까지 실제 식질 작업 흐름을 확장한 기능 릴리즈입니다.

## v1.11.1 대비 핵심 차이

- **자동 폰트 맞춤 v2:** 새 role-aware 랭커가 일반 대사와 강조 계열을 나눠 평가하고, 본문에서 개성체 `Single Day`가 오용되지 않도록 별도 안전 조건을 적용합니다.
- **검색 및 치환:** 현재 페이지 또는 전체 화의 번역문·원문을 미리 확인하고 한 번에 바꿀 수 있습니다.
- **읽기 순서와 다중 선택:** 저장되는 블록 순서를 직접 조정하고, 드래그·Ctrl·Shift로 여러 블록을 선택해 함께 편집할 수 있습니다.
- **결과물 출력:** 기존 완성 PNG에 더해 원본·정리 배경·블록별 대사를 분리한 레이어 PSD를 출력할 수 있습니다.
- **단축키·서식 슬롯:** 검색, 결과물 출력, 읽기 순서, 보정 도구와 서식 프리셋 슬롯을 키보드로 바로 실행할 수 있습니다.

## 자동 폰트 맞춤 v2

- 한국어 자동 폰트 후보 21개를 유지하면서 body/variant 두 점수 경로와 픽셀 기반 역할 판단을 결합한 v2 랭커로 교체했습니다.
- 일반 대사·강조·효과음의 시각 역할을 구분하고, 본문 역할에서는 `Single Day`를 차단합니다. 강조 계열에서도 역할 신뢰도와 다른 후보 대비 점수 차이가 충분할 때만 허용합니다.
- 사용자가 직접 고정한 폰트, 외곽선 두께·색, 글자색은 자동 선택이 바꾸지 않습니다. 적용된 자동 폰트는 기존처럼 한 번에 되돌릴 수 있습니다.
- production runtime은 소유권 marker, 계약, 보정, 랭커, 카탈로그, 프로토타입, 인코더의 정확한 크기와 SHA-256을 모두 확인합니다. 릴리스 승인이나 파일 결속이 맞지 않으면 자동 적용을 끄고 기존 폰트를 유지합니다.
- 새 v2 캐시를 사용하므로 기존 v1 캐시는 손상시키지 않습니다. v1 캐시에 바이트가 같은 대형 자산이 있으면 검증 후 복사하고, 없으면 `font-matching-runtime-v2` 자산 릴리스에서 약 467MB를 한 번 내려받습니다.
- 설치 파일에는 작은 v2 신뢰 파일과 랭커를 포함하고, 대형 인코더·프로토타입·카탈로그만 외부 자산으로 유지합니다.

### v2 검증 범위와 한계

- 기존 모델·QA 작품을 통째로 제외한 10개 작품, 서로 다른 40개 화의 새 페이지에서 Gemma→OCR→인페인팅→폰트 추론→렌더 전체 경로를 cache 없이 실행했습니다.
- 40페이지·375블록 중 자동 폰트가 337블록에 적용됐고, `Single Day`는 4회 모두 강조 계열이었으며 본문 오용은 0건이었습니다. 자동 적용 블록의 외곽선 손실도 0건이었습니다.
- 원본 해상도 수동 전수 감사 결과는 내용이 있는 30페이지 중 `GOOD 10 / ACCEPTABLE 15 / BAD 5`, 사용 가능 25페이지(83.33%)였습니다. 나머지 10페이지는 번역할 내용이 없어 N/A였습니다.
- 이 결과는 실용 가능한 v2 기준이지만 최종 품질을 뜻하지 않습니다. 일반 본문을 강조체로 판단하거나 한 페이지 안에서 글꼴이 갈리는 경우가 남아 있으므로, 자동 결과는 출력 전에 검수하세요.
- 작은 33행 보정 세트의 strict preferred/precision 기준은 통과하지 못했습니다. 이 사실은 runtime 계약에 그대로 기록했고, 위의 exact fresh 40페이지 수동 감사와 사용자 승인을 결속한 별도 release acceptance만 production에서 허용합니다.

## 검색 및 치환

- `Ctrl+H`로 `검색 및 치환`을 열 수 있습니다.
- 검색 범위를 `현재 페이지` 또는 `전체 화`, 필드를 `번역문`·`원문`·`둘 다`로 정할 수 있습니다.
- 일반 문자열, 대소문자 구분, 정규식과 캡처 그룹 치환을 지원합니다.
- 바꾸기 전에 페이지·필드·일치 수와 문장 미리보기를 보여 주며, 결과를 눌러 해당 블록으로 이동할 수 있습니다.
- `모두 치환`은 한 번의 편집 기록으로 저장되므로 실행 취소와 다시 실행으로 되돌릴 수 있습니다.

## 블록 선택·읽기 순서·서식 작업

- 선택 도구의 빈 공간에서 드래그하면 사각형 안의 블록을 여러 개 선택합니다. Ctrl/Cmd는 선택 추가·해제, Shift는 목록 범위 선택에 사용합니다.
- 현재 페이지 블록 목록에 순서 앞/뒤 버튼과 `좌표순 정렬`을 추가했습니다. 저장된 순서는 이전·다음 블록 이동, 텍스트 모아보기, 검수표 순서에 반영됩니다.
- 여러 선택 블록을 함께 삭제하거나 서식·위치·크기를 한 번에 조정할 수 있습니다. 기준 블록 복제도 읽기 순서 바로 뒤에 새 블록을 넣습니다.
- 서식 프리셋에 1~10번 단축키 슬롯을 지정할 수 있으며 `Alt+1`부터 `Alt+0`으로 적용합니다. 같은 슬롯이 중복 저장되지 않도록 정규화합니다.
- 확대 상태에 `화면에 맞춤`, `너비에 맞춤`, `높이에 맞춤`, `실제 크기` 명령을 추가했습니다.
- 보정 도구 선택, 마스크 적용·취소, 검색, 출력, 읽기 순서와 서식 슬롯을 포함하도록 단축키 설정을 확장했습니다. 충돌하는 키를 새 동작에 배정하면 이전 동작을 명확히 해제합니다.
- 보정 포인터 시작·이동·종료 처리를 분리하고, 작업 중 라이브 오버레이와 휠 확대 동작을 정리했습니다.

## PNG와 레이어 PSD 결과물 출력

- 출력 창을 `결과물 출력`으로 정리하고 `완성 이미지 (PNG)`와 `레이어 문서 (PSD)` 중에서 고를 수 있게 했습니다.
- PSD는 아래에서 위 순서로 `원본 배경 (Original)`, 선택적인 `정리 배경 (Inpaint)`, 각 대사 블록 레이어를 만듭니다.
- 일반 가로쓰기 블록에는 편집 가능한 PSD 텍스트 정보와 래스터 미리보기를 함께 넣습니다. 세로쓰기·곡선·원근 블록은 앱에서 보이던 모양이 달라지지 않도록 정확한 래스터 레이어로 보존합니다.
- `글자 없이 출력`을 선택하면 PNG는 인페인팅 배경만, PSD는 원본과 정리 배경 레이어만 저장합니다.
- 기존 출력 전 점검에 PSD 확장자와 선택 형식을 연결했습니다. 선택 페이지 수, 확장자까지 반영된 파일명 예시, 작업 중·번역 실패·후처리 대기·빈 번역문·인페인팅 누락을 출력 전에 확인합니다.
- 기존 파일을 덮어쓰지 않고 새 시간 폴더에 저장하며, 취소·실패 시 미완성 결과를 정리하던 정책을 PSD에도 동일하게 적용합니다.
- Windows의 긴 저장소 경로에서 Chromium이 임시 HTML을 열지 못하던 문제를 막기 위해 세션별 짧은 OS 임시 경로와 고정 `page.html`을 사용합니다. 동시 출력 세션도 각자 디렉터리를 소유하고 종료 시 정리합니다.

## 개발·패키징 수정

- `npm run dev`의 Electron 컴파일 캐시가 runtime-assets 단계 소유 파일을 `out/main` TypeScript 산출물로 잘못 요구해, `out/main/runtime/font-matching/.font-matching-runtime-artifact-owned.json` 누락으로 중단되던 문제를 수정했습니다.
- 폰트 runtime 소스는 Electron 컴파일 캐시 입력·필수 출력에서 제외하고, 실제 권위 위치인 `out/app-runtime/font-matching`은 runtime-assets 단계가 준비하도록 경계를 고정했습니다.
- 개발 중 `node_modules`에 생성될 수 있는 `.v8-cache`를 설치 파일에서 제외해 기기별 임시 바이너리 캐시가 패키지에 섞이지 않게 했습니다.
- 앱 릴리스와 별도로 대용량 자산을 GitHub Release에 게시·검증하는 일반 절차와, 안정 앱 버전 릴리스 절차를 `AGENTS.md`에 기록했습니다.

## README와 사용 안내

- 한국어 README에 실제 프로덕션 컴포넌트를 자체 Chromium QA 도구로 캡처한 검색 및 치환·PSD 출력 화면과 상세 사용법을 추가했습니다.
- 영어·일본어·중국어 간체·중국어 번체 README의 현재 버전과 PNG/PSD 출력 설명을 v1.12.0 기준으로 맞췄습니다.

## 업그레이드 안내

- 기존 작품, 페이지, 블록, 설정, 사용자 폰트와 v1 폰트 runtime 캐시는 그대로 유지됩니다.
- 페이지의 명시적 읽기 순서는 이 버전부터 저장됩니다. 기존 페이지는 작품의 좌→우/우→좌 설정과 좌표로 안전하게 추론하고, 사용자가 순서를 바꾸면 그때 명시값을 저장합니다.
- 새 PSD 출력은 기존 PNG 출력에 추가되는 선택지입니다. 기존 PNG 작업 방식과 파일명 충돌 방지 정책은 유지됩니다.
- 자동 폰트 맞춤을 사용하지 않으면 v2 대형 자산을 받을 필요가 없습니다. 사용하는 경우 기존 캐시가 없을 때만 첫 실행에 다운로드 시간이 걸릴 수 있습니다.

## 검증

- 실제 프로덕션 검색 및 치환·결과물 출력 컴포넌트를 1440px와 980px 창에서 Chromium으로 캡처해 잘림, 겹침과 가로 오버플로를 확인했습니다.
- TypeScript·JavaScript 타입 검사, Prettier, ESLint, 구조·의존성·dead-code 검사
- Vitest 전체 회귀·커버리지 검사, PSD round-trip·투명 레이어·출력 보안 테스트
- 프로덕션 빌드, 페이지 출력 픽셀 일치 QA, 이미지·폰트 프로토콜 smoke
- Windows 새 설치·업그레이드·사용자 데이터 보존 installer smoke
- Windows와 Apple Silicon macOS의 GitHub Actions 빌드 및 게시 산출물 SHA-256 재다운로드 검증
