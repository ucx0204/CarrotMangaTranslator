# v2.8.0 — HayaiOCR 페이지 작업

## 필요한 작업만 선택해서 실행

- HayaiOCR에 **페이지 작업** 화면을 추가했습니다. 블록 검출, OCR, 번역, 자동 서식, 원문 제거, 말풍선·줄 배치, 자동 검수를 따로 선택할 수 있습니다.
- **손번역 준비**로 검출·OCR·원문 제거를 마친 뒤 원문을 교정하고, **번역만**으로 이어서 작업할 수 있습니다. 저장된 블록 위치와 원문을 재사용합니다.
- 기본적으로 기존 결과를 보존하고 빈 항목만 채웁니다. 단계별 재처리 옵션과 실행 전 입력 검사를 제공합니다.
- 원문·번역문·최종 서식 단계에 일괄 편집 규칙을 적용할 수 있습니다. 중단한 작업을 이어갈 때 완료한 규칙을 중복 적용하지 않습니다.
- 자동 검수로 빈 번역, 숫자·용어 불일치 등을 확인할 수 있습니다.

## 익숙한 화면과 새 화면

- HayaiOCR 설정에서 **기존 버전 / 새 버전**을 전환할 수 있으며 마지막 선택을 기억합니다. PaddleOCR의 기존 설정과 실행 방식은 유지합니다.
- 대상 페이지 영역을 넓히고 실행 순서를 간결하게 배치했습니다. 화면 전환 시 모달 너비가 자연스럽게 바뀝니다.
- 기본 프리셋 5종과 사용자 프리셋의 즐겨찾기·수정 저장·복사·삭제를 제공합니다.
- 작업과 세부 옵션의 설명을 툴팁으로 제공하며, 드롭다운을 열 때 설명이 선택 항목을 가리지 않도록 했습니다.
- 원문·번역문 목록의 읽기 크기를 기본 15px로 높이고 12–24px 조절을 추가했습니다. 선택한 원문은 전체 내용을 표시합니다.
- [README](https://github.com/ucx0204/CarrotMangaTranslator/blob/v2.8.0/README.md)에 실제 화면 캡처와 사용법을 추가했습니다.

## 결과 보존과 표시

- 새 작업에서 번역 응답에 일부 블록이 빠지거나 제외돼도 정상 번역을 저장하도록 수정했습니다. 빈 번역은 자동 검수에서 확인하며 실제 요청 실패는 오류로 기록합니다.
- 손번역 준비로 만든 빈 블록은 편집할 수 있으며, 화면·PNG·PSD에 원문이 대신 그려지지 않습니다.
- 단계 완료 기록과 페이지 결과를 함께 저장하고, 취소·재개와 저장 충돌을 처리합니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다. 각 플랫폼의 릴리스 절차에서 패키지와 실행 여부를 검증합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
