# v2.0.1 패치노트

기준 범위: `v2.0.0` 태그(`176c556e`)와 `v2.0.1` 릴리스 커밋의 직접 diff입니다. 최종 제품에 남은 변경만 기록했습니다.

## macOS

- Flux Metal 실행 파일이 기능 조회에서 실제 `metal_device` 상태를 반환하도록 수정했습니다. 이 값이 누락되어 중단되던 Apple Silicon DMG/ZIP 빌드 후 기능 계약 검증이 정상 완료됩니다.

---

## Code signing

- Windows 설치 파일은 Authenticode 미서명입니다.
- Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명과 Apple 공증은 포함하지 않습니다.
- [Code signing policy](https://github.com/ucx0204/CarrotMangaTranslator/blob/master/CODE_SIGNING_POLICY.md)
