# v1.19.0 패치노트

기준 범위: `v1.18.2` 태그(`9d8b7a5d`)와 이번 `v1.19.0` 최종 트리를 직접 비교했습니다. 중간 개발 상태가 아니라 두 최종 트리에 실제로 남은 차이만 기록했습니다.

v1.19.0은 반복 편집을 줄이는 블록 라이브러리와 결과물 자동 저장을 추가하고, 편집 작업 공간·텍스트 도구·출력 흐름을 확장하면서 페이지 이동 시 보이던 글꼴 전환과 컨트롤 깜빡임을 줄인 기능 릴리스입니다.

## 블록 라이브러리

- 현재 텍스트 블록의 문구, 방향·역할, 크기, 글꼴, 스타일과 변형을 라이브러리에 저장하고 다른 페이지에 다시 삽입할 수 있습니다. 검색, 최근순·이름순 정렬, 미리보기, 이름 변경, 편집과 삭제를 지원합니다.
- 삽입한 블록은 새 ID로 현재 화면 중앙에 배치되고 한 번의 실행 취소 단계로 기록됩니다. 페이지 위치, 검수 상태, 화자·용어 연결 같은 페이지 전용 정보는 라이브러리에 섞이지 않습니다.
- 라이브러리는 메인 편집기와 분리 편집기가 함께 사용하며, 최대 2,000개 항목을 원자적으로 저장합니다.

## 결과물 출력 및 자동 저장

- 일반 이미지 출력에 원본 형식, PNG, JPEG, WebP를 지원합니다. JPEG·WebP 품질, 원본 파일명과 하위 폴더 유지, 새 타임스탬프 폴더 또는 선택 폴더에 바로 저장, 파일 충돌 시 덮어쓰기·건너뛰기·취소를 선택할 수 있습니다. 레이어 PSD 출력은 별도 흐름으로 유지됩니다.
- 원본을 가져올 때 `결과물 폴더에 자동 저장`을 켜고 형식과 품질을 정할 수 있습니다. 설정의 `결과물 자동 저장`에서 작업·화별 활성화, 기본 또는 사용자 지정 폴더, 결과 열기, 검색·정렬과 상태 확인을 제공합니다.
- 자동 저장은 실제 화면 픽셀이 바뀐 페이지만 편집이 멈춘 뒤 저장하고, 포인터 조작·IME 입력 중에는 렌더링을 피합니다. 저장은 원자적으로 게시되며 실패 작업과 재시도 일정이 보존되어 앱을 다시 켠 뒤에도 이어집니다.
- 원본의 중첩 경로와 이름을 유지하면서 같은 이름 충돌을 구분하고, 연결 경로는 운영체제와 관계없이 Windows·POSIX 절대 경로와 상위 경로 탈출을 거부합니다.

## 편집 작업 공간

- 확대·축소를 더 세밀하게 조정하고 휠 위치 또는 선택 영역을 기준으로 화면을 고정합니다. 숫자패드 확대·축소 단축키, 자연 이미지 비율을 따르는 화면 맞춤, 임시 손 도구의 안정적인 이동 종료도 추가했습니다.
- 인페인트 결과가 있는 페이지에서 원본 이미지를 0~100%로 겹쳐 보며 비교할 수 있습니다. 페이지를 바꾸면 패널 상태를 정리해 이전 페이지 상태가 남지 않습니다.
- 리터치 도구를 `칠하기 도구`와 `복원 도구`로 정리하고, 드래그한 사각 영역을 원본 픽셀로 한 번에 되돌리는 `사각 복원`을 추가했습니다.

## 번역·텍스트·스타일 가이드

- `텍스트 모아보기` 안에 `모아보기`와 `검색·치환` 탭을 통합해 미리보기와 일괄 적용을 같은 창에서 처리합니다.
- 일반 텍스트 내보내기는 블록 사이를 빈 줄 하나로 구분하면서 블록 내부의 여러 줄을 보존합니다. 가져오기도 이 형식을 인식하며 기존 형식의 대체 해석은 유지합니다.
- 활성 용어의 번역을 비워 두면 해당 원문과 별칭을 OCR 결과에서 모델로 전달되는 입력과 대응 번역 출력에서 제외할 수 있습니다. 겹치는 항목은 가장 긴 용어를 우선하고, 비활성 또는 번역이 있는 항목은 제외하지 않습니다.
- 스타일 가이드에 모든 기준의 오름차순·내림차순 정렬, `등장 횟수 0` 필터, 일괄 삭제 확인창을 추가하고 신규·편집 행의 포커스와 IME 입력 안정성을 개선했습니다.

## UI·성능·런타임 안정성

- 페이지에 실제로 필요한 글꼴 face만 우선 준비하고 현재 페이지의 텍스트는 해당 글꼴이 준비된 뒤 표시합니다. 인접 페이지의 정확한 글꼴과 원본·편집 이미지는 유휴 시간에 미리 준비하며, 다음 이미지가 디코드되기 전에는 기존 프레임을 유지해 페이지 이동 시 대체 글꼴 전환과 빈 프레임을 줄였습니다.
- `원본 불투명도 조절`을 포함한 오른쪽 퀵 컨트롤의 DOM과 아이콘을 로딩 중에도 유지하고 렌더 경계를 줄여 버튼·아이콘 깜빡임을 완화했습니다.
- 모달, 선택·숫자 입력, 툴팁, 팝업, 진행 상태와 알림을 공통 UI로 정리했습니다. 키보드·IME 포커스, 팝업 포커스 이동, 토스트 안내와 분리 편집기 오류 표시도 보강했습니다.
- AMD HIP SDK 탐색은 실제 SDK의 `bin`과 지원 런타임 DLL을 검증하며, 드라이버가 System32 등에 노출한 DLL을 SDK로 오인하지 않습니다. 명시적 `HIP_PATH`·`ROCM_PATH`와 표준 버전 경로를 우선해 잘못된 AMD Flux 준비 완료 판정을 줄였습니다.
- Gemma `minimum12b`와 `economy26b` 프로필의 fit 여유 VRAM을 2,048MB에서 1,024MB로 조정해 가능한 경우 더 많은 레이어를 GPU에 배치합니다. `full31b`의 1,024MB 설정은 그대로입니다.

## 개발자·호환성 참고

- 이미지 출력 IPC를 raster 요청과 PSD 요청으로 분리했습니다. raster 요청은 원본 형식·PNG·JPEG·WebP만 받으며 PSD는 전용 계약을 사용합니다.
- `block-library.json`, 연결 결과물 registry·재시도 queue, 페이지 visual revision과 마스크 provenance에 엄격한 v1 저장 계약을 추가했습니다. 기존 작업 데이터는 새 필드가 없어도 계속 읽을 수 있습니다.
- 가져온 페이지에 원본 파일명·상대 경로 메타데이터가 선택적으로 보존됩니다. 렌더러 진행 표시를 내부 공통 컴포넌트로 옮겨 `@radix-ui/react-progress` 런타임 의존성을 제거했습니다.
- 지원 운영체제는 Windows 10/11과 Apple Silicon macOS 14+로 v1.18.2와 같습니다.
