# v2.7.11 — 페이지 번역 실패 후에도 다음 작업 계속 진행

## 번역 대기열 처리 개선

- 한 페이지의 번역 재시도가 모두 실패해도 실패 상태를 저장한 뒤 다음 페이지와 대기 중인 챕터의 번역을 계속 진행하도록 수정했습니다 (#112).
- 토큰 한도·컨텍스트 길이 설정 안내와 작업 중단 여부를 분리했습니다. 설정 안내는 유지하면서, 해당 페이지의 실패 때문에 전체 대기열이 중단되지 않도록 했습니다.
- 실패한 페이지는 확인하거나 다시 번역할 수 있도록 남겨 두며, 이후 챕터가 성공해도 전체 작업은 일부 실패로 표시합니다. 자동 인페인팅은 번역에 성공한 페이지만 처리합니다.
- 사용자가 취소한 경우, 재시도할 수 없는 인증·런타임 오류, 실패 상태를 저장하지 못한 경우에는 기존처럼 작업을 중단합니다. 자동 재시도 횟수는 늘리지 않았습니다.

## 한국어 번역 표기 개선

- 번역 프롬프트에서 한국어만 사용하거나 외국어 표기를 한글로 음역하도록 강제하던 지시를 완화했습니다.
- `A랭크`, `1856년`처럼 일반적으로 사용하는 영문자·아라비아 숫자 표기를 유지하도록 명확히 안내했습니다. 이를 `에이랭크`, `천팔백오십육년`처럼 불필요하게 풀어 쓰는 문제를 줄이기 위한 수정입니다.
- 추가 모델 호출 없이 번역 지시문만 조정했습니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS용 DMG·ZIP을 제공합니다. 각 플랫폼의 릴리스 절차에서 패키지와 실행 여부를 검증합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
