# v3.8.14

## FLUX 인페인팅에 경량 모드 추가

**설정 → 이미지 · 원문 제거**에서 인페인팅 모델을 **Flux 풀로드**로 고른 뒤, 백엔드 선택 바로 아래에서 **일반** 또는 **경량**을 선택할 수 있습니다. AMD에서는 ROCm과 Vulkan 중 원하는 백엔드로 두 모드를 모두 사용할 수 있습니다.

- **일반**은 기존 FLUX 처리 방식을 사용합니다.
- **경량**은 큰 효과음도 지울 영역 하나를 작은 해상도로 줄여 한 번에 처리합니다. 메모리 사용량과 처리 시간이 줄어들며, 효과음 뒤의 옷 주름이나 가는 무늬는 일반 모드와 다르게 복원될 수 있습니다.
- VRAM이 8GB 이하로 감지된 AMD 그래픽카드는 **경량**, 그 밖의 환경은 **일반**이 기본입니다. 직접 선택해 저장한 모드는 다음 실행에도 유지됩니다.

Windows에서 RTX 4090과 Vulkan으로 서로 다른 만화 30편의 본문을 한 쪽씩 처리했습니다. 효과음 26곳을 포함한 133곳에서 일반은 총 **8분 02초**, 경량은 **5분 42초**가 걸렸습니다. 이때 FLUX 프로세스의 최대 전용 GPU 메모리는 일반 **9.92 GiB**, 경량 **3.19 GiB**였습니다. RX 7600에서의 실제 처리 시간과 메모리 사용량은 아직 측정하지 않았습니다.
