# v3.8.5

대화를 삭제한 뒤 남던 첨부 이미지·Codex 기록과 글꼴 분석 임시 파일을 정리하고, 지울 대상이 없는 페이지의 인페인팅 처리를 바로잡았습니다.

## 대화와 임시 파일 정리

- 대화를 삭제하면 해당 대화의 첨부 이미지 복사본·요약 캐시·Codex 세션 기록을 함께 정리합니다. 앱을 재시작한 뒤 삭제해도 적용되며, 정리에 실패하면 대화 기록을 남겨 다시 시도할 수 있습니다.
- 삭제 중 늦게 끝나는 저장이나 첨부 처리로 파일이 다시 생성되지 않도록 대화별 저장과 삭제 순서를 맞췄습니다.
- 글꼴 분석이 끝나거나 실패·취소되면 워커 종료를 확인한 뒤 해당 실행의 임시 폴더를 정리합니다. 워커 종료를 확인하지 못하거나 안전하지 않은 링크를 발견하면 폴더를 보존합니다.
- 원본·보관함·출력물·다른 대화는 정리 대상이 아닙니다. 이전 버전에서 이미 쌓인 잔여물이나 공용 `system-temp` 폴더를 일괄 삭제하지 않습니다.

## 대상 없는 인페인팅

- 지울 블록이 없거나 모두 제외된 페이지는 불필요한 모델 준비 없이 대상이 없다는 오류를 표시합니다. 실제 변경 없이 성공으로 표시되던 경우를 수정했습니다.
- 번역 완료 기록이 있는 빈 페이지는 기존 완료 절차를 유지합니다. 여러 페이지에서 한 페이지의 완료 기록이 다른 페이지의 대상 없음 오류를 숨기지 않도록 했습니다.
- 대기 중 편집으로 뒤쪽 페이지에 대상이 추가되면 실제 처리 시점에 모델을 준비합니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.5.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.5-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
