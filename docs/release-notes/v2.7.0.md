# v2.7.0

- 효과음 이미지 생성·원문 지우기 전에 이미지와 대사 목록을 함께 보며 원문·번역문 수정, 영역·바운딩 박스 추가·제외를 일괄 확정할 수 있습니다. 이미지 생성 실패·취소 시에도 확정한 편집은 보존합니다.
- 일괄 편집의 화자 조건(같음)과 화자 지정에 이름·별칭으로 검색하는 선택 목록을 추가했습니다. 화자별 글꼴 변경에 사용할 수 있습니다.
- 수동 가리기에 페이지 목록, 마스크 일괄 복사·되돌리기, 초안 자동 저장과 페이지·화·작품 단위 사전 편집을 추가했습니다.
- Codex를 0.154.0으로 업데이트하고, Astra 설정이 다른 모델로 바뀌는 문제를 수정했습니다.
- Codex 로그인 만료·사용량 한도를 서버 오류로 처리하던 문제를 수정했습니다. 재로그인이 필요하면 안내하고 불필요한 재시도를 중단합니다.
- 효과음 번역의 잘못된 JSON 응답 재시도와 번역 결과가 0건일 때의 실패 표시를 보완했습니다.
- Windows 보호 폴더 설치를 지원합니다. 앱 실행 시 데이터 폴더의 쓰기 권한이 부족한 경우에만 관리자 승인을 요청합니다.
- 여러 NVIDIA GPU를 사용할 때 Flux 실행 파일과 실제 연산 GPU가 서로 달라지는 오류를 수정했습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
