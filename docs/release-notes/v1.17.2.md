# v1.17.2 패치노트

기준 범위: `v1.17.1` 태그와 이번 `v1.17.2` 최종 트리를 직접 비교했습니다. 아래에는 두 최종 버전 사이에 실제로 남은 차이만 기록했습니다.

v1.17.2는 Google Vertex AI를 사용할 때 매시간 OAuth 액세스 토큰을 직접 다시 입력하지 않아도 되도록 서비스 계정 JSON 인증을 추가한 릴리즈입니다.

## Vertex 서비스 계정 JSON 인증

- `설정 → 번역 엔진 → API → Google Vertex AI`에서 기존 OAuth 액세스 토큰과 서비스 계정 JSON 중 인증 방식을 선택할 수 있습니다. 새 Vertex 설정은 서비스 계정 JSON을 기본으로 사용하고, 이미 액세스 토큰을 사용하던 설정은 기존 방식을 유지합니다.
- 서비스 계정 JSON을 선택하면 파일의 `project_id`를 프로젝트 입력란에 자동 반영합니다. 모델 목록 확인과 실제 번역 요청 모두 선택한 서비스 계정으로 인증합니다.
- 앱이 Google의 짧은 수명 액세스 토큰을 필요할 때 발급하고 갱신합니다. 인증 실패로 `401` 또는 `403` 응답을 받으면 캐시된 토큰을 버리고 새 토큰으로 다시 시도합니다.
- `MANGA_TRANSLATOR_API_KEY` 환경 변수를 명시한 환경은 기존처럼 그 값을 우선하므로 자동화 환경의 동작을 바꾸지 않습니다.

## 설정 안내와 자격 증명 보호

- 앱 안에 프로젝트 생성, Vertex AI API 활성화, `Vertex AI 사용자` 역할 부여, 서비스 계정 JSON 키 생성과 선택 순서를 보여주는 안내 모달을 추가했습니다. 현재 Vertex 경로에서 사용하지 않는 별도의 Gemini API 활성화 단계는 넣지 않았습니다.
- 선택 단계에서 `.json` 확장자, 파일 크기, `service_account` 유형, 프로젝트 ID, 서비스 계정 이메일, 개인키와 Google 토큰 주소를 검사합니다. 잘못된 파일은 저장하기 전에 오류로 안내합니다.
- JSON 내용과 개인키는 앱 설정에 복사하지 않고 원본 파일의 로컬 경로만 저장합니다. 렌더러에는 파일명·프로젝트 ID·서비스 계정 이메일 같은 공개 메타데이터만 전달하며, 오류 보고서에서는 JSON 경로도 가립니다.
- 서비스 계정에는 대상 프로젝트의 `Vertex AI 사용자` 역할이 필요합니다. JSON 키는 비밀번호처럼 보관하고 더 이상 필요하지 않으면 Google Cloud에서 삭제하거나 폐기해야 합니다.
