# v2.0.0 패치노트

기준 범위: `v1.20.2` 태그(`4b2f6a63`)와 `v2.0.0` 릴리스 커밋의 직접 diff입니다. 최종 제품에 남은 변경만 기록했습니다.

## OpenAI Codex

- 시스템 Codex CLI와 로컬 OAuth HTTP 엔드포인트를 제거하고, 앱에 포함된 OpenAI 공식 Codex App Server로 교체했습니다. `설정 → LLM → Codex`에서 ChatGPT 계정으로 로그인하며 인증 정보는 앱 전용 데이터 디렉터리에만 저장됩니다.
- 대용량 이미지 요청 본문을 Electron 메인 프로세스의 로컬 HTTP 서버가 직접 버퍼링하던 경로를 없앴습니다. 이 변경으로 대용량 Codex 요청 중 앱 전체가 멈추던 [#79](https://github.com/ucx0204/CarrotMangaTranslator/issues/79)의 원인을 제거했습니다.
- 번역은 읽기 전용 임시 스레드에서 실행되고 완료 후 삭제됩니다. App Server가 제공하는 모델 목록과 추론 강도를 선택할 수 있고, 목록에 없는 모델 ID도 직접 입력할 수 있습니다.

## 용어집 인터넷 조사

- 작품명, 기존 용어·캐릭터, OCR 출현 정보를 바탕으로 용어집 변경안을 만드는 인터넷 조사를 추가했습니다. Tavily 검색 결과를 Gemma 또는 API 모델로 분석하거나, Codex 내장 웹 검색을 사용할 수 있습니다.
- 조사 결과는 출처, 신뢰도, 로컬 출현 근거와 함께 `추가·수정·비활성화` 변경안으로 표시됩니다. 사용자가 선택한 항목만 저장 전 초안에 반영되며, 수동 작성 항목은 자동으로 덮어쓰지 않습니다.
- Tavily API 키는 OS 암호화 저장소에 보관합니다. 연결 상태, 요금제, 월간 사용량·잔여량과 실행당 최대 크레딧을 확인할 수 있습니다.

## Gemma 4

- `12B·26B·31B 속도(추천)` QAT 4-bit 프리셋을 추가하고 기존 모델은 `레거시`로 유지했습니다. 속도 프리셋은 CUDA·Vulkan·Metal에서 llama.cpp b10621, 지원되는 Windows AMD 환경에서 Lemonade ROCm b1317을 사용합니다.
- 지원되는 NVIDIA CUDA 경로는 각 모델에 맞는 MTP 헤드를 사용합니다. 시작 점검에서 MTP 또는 VRAM 여유가 부족하면 저장 설정을 자동 변경하지 않고 원인을 안내합니다.
- 새 설정과 권장값의 Gemma 컨텍스트 길이는 `32,768`, 최대 출력 토큰은 `24,576`입니다. 입력·이미지용으로 `8,192` 토큰을 남기며 기존에 저장한 사용자 값은 강제로 바꾸지 않습니다.
- 기본 여유 VRAM은 12B `512 MiB`, 26B `1,024 MiB`, 31B `1,536 MiB`입니다. 직접 값을 조절할 수 있고, 저용량 GPU에서는 `mmproj`를 CPU에 둘 수 있습니다.

## 원본 해상도 출력

- 수동 결과물 출력과 연결 작업공간의 자동 저장 결과가 모두 원본 해상도를 유지합니다. [#80](https://github.com/ucx0204/CarrotMangaTranslator/issues/80)의 `4,445 × 6,053` 이미지와 `10,000 × 12,000` 이미지를 축소하지 않고 출력할 수 있습니다.
- 한 번에 캡처하기 큰 이미지는 최대 `4,096 × 4,096` 타일과 `8 px` 겹침으로 나눕니다. 겹친 부분을 잘라낸 뒤 원본 좌표대로 이어 붙여 경계 이음새와 픽셀 누락을 막습니다.
- 수동 출력창의 기존 옵션 구성은 그대로 유지했습니다. 지원 범위를 넘는 경우 픽셀 총량 대신 실제 이미지 해상도 `가로 × 세로`를 오류에 표시합니다.

## 번역·편집·인페인팅

- 누적 작품 컨텍스트 기록 범위를 `상세 기록·균형 기록·필수 용어만` 중에서 선택할 수 있습니다. 페이지별로 준비, OCR, 번역, 결과 정리, 글자·폰트, 인페인팅, 말풍선 단계의 소요 시간과 전체 합계를 확인할 수 있습니다.
- 작업 완료 알림음과 음소거·볼륨 조절을 추가했습니다. API 키 설정 화면은 빈 줄과 중복을 제외한 실제 저장 키 개수를 표시합니다.
- 병합된 OCR 조각도 원문 크기 측정값을 이어받아 자동 글자 크기를 복구합니다. 서로 연결된 말풍선은 연결 영역 전체의 원문 글자를 지우도록 마스크를 확장했습니다.
- Koharu Metal 인페인팅의 작업 버퍼를 입력 크기에 맞게 제한해 과도한 메모리 할당과 실패를 줄였습니다.

## 설치와 호환성

- Windows에 `CPU 네이티브 (매우 느림)` Flux 호환 모드를 추가했습니다. Python·Diffusers 없이 실행하며, 선택 시 검증된 CPU 실행 파일을 별도 릴리스에서 한 번 내려받습니다. 일반 CPU 인페인팅은 LaMa 또는 AOT가 권장됩니다.
- Windows 설치 프로그램이 데이터 저장 위치를 관리자 권한이 아닌 실제 앱 실행 사용자 권한으로 쓰기 검사합니다.
- 기존 프로젝트 형식은 호환되며, 저장된 Gemma 컨텍스트 길이와 최대 출력 토큰 값은 유지됩니다. 지원 운영체제는 Windows 10/11과 Apple Silicon macOS 14+입니다.
