# v2.7.4

- 영역 번역의 효과음 이미지 설정에서 ‘원문 지우기’ 옆에 ‘반전으로 처리’ 옵션을 추가했습니다. 켜면 원본 영역의 색상을 반전해 이미지 생성에 보내고, 생성된 효과음을 다시 반전한 뒤 합성합니다.
- 이미지 생성이나 원문 지우기가 sexual 사유로 거부되면 해당 영역만 제외하고 나머지 영역과 페이지의 처리를 계속하도록 수정했습니다. 거부된 영역에는 빨간 바운딩박스와 ‘sexual로 판정됨’을 표시하며, 저장 후 다시 열어도 표시가 유지됩니다.
- 이미지 생성 실패 시 거부 사유와 서버 오류의 상세 진단을 남겨 원인을 확인하기 쉽게 개선했습니다.
