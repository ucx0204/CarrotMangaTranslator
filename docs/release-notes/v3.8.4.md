# v3.8.4

페이지 작업의 진행률과 보관함 완료 표시를 실제 저장 상태에 맞추고, 오류 신고 로그에서 앱 버전과 빌드를 확인할 수 있도록 보완했습니다.

## 진행률과 완료 표시

- 여러 화와 단계를 처리할 때 현재 화·단계·페이지를 표시하고, 페이지 저장이 끝난 뒤 진행률과 편집 화면·보관함 상태를 갱신합니다.
- 번역이 끝났더라도 선택한 원문 제거·배치·검수가 남아 있으면 전체 작업이 완료된 것으로 표시하지 않습니다.
- 번역할 글자가 없는 페이지도 번역 단계를 정상적으로 마쳤다면 완료로 표시합니다. 기존에 저장된 빈 페이지 완료 기록도 읽을 수 있습니다.

## 오류 신고 로그

- 앱 시작 로그와 초기 실행 로그에 앱 버전, 운영체제·아키텍처, Electron·Node 버전을 기록합니다.
- 설치본에 빌드 기준 커밋과 미커밋 변경 여부를 포함해 로그에서 확인할 수 있습니다. 정보가 없는 개발 실행이나 이전 설치본은 알 수 없는 값으로 구분합니다.
- 이 변경은 진단 정보 보완입니다. 이슈 #170의 용량 증가나 #171의 OCR 설치 오류가 해결됐다는 의미는 아닙니다.

## AI 앱 연결 업데이트

- Codex CLI를 0.167.0으로 업데이트했습니다.
- Claude Code를 2.1.318, Agent SDK를 0.3.318로 업데이트했습니다.
- Grok Build CLI를 1.0.77로 업데이트했습니다.
- Windows x64와 macOS arm64 배포 파일의 버전·크기·해시를 검증하고, Windows에서 새 설치와 앱 연결 초기화를 확인했습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.4.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.4-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
