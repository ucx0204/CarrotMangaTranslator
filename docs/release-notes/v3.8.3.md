# v3.8.3

v3.8.1의 UI·접근성 개선과 v3.8.2의 macOS 마운트 검증 수정을 포함하는 후속 릴리스입니다. 배포 검사에서 파일시스템 속도에 따라 결과가 달라지던 테스트를 수정했습니다.

## 배포 검증 안정화

- 보관 이력 정리 테스트의 시계를 고정하고, 과거 이력 다음에 새 저장이 오도록 시간 순서를 명시했습니다. 빠른 파일시스템에서 테스트용 이력이 미래 시각으로 남아 기대한 정리 개수와 달라지는 문제를 해결했습니다.
- 앱의 보관 이력 정리 로직·데이터 보존 정책·UI·업데이트 동작은 변경하지 않았습니다.
- 숫자·단위 겹침, 포커스 테두리 잘림, 키보드 이동 등의 개선은 [v3.8.1 릴리스 노트](v3.8.1.md), macOS 업데이트 마운트 검증 수정은 [v3.8.2 릴리스 노트](v3.8.2.md)에서 확인할 수 있습니다.

## 설치 파일과 서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.8.3.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.8.3-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 플랫폼별 SHA-256 checksum과 빌드 commit·workflow를 기록한 provenance를 함께 제공합니다.
- v3.8.0 이상 사용자는 앱 내 업데이트로 새 버전을 받을 수 있습니다. macOS는 DMG를 연 뒤 앱을 교체합니다.
