# v2.7.13 — 저장·효과음 작업 안정화와 사용 가이드 개편

## 용어/기억 저장 충돌 수정

- 인터넷 조사에서 제안된 용어·캐릭터를 적용한 뒤 저장하면, 다른 편집이 없는데도 저장 충돌로 거절되던 문제를 수정했습니다.
- 제안을 적용하는 동안 기존 저장 버전을 유지하고, 실제 저장이 완료될 때 갱신합니다. 다른 작업이 먼저 저장한 내용에 대한 충돌 보호는 유지합니다. (#124)

## 효과음 이미지 작업 이어서 실행

- 이미지 작업을 이어서 실행할 때 가리기 영역과 효과음이 겹치면, 해당 페이지의 번역문을 보존하고 이미지 작업만 보류합니다. 나머지 페이지는 계속 처리합니다.
- 보류한 페이지와 원인을 작업 상태에 표시합니다. 가리기를 수정한 뒤 다시 이어서 실행하면 미완료 이미지를 처리할 수 있습니다. (#123)

## 편집 중 적용과 커서

- 서식 일괄 적용 창에서 **이 화 전체**를 선택한 뒤 해당 화에 작업 잠금이 생기면 적용을 막습니다. 잠금이 풀리면 같은 선택으로 다시 적용할 수 있으며, 잠기지 않은 현재 페이지의 적용은 유지합니다. (#122)
- 사각형·원형·사각 지우개에 흑백 이중 윤곽의 고정 십자 커서를 적용했습니다. 밝거나 어두운 원고와 OS 테마에 관계없이 그리기 시작점을 식별하기 쉽습니다. (#119)

## 다섯 언어 사용 가이드

- 한국어·영어·일본어·중국어 간체·번체 README를 같은 구조로 개편했습니다. 첫 페이지 완성 순서, 작업별 바로 가기, 접어서 보는 고급 설명으로 필요한 기능을 찾기 쉽게 했습니다.
- 현재 앱 화면으로 설정·번역·편집·일괄 처리·용어/기억·출력 설명을 갱신했습니다. 효과음의 한국어 이미지 변환 전후 예제와 텍스트 블록 편집 방법도 추가했습니다.
- 예제 원고와 효과음 이미지는 Codex 내장 imagegen으로 준비했고, UI와 식자는 실제 앱 컴포넌트로 캡처했습니다. 모델 성능 비교 자료는 아닙니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다. 각 플랫폼의 릴리스 절차에서 패키지와 실행 여부를 검증합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다. macOS에서 처음 실행할 때 **시스템 설정 → 개인정보 보호 및 보안**에서 실행을 허용해야 할 수 있습니다.
