# v1.3.0 패치노트

기준 범위: `v1.2.1` 이후부터 `v1.3.0`까지의 변경 사항입니다.
주요 포함 변경: 폰트 즐겨찾기·순서·기본 폰트 설정, 선택 블록 글자 크기 빠른 조절, 텍스트 모아보기 일괄 서식 편집, 블록 배경 투명도, 편집·설정 UI 개선과 v1.3.0 릴리즈 준비 변경.

## 새 기능 및 개선

### 원하는 폰트를 먼저 찾는 폰트 관리

- 자주 쓰는 폰트를 즐겨찾기에 추가하면 폰트 선택 목록의 위쪽에서 바로 찾을 수 있습니다.
- 폰트 관리 화면에서 검색하고 드래그해 순서를 바꾸며, 필요하면 저장된 순서를 초기화할 수 있습니다.
- 앱의 `기본 폰트`도 고정하지 않고 내장 폰트와 직접 등록한 TTF/OTF 폰트 중에서 자유롭게 지정할 수 있습니다.
- 즐겨찾기, 표시 순서와 기본 폰트 설정은 함께 저장되며 열린 편집 창과 내보내기 결과에도 같은 기준이 적용됩니다.

### 선택한 텍스트 블록의 글자 크기 빠른 조절

- 텍스트 블록을 선택한 뒤 `−`, `+` 버튼으로 글자 크기를 1px씩 바로 줄이거나 늘릴 수 있습니다.
- 숫자 입력란에서 정확한 크기를 직접 입력할 수 있고 허용 범위의 최솟값과 최댓값을 안전하게 적용합니다.
- 자동 맞춤 블록에서 크기를 직접 조절하면 현재 보이는 크기를 기준으로 고정 크기로 전환해 갑작스러운 크기 변화를 줄였습니다.

### 텍스트 모아보기의 여러 블록 서식 편집

- 텍스트 모아보기에서 현재 페이지 또는 전체 화의 블록을 여러 개 골라 하나의 편집 화면에서 서식을 바꿀 수 있습니다.
- 폰트, 크기, 가로·세로 배치, 굵게·기울임, 자동 맞춤, 색상, 외곽선, 줄 간격, 자간, 장평, 기울기와 투명도를 지원합니다.
- 선택한 블록들의 값이 서로 다르면 `혼합` 상태로 표시하고, 사용자가 실제로 변경한 항목만 전체 대상에 적용합니다.
- 첫 번째 선택 블록을 기준으로 결과를 미리 보며, 한 번의 적용을 하나의 실행 취소 기록으로 저장합니다.

### 텍스트와 블록 배경 투명도 분리

- 글자 투명도와 편집용 블록 배경 투명도를 별도 항목으로 나눠 각각 조절할 수 있습니다.
- 블록 배경 투명도는 선택한 블록, 현재 페이지 또는 전체 화 범위에 일괄 적용할 수 있습니다.
- 편집 화면, HTML 렌더링과 PNG 내보내기에서 새 투명도 값을 같은 방식으로 처리합니다.

### 선택 영역만 다시 번역

- 캔버스 작업 막대에 영역 번역 도구를 추가해 필요한 부분을 드래그하고 해당 영역만 다시 번역할 수 있습니다.
- 현재 작업 상태에 따라 사용할 수 있는 때만 활성화되며 기존 포인터·블록·인페인팅 도구와 같은 위치에서 전환할 수 있습니다.

## 사용성 개선

### 설정 화면 구조와 선택 방식 정리

- 번역 엔진, 연결·인증, 언어, 하드웨어·OCR, 기본 서식 설정을 목적별 섹션과 카드로 다시 구성했습니다.
- Codex와 원격 API 모델의 공개 한도와 앱 권장 생성값을 구분해 보여 주며, 권장값을 한 번에 적용해도 직접 입력한 값은 사용자가 선택하기 전까지 유지합니다.
- 기본 서식 설정에 실제 결과를 바로 확인할 수 있는 미리보기와 글자·색상·외곽선·세부 조정 영역을 추가했습니다.
- 작품 가져오기와 공유 파일 불러오기에서 카드 전체를 클릭해 대상을 고를 수 있도록 선택 영역과 키보드 접근성을 다듬었습니다.

### 편집 화면의 조작과 반응형 배치 개선

- 폰트 선택기, 숫자 입력, 선택 카드, 모달과 편집 도구의 간격·상태 표현을 통일했습니다.
- 텍스트 모아보기의 일괄 서식 편집은 대상 선택과 실제 적용 작업을 분리해 현재 단계와 적용 범위를 더 분명하게 표시합니다.
- 넓은 화면과 좁은 화면에서 주요 모달과 편집 컨트롤이 잘리거나 가로로 넘치지 않도록 레이아웃을 조정했습니다.

## 성능 및 안정성 개선

### 폰트 설정과 렌더링 일관성 강화

- 폰트 즐겨찾기·순서·기본값을 정규화하고 임시 파일을 이용해 원자적으로 저장합니다.
- 직접 등록한 폰트를 삭제하면 즐겨찾기, 순서와 기본 폰트 참조에서도 함께 제거해 유효하지 않은 설정이 남지 않도록 했습니다.
- 폰트 설정 변경을 열린 창에 동기화하고, 저장 실패 시 화면을 닫지 않은 채 오류를 확인하고 다시 시도할 수 있도록 보강했습니다.
- 블록별 폰트, 사용자가 정한 기본 폰트와 앱 대체 폰트의 우선순위를 편집 화면과 내보내기에서 동일하게 맞췄습니다.

### 일괄 편집과 설정 호환성 보강

- 여러 블록 서식 적용 시 항상 최신 화 상태를 기준으로 변경해 동시에 일어난 다른 편집을 덮어쓰지 않도록 했습니다.
- 새 글자·배경 투명도와 폰트 설정이 없는 기존 작품과 설정 파일도 기존 기본값으로 안전하게 열립니다.
- IPC 스키마, 패널 브리지, 설정 정규화와 내보내기 경로에 새 필드를 연결하고 잘못된 값은 허용 범위로 정리합니다.

## 내부 정리 및 테스트

- 폰트 설정 정규화·저장·삭제·창 동기화, 기본 폰트 우선순위와 내보내기 렌더링을 main/IPC/renderer 테스트로 검증합니다.
- 글자 크기 증감과 자동 맞춤 전환, 여러 블록의 혼합값·변경 항목만 적용·단일 실행 취소, 텍스트·블록 배경 투명도를 테스트로 고정했습니다.
- 설정 카드, 엔진 전환, 모델 권장값, 가져오기·공유 선택 UI와 반응형 레이아웃을 컴포넌트 테스트로 검증합니다.
