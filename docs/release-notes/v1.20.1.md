# v1.20.1 패치노트

기준 범위: `v1.20.0` 태그(`264f3a73`)와 이번 `v1.20.1` 최종 트리를 직접 비교했습니다. 개발 중 되돌린 실험이 아니라 최종 제품과 문서에 남은 차이만 기록했습니다.

v1.20.1은 빈 작업공간의 오른쪽 편집 패널을 정리하고 웹 링크 가져오기 화면의 조작 밀도를 개선하며, 여러 화 가져오기와 자동 지우기 안정성을 보강하고 현재 UI에 맞춰 README와 예시 화면을 전면 갱신한 릴리스입니다.

## 작업공간 오른쪽 패널

- 화를 열지 않은 초기 화면에서는 내용이 없는 오른쪽 편집 패널을 화면 밖으로 접고, 중앙 작업공간이 비어 있던 영역까지 사용하도록 변경했습니다. 페이지 빠른 도구 모음은 화면 오른쪽 가장자리에 그대로 유지됩니다.
- 보관함에서 화를 열면 오른쪽 편집 패널과 전용 레이아웃 영역이 240ms 동안 함께 자연스럽게 펼쳐집니다. 화를 닫으면 반대 방향으로 접히며, 숨겨진 패널은 포인터 입력과 보조 기술 탐색에서도 제외됩니다.
- 1,180px 이하의 좁은 화면에서는 패널을 기존처럼 작업공간 아래에 배치하되, 열려 있는 화가 없으면 렌더링 영역을 차지하지 않습니다. 모션 감소 설정을 사용하면 전환 애니메이션을 적용하지 않습니다.
- 초기·선택·전환 중간 상태와 넓은 창·좁은 창을 실제 프로덕션 컴포넌트로 캡처해 빠른 도구 모음 위치, 패널 겹침과 가로 오버플로가 없는지 확인했습니다.

## 웹 페이지 링크에서 이미지 가져오기

- 이미지 크기 필터의 `전체`, `중간이상`, `최대` 항목을 세로 목록에서 한 줄 가로 선택기로 변경했습니다.
- 웹 페이지 주소 입력란의 외곽 프레임 안에 다시 둥근 입력 테두리가 보이던 중첩 표현을 제거해, 링크 아이콘과 주소가 하나의 입력 영역으로 보이도록 정리했습니다.
- 필터 선택 상태와 URL 입력 프레임의 프로덕션 속성을 자동 테스트로 고정했습니다.

## README 및 예시 화면

- 한국어 README의 빠른 시작, 작업 단위, 설정, 번역·편집·출력과 문제 해결 설명을 현재 기능 기준으로 다시 작성했습니다. 초보자를 과도하게 단순화한 표현은 줄이고 실제 작업에 필요한 용어와 선택 기준을 직접 설명합니다.
- README 가이드 이미지 28장을 현재 프로덕션 UI와 QA 브리지로 전부 다시 캡처했습니다. 예시는 악역 영애로 빙의한 주인공이 이세계 문자를 이해하지 못하다가 번역 마법으로 해독하는 하나의 작업 흐름으로 구성했습니다.
- 빈 보관함의 접힌 오른쪽 패널과 수정된 웹 가져오기 필터·주소 입력란을 새 화면에 반영했습니다.
- 한국어·영어·일본어·중국어 README의 현재 버전, 패치노트와 설치 파일 링크를 `v1.20.1`로 맞췄습니다.

## 자동 지우기 안정성

- CUDA Flux에서 서로 맞닿거나 겹치는 여러 지우기 구간을 처리할 때 처리 창만 병합되고 합성 마스크는 개별 상태로 남아 작업이 중단되던 문제를 수정했습니다.
- Flux 처리 창과 구간별 마스크·합성 정보가 항상 같은 순서를 유지하도록 변경하고, 하드 경계가 없는 일반 말풍선에서도 같은 오류가 재발하지 않는 회귀 테스트를 추가했습니다.

## 여러 화 가져오기 안정성

- 폴더 기반 여러 화 가져오기에서 확장자는 이미지이지만 실제 바이트가 PNG·JPEG·WebP가 아닌 파일 하나 때문에 정상 페이지와 다른 화까지 모두 취소되던 문제를 수정했습니다.
- 가져오기 전 헤더 검사에서 해당 파일만 안전하게 제외하고, 확인 창에 제외 개수와 `화 제목 / 파일명`을 표시합니다. 정상 페이지와 화는 그대로 가져오며 잘못된 파일은 라이브러리에 복사하지 않습니다.

## Windows 패키지 안전성

- 개발 환경에서 저장소 루트를 앱 데이터 경로로 사용했더라도 `results`, 설정 세대, 블록 보관함과 연결된 작업공간 메타데이터가 설치파일에 포함되지 않도록 패키징 제외 규칙을 보강했습니다.
- Python 검사 캐시와 로컬 개발 도구 설정도 릴리스 패키지에서 제외합니다. 사용자 원본이나 로컬 설정 파일을 수정·삭제하지 않고, 패키징 입력에서만 제외합니다.
- Git 커밋과 push 전에 비공개 작업공간 경로를 검사하는 저장소 훅을 자동 설치하며, push할 커밋의 중간 이력에 해당 파일이 잠시 존재한 경우도 전송을 차단합니다.
- Windows와 macOS 패키징 완료 단계에서 `app.asar` 전체 목록을 다시 검사해 비공개 작업공간 파일이 하나라도 발견되면 산출물 생성을 실패 처리합니다.
