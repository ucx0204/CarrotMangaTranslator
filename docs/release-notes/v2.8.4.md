# v2.8.4 — 빈 번역으로 페이지 작업이 실패하던 문제 수정

- v2.8.3에서 일부 블록의 번역문이 비었다는 이유로 페이지 전체를 실패 처리하고 후속 작업을 중단하던 문제를 수정했습니다. 말줄임표·문장부호·효과음 등의 번역이 생략되어도 정상 번역은 저장하고 나머지 작업을 계속합니다.
- 번역 결과가 없는 빈 블록은 최종 결과의 블록 목록에서 제외합니다. 제외된 항목에는 인페인팅·폰트 맞춤·말풍선 배치·검수를 실행하지 않아 해당 원문 이미지가 유지됩니다. 이미 저장된 번역이나 수동 번역이 있는 블록은 보존합니다.
- 번역 대상이 모두 빈 결과여도 페이지를 실패시키지 않고 완료합니다. 기존 블록 유지 번역의 빈 응답을 정상 처리하며, 완료된 작업을 빈 번역만으로 계속 재시도하지 않습니다.
- v2.8.3에서 빈 번역 때문에 실패한 작업은 업데이트 후 이어서 실행할 수 있습니다. 이미 저장된 번역은 기본 설정에서 유지됩니다. 네트워크·응답 해석 오류 등 실제 실행 오류는 계속 보고합니다.
- v2.8.3의 기존 효과음 번역 신뢰도 필터 수정은 유지합니다.

## 배포 및 서명 안내

Windows x64 설치 파일과 Apple Silicon macOS 14 이상용 DMG·ZIP을 제공합니다.

Windows 설치 파일은 코드 서명되지 않았습니다. macOS 패키지는 임시 서명(ad-hoc)을 사용하며 Apple 공증을 받지 않았습니다.
