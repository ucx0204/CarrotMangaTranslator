# v2.7.2

- Codex ImageGen으로 만든 효과음 이미지도 블록 라이브러리에 저장하고 다시 사용할 수 있습니다. 이미지와 글꼴 굵기, 마스크가 함께 보존되며 다른 크기의 페이지에서도 크기와 비율을 유지합니다.
- 선택한 텍스트·이미지 블록을 Ctrl+C / Ctrl+V(macOS: Cmd+C / Cmd+V)로 복사하고 붙여넣을 수 있습니다. 페이지·화·작품을 이동한 뒤에도 여러 블록의 내용, 서식, 이미지와 상대 배치를 함께 붙여넣습니다.
- 붙여넣기는 한 번에 실행 취소할 수 있으며 입력칸에서는 기존 텍스트 복사·붙여넣기가 동작합니다. 단축키 도움말에도 블록 복사·붙여넣기를 추가했습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
