# v2.7.1

- Codex 효과음 이미지 생성에서 짧은 한국어가 일본어와 섞인 자형으로 나타나는 문제를 완화했습니다. 확정한 번역문을 글자 구조의 기준으로 삼고, 한글의 초성·중성·받침을 완성된 음절 안에 유지하도록 생성 지시를 보완했습니다.
- 원문을 번역할 목표 문자열로 잘못 표시하던 문제를 수정했습니다. 같은 스타일로 묶인 효과음도 앞서 생성된 글자의 잘못된 자형을 따라가지 않도록 했습니다.
- 원문의 색상·질감·외곽선·글자 묶음 배치는 계속 참고합니다. 특정 단어에 대한 예외 없이 적용하며 복잡한 표지 결과도 확인했습니다. 생성 결과에 따라 일부 자형 오류나 원문 획 잔재는 남을 수 있습니다.

## 코드 서명

- Windows 설치 파일은 Authenticode 미서명입니다. Apple Silicon DMG/ZIP은 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 포함하지 않습니다.
