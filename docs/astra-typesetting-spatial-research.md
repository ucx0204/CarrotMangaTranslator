# Astra 식자 2차 메커니즘 전환

2026-09-06 · v0.2.0은 승격되지 않았다. discovery-002의 원문 잔여는 기존 6번과
다른 작품에서도 발생했다. 이미 틀린 좁은 crop 안에서 같은 마스크를 재생하는
미세 조정을 중단한다.

## 증거와 조사 범위

`.tmp/astra-typesetting-research/research-transition-002/query-ledger.json`은
200개 고유 질의와 50개 원시 응답의 해시를 봉인한다. 이전 전환과 동일한 문자열의
질의는 없다. 이것은 200편을 읽었다거나 모두 적용 가능하다는 뜻이 아니다.
3D 검출·로봇 동작·모델 내부 token pruning 등 검색 범위가 빗나간 결과는 적용 근거에서
제외했다. 학습이 필요한 논문의 수치를 Astra의 프롬프트 변경 성능으로 인용하지 않는다.

## 다음 결정을 바꾼 자료

- [V\*](https://arxiv.org/html/2312.14135v2)는 전체 맥락과 필요한 부분의 시각적
  작업 기억을 결합한다. 우리에게 가져올 수 있는 가설은 원문을 더 크게 보게 하되
  위치 변환은 프로그램이 관리하는 것이다. 해당 논문의 학습된 모델과 성능은
  현 앱에 도입하지 않는다.
- [Iterative Visual Thinking](https://arxiv.org/html/2606.13156v1)은 평가한 소형
  모델에서 학습 없이 자기 bbox를 반복 수정시키면 악화되는 반례를 보인다.
  확대·반복 자체를 품질 증거로 보지 않는다. 이전 예측선을 정답처럼 보여 주는 대신
  여유 있는 원본 crop을 제시하고, 결과 전체를 새 화에서 검사한다. Astra 자체의
  실패율을 측정한 연구는 아니다.
- [COO](https://arxiv.org/abs/2207.04675)는 분리·잘린 효과음 조각을 연결하는 과제를
  별도로 다룬다. 잘린 crop 하나만으로 글자와 그 표현을 완결시킬 수 없다는 현재
  실패 분류에 부합한다. 데이터셋이나 모델을 내려받지는 않았다.
- [FontBench](https://arxiv.org/html/2603.08497v1)는 문자열 판독과 family/size/style
  판별을 분리한다. 250개 합성 이미지, 26개 폰트의 제한된 실험이며 일본어→한국어
  만화나 Astra의 성능 측정은 아니다. 실제 대상 폰트 견본, 굵기별 비교, 렌더 검수를
  유지하는 근거로만 삼는다.
- [Codex App Server](https://learn.chatgpt.com/docs/app-server)는 실험적 dynamicTools와
  thread/resume을 설명한다. 향후 Codex가 확대·측정·부분 렌더를 직접 선택하는 방식은
  가능성 있는 별도 후보지만 현재 설치 버전 계약과 실제 이미지 도구 반환을 검증해야 한다.
  지금 구현했다고 주장하지 않는다. API Responses 문서 검색 결과를 App Server 계약으로
  대신 쓰지 않는다.

## 사전 등록: v0.3.0-candidate

관찰: discovery-002의 source bbox 일부가 글자 열·후리가나·획을 잘랐다.
고정된 그 bbox 내부의 제거 계획은 반복해도 바깥 잔여를 지울 수 없다.

주요 메커니즘: 초기 페이지 판독 후, 원문 영역마다 가로 최소 24px/폭의 50%,
세로 최소 24px/높이의 20% 여유를 둔 원본 crop에서 제거 외곽을 직접 판단한다.
각 crop의 좌표를 실제 원본 픽셀에 고정한다. 외곽의 합집합으로 원문 bbox를 다시
정하고, 마스크 좌표는 같은 실제 픽셀을 가리키도록 재표현한다. **그 뒤** 화 전체의
최종 source crop을 비교해 서체를 묶는다. 정해진 좁은 bbox를 마스크 허용 한계로
사용하던 상류 계약을 바꾸는 한 후보다.

흰 말풍선에서 그림이 없는 연속 텍스트는 불필요하게 글자마다 조각내지 않고 안전한
한 외곽을 허용한다. 그림 위 글자는 기존 배경 생성·정합·제한된 보정·원본 복원 규칙을
통과해야 한다. 일본어라는 의미가 있는 제목을 단순히 로고라고 자동 제외하지 않는다.

고정: Astra high, ChatGPT 인증, 프리셋 4개 실제 폰트, family-first, 최대 2회 보정,
실제 앱 service와 편집·출력 경로. 같은 모델 용량 부족의 제한 재시도와 실패 기록 수정은
신뢰성 변경으로 구분한다. 기존 6번을 자동 재생하지 않고 다음 미사용 작품의 전체 화를
seed/hash로 먼저 봉인한다.

성공/기각: 전체 실제 저장본에서 원문 잔여·오탈자·지운 그림·접합선·서체 강조·줄바꿈을
직접 검사한다. 보존 영역의 원본 픽셀과 실패 영역 복원을 별도 측정한다. 검토로 남긴 원문을
번역 성공으로 세지 않는다. 범위 확대가 주변 글자나 그림을 지우거나 잔여/접합선 실패가
반복되면 기각한다. 다른 화와의 호출 수 차이는 workload 차이가 있으므로 절감률로 만들지 않는다.

보류: 내부 polygon 경계 정합, rich text 혼합 크기·굵기, 후기 image/text 선택 변경,
agent 도구 루프, 영구 checkpoint 재개. 이번 후보가 이 문제까지 해결했다고 주장하지 않는다.
