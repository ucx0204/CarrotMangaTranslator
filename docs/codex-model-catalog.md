# Codex 모델 목록 자동 갱신

모델 선택지의 권위는 로그인한 ChatGPT 계정으로 실행한 공식 Codex App Server의
`model/list` 응답이다. 앱에 모델 ID를 등록하지 않아도 응답에 포함된 새 모델과 해당
모델의 추론 강도를 표시한다. `src/shared/modelPresets.ts`는 알려진 모델의 생성 한도
등에 쓰는 보조 메타데이터이며, 모델 선택지의 허용 목록이 아니다.

## 조회와 갱신

- `src/main/codexAppServerClient.ts`가 `model/list`의 페이지를 조회한다.
- `src/main/ipc/codexAccountIpc.ts`가 계정과 모델 목록을 전달한다. 겹치는 계정 조회는
  하나의 요청을 공유하며, 완료된 목록을 앱 프로세스에 영구 캐시하지 않는다.
- `CodexAccountField`가 설정 화면을 열 때 조회하고, 화면이 보이는 동안 5분마다 다시
  조회한다. 창으로 돌아올 때도 마지막 조회 후 5분이 지났으면 갱신한다.
- 숨겨진 화면, 작업으로 잠긴 설정, 로그인·로그아웃 중에는 자동 조회를 멈춘다.
  이미 진행 중인 조회는 중복 실행하지 않고, 화면 종료나 인증 작업 전에 시작한
  조회 결과가 나중 상태를 덮어쓰지 않도록 폐기한다.
- 갱신에 실패하면 기존 목록과 선택을 보존하고 오류를 표시한다. 다음 조회가 성공하면
  오류를 지운다. 새 기본 모델이 등장해도 사용자가 선택한 모델이 유효하면 유지한다.

Codex 자체의 서버 캐시, 계정별 공개 범위, 실행기 호환성은 그대로 적용된다.
모델 카탈로그에 추가되는 모델은 자동 반영되지만 새로운 프로토콜이나 실행기 기능이
필요한 모델은 내장 실행기 업데이트가 필요할 수 있다. 실행 파일 자체를 검증 없이
자동 교체하지 않는다.

## Astra 확인 (2026-09-05)

내장 `@openai/codex`를 `0.150.1`에서 `0.153.1`로 갱신했다. npm 의존성·lockfile,
개발 실행기 버전 검사, Windows/macOS 패키징 버전 검사를 함께 맞췄다.

앱의 기존 로그인 계정과 실제 production `CodexAppServerClient`로 확인한 응답:

- 모델: `gpt-6-astra`, 표시명: `GPT-6-Astra`
- 추론 강도: `low`, `medium`, `high`, `xhigh`, `max`, `ultra`; 서버 기본값: `medium`
- 실제 Astra 요청: 일본어 `こんにちは`를 JSON 구조로 번역해 `안녕하세요` 응답 확인
- production 설정 화면을 1600×980, 1240×760에서 캡처해 Astra 드롭다운, 외부 스크롤,
  잘림과 정렬 확인

회귀 테스트는 Astra와 미등록 미래 모델의 자동 표시·선택, 갱신 실패·복구, 숨김·복귀,
요청 중복 방지, 로그아웃 뒤 늦은 응답 폐기, 작업 중 갱신 중지와 React StrictMode의
effect 재실행을 검증한다.

공식 계약: [Codex App Server의 모델 목록](https://learn.chatgpt.com/docs/app-server#models).

## 2026-09-12 실행기와 인증 복구

내장 실행기를 npm의 최신 `@openai/codex@0.154.0`으로 갱신했다. 의존성·lockfile,
개발/패키징 버전 검사와 QA 브리지의 표시 버전을 함께 맞췄다. 계정 목록에서 선택 모델이
일시적으로 빠져도 Astra를 기본 Sol로 자동 변경하지 않는다. 기존 선택을 표시하고
사용할 수 없는 모델이라는 안내를 띄운다. 정확한 모델이 있을 때만 추론 강도를 검증한다.

기존 실패 로그의 원인은 폐기된 refresh token이었다. 계정 조회는 `readAccount(true)`로
인증을 갱신하며, 해당 인증 오류는 로그아웃 상태와 재로그인 안내로 전달한다. 일반 통신
오류는 인증 오류로 간주하지 않는다. RPC·텍스트/이미지 턴 실패의 인증 원인을 보존하고
HTTP 401의 재시도 불가 오류로 전달해 일반 502나 이미지 결과 누락 문구로 가리지 않는다.

앱 재로그인 후 production 클라이언트에서 `gpt-6-astra`와 `low`부터 `ultra`까지의
추론 강도를 다시 확인했다. 실제 Astra 번역 요청은 `안녕하세요`를 반환했고,
production ImageGen 요청도 PNG 694,324 bytes, 1254×1254로 성공했다.
합성한 시험 이미지로 연결을 확인한 결과이며 작품 전체의 생성 품질 검증은 아니다.
실행 로그는 `.tmp/sfx-codex-live.log`에 있다.
