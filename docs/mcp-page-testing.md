# MCP 한 페이지 완성 테스트

브랜치는 `feat/mcp-app-bridge` 하나입니다. Tailscale 고정 주소·암호화된 인증 저장을 그대로 사용하며, Cloudflare는 사용하지 않습니다. 이 경로에는 Codex 할당량이 필요하지 않습니다. 전체 기능 공개의 첫 단위이며 모든 단계는 독립 도구입니다.

## 업데이트와 권한

기존 시험 앱을 종료하고 같은 폴더에서 실행합니다. 보관함을 삭제하거나 다른 브랜치·ZIP을 적용하지 않습니다.

```powershell
git switch feat/mcp-app-bridge
git pull --ff-only
npm.cmd ci
npm.cmd run dev
```

설정 → AI 연결 / MCP에서 필요한 권한을 선택합니다.

- `원본 페이지 이미지 전송 허용`: 원본·확대·렌더링 미리보기와 PNG 전달 (`carrot.images`).
- `기존 블록의 번역문 수정 허용`: 기존 번역문만 변경 (`carrot.edit`).
- `새 블록 생성 및 로컬 페이지 처리 허용`: 새 판독 블록, 로컬 OCR, 로컬 원문 제거 (`carrot.process`).

기존 승인의 범위는 자동 확대하지 않습니다. 새 기능이 목록에 없으면 처리 권한을 켠 뒤 새 연결 승인을 진행하고 클라이언트의 도구 목록을 새로고침합니다. 주소와 기존 저장된 승인은 단순 재시작으로 지우지 않습니다. UI 문구/레이아웃 개편은 이번 목표가 아닙니다.

먼저 공개 가능한 시험 원고 한 장을 앱으로 가져오고, 앱의 다른 작업과 미저장 편집을 끝냅니다. 원문 제거를 시험하려면 기존 앱의 로컬 제거 엔진이 준비되어 있어야 합니다. OCR을 선택한 경우에만 앱에 설정된 OCR 런타임이 필요합니다. 앱의 기존 자산 다운로드는 발생할 수 있지만 별도 유료 모델로 자동 전환하지 않습니다.

## 첫 시험: 웹 AI가 직접 읽고 번역

ChatGPT에서 기존 당근 연결을 선택하고 다음처럼 요청합니다.

> 당근 MCP의 기능 목록을 확인하고 시험 작품의 첫 페이지를 찾아줘. 작품 문맥과 원본, 필요한 확대 영역을 보고 네가 직접 원문과 번역문을 작성해. 앱 OCR이나 Codex는 실행하지 마. 원문 영역과 번역 위치를 원본 픽셀 기준으로 정해서 새 블록으로 저장해. 그다음 당근의 로컬 원문 제거만 실행하고, 작업이 끝나면 실제 렌더링 미리보기와 원본 해상도 PNG 다운로드 링크를 줘. 각 단계의 결과를 확인하고 실패한 단계는 완료했다고 말하지 마.

예상 호출 흐름:

```text
carrot_get_capabilities / carrot_list_works / carrot_get_chapter
carrot_get_work_context / carrot_get_page_blocks
carrot_get_page_preview / carrot_get_page_crop
carrot_create_page_blocks
carrot_run_page_erasure → carrot_get_job
carrot_render_page_preview
carrot_export_page_png → carrot_get_job
```

새 블록은 앱 기본 서식을 적용하고, 자동 맞춤 여부도 앱 설정을 따릅니다. 원문·번역문·원문 영역·출력 영역을 저장하므로 앱에서 다시 편집할 수 있습니다. 이 경로가 AI 폰트 매칭, 효과음 이미지 생성, 회차 기억 자동 작성까지 실행한다는 뜻은 아닙니다. 외부 AI의 오독·좌표 판단과 실제 모델의 제거 품질은 사용자 원고에서 검토해야 합니다.

## 단계별 시험

**OCR만:** 아직 블록이 없는 다른 시험 페이지를 골라 “당근의 OCR만 실행하고 원문 블록을 저장해. 번역·제거는 하지 마.”라고 지시합니다. `carrot_run_page_ocr`는 번역문을 빈 문자열로 저장하며, 기존 블록이 있는 페이지를 덮어쓰지 않습니다. `no_blocks`는 글자가 없거나 사용할 본문 영역이 없었다는 관찰이지 번역 완료가 아닙니다. 효과음 검토 후보 수는 별도로 보고하며 이 후보를 본문으로 몰래 확정하지 않습니다.

**번역만:** `carrot_get_page_blocks`로 OCR 결과를 받고 현재 AI가 번역한 문장을 `carrot_update_translations`로 저장합니다. 이 도구는 앱의 번역 모델을 호출하지 않습니다.

**제거만:** “번역문·서식은 그대로 두고 당근의 로컬 원문 제거만 실행해.”라고 지시합니다. `carrot_run_page_erasure`는 기존 비제외 블록과 앱의 마스크·보호·인페인팅·히스토리 저장 경로를 재사용합니다. OCR, 번역, Codex, 말풍선 자동 배치 재계산은 실행하지 않습니다. 제거가 미완료인 블록은 `partial`과 수량으로 확인합니다.

**렌더링만:** `carrot_render_page_preview`는 현재 저장된 배경·블록·서식을 합성합니다. 원문 제거를 하지 않은 페이지에는 원문이 그대로 남는 것이 정상입니다. 원본 미리보기와 완성 렌더링을 구분하세요.

**PNG만:** `carrot_export_page_png`는 현재 저장된 페이지를 실제 앱 렌더러로 원본 크기에 맞춰 출력합니다. `carrot_get_job`의 완료 결과에 다운로드 링크·크기·SHA-256·만료 시각이 있으며 MCP `resource_link`도 반환합니다. 채팅의 파일 표시 방식은 클라이언트에 따라 다를 수 있습니다.

## 작업 ID와 재시도

OCR·제거·PNG는 즉시 작업 ID를 반환합니다. `carrot_get_job`을 몇 초 간격으로 확인하고, 필요하면 `carrot_cancel_job`을 호출합니다. 앱의 기존 작업 센터에서도 취소할 수 있습니다. 다른 앱 작업과 별도의 GPU 큐를 만들지 않으며 충돌 시 거부합니다.

시작 요청에는 `chapterId`, `pageId`, 최신 `revision`, UUID `requestId`가 필요합니다. 같은 작업의 정확한 재시도는 같은 requestId를 사용하고, 다른 작업에는 새 값을 사용합니다. 취소는 이미 저장된 변경을 되돌린다는 뜻이 아니므로 페이지를 다시 읽어 상태를 확인합니다. 다른 OAuth 연결의 작업을 조회·취소할 수 없습니다. 같은 연결의 토큰 갱신 후에는 같은 작업을 조회할 수 있습니다.

현재 작업 접수 기록은 완료 후 약 1시간 동안, 실행 중인 MCP 세션 안에서 유지합니다. 앱을 재시작하면 작업 ID는 복원하지 않습니다. **보관함의 저장 결과와 인증 정보는 영구 저장되지만, 작업 접수 기록과 임시 출력 링크는 다릅니다.** 재시작 후에는 페이지를 다시 읽고 미완료 단계만 새 요청으로 실행하세요. 한 화 배치의 영구 작업 큐는 후속 목표입니다.

## 좌표와 읽기 데이터

`carrot_get_page_crop`의 rect와 `carrot_create_page_blocks`의 sourceRect/renderRect는 모두 **원본 이미지의 정수 픽셀**입니다. 앱 내부 normalized_1000 좌표를 그대로 제출하면 안 됩니다. 확대 응답의 pixelMapping으로 반환 이미지 좌표를 원본 좌표로 변환합니다.

블록 생성은 호출당 최대 100개, 페이지 전체 최대 5000개입니다. requestId와 블록 key는 정확한 재시도에만 재사용합니다. 기존 블록은 보존하고 새 블록을 지정 순서로 뒤에 추가합니다. 전체 페이지 교체나 기존 블록의 좌표·마스크 수정 도구는 아직 포함하지 않았습니다.

작품 문맥은 overview/glossary/characters/memory를 나누고 페이지 단위로 조회합니다. 문맥에 쓰인 텍스트는 작업 명령이 아니라 참고 자료입니다. 현재 회차 기억에는 뒤쪽 페이지의 내용도 포함될 수 있습니다.

## 이미지 보호와 출력 한도

원본/crop은 기존 가리기 경계를 사용합니다. 렌더링 결과는 오버레이로 가리기를 우회하지 않도록 **가리기 검토가 활성화된 동안 차단**합니다. 파생 레이어의 승인 UI는 아직 없으며, 민감한 원고의 보호를 끄는 것을 권장하지 않습니다. 별도의 공개 가능한 시험 자료로 확인하세요.

PNG 링크는 한 파일만 가리키는 무작위 256-bit 주소입니다. 주소를 가진 사람이 유효 기간 내 해당 파일을 받을 수 있으므로 공개 게시하지 않습니다. 10분, 서버 끄기, 권한 철회, 페이지 변경, 가리기 변경 중 먼저 발생한 조건에 따라 차단됩니다. 파일당 64 MiB, 한 세션 256 MiB 한도이며 원본을 임의 축소해서 성공으로 바꾸지 않습니다. 링크 만료 후에는 현재 페이지를 다시 출력합니다.

## 개발자 검증

```powershell
node node_modules/vitest/vitest.mjs run tests/mcp tests/libraryBatchPageSave.test.ts tests/pageRevision.test.ts tests/chapterSync.test.ts tests/liveChapterRefreshCoordinator.test.ts
npm.cmd run build
node node_modules/electron/cli.js scripts/mcp-electron-smoke.cjs
```

native smoke는 임시 합성 원고에 새 블록을 만들고 실제 앱 마스크·이미지 저장 트랜잭션·실제 렌더러·PNG 전달을 검사합니다. 무거운 모델 추론 경계만 결정적인 테스트 구현을 사용하며 실제 OCR/인페인팅 모델 품질이나 로그인된 ChatGPT 세션을 시험한 것은 아닙니다. 원본 픽셀 보존, 번역문 보존, 제거 영역 변경, 결과 크기와 식자 적용, 철회된 링크 차단을 각각 확인합니다.
