# 승인된 식자 개선의 앱 적용

## 적용 상태와 종료 결정

내부 버전 `typeset-v0.1.0`으로 승격했다. 이어 앱 적용과 커밋을 명시적으로 지시했고,
추가 시각 검토는 직접 전부 확인했다는 이유로 생략하도록 했다. 새 후보·추가 튜닝은
종료한다. 국소적인 미학 손해가 남아 있다는 이유로 이 승격을 다시 보류하지 않는다.

연구 기준은 `b9071432`(2.4.3), 앱 적용 대상은 `28ddd924`(2.4.4) 이후의 `master`다.
제품 코드와 행동 테스트 통합 커밋은 `e35bdead`이며, 별도 연구 워크트리의 대응 커밋은
`a9231bf9`다. 앱 버전·릴리스 자산·모델 버전은 이 작업에서 올리지 않았다.

## 앱에서 달라지는 동작

- 원문 글씨의 실제 래스터 증거, 짧은 글자와 말줄임표의 글자 수 해석을 보완한다.
  일반 본문은 고정 px 증가 없이 작은 광학 보정을 적용한다. 신뢰할 수 있는 같은
  페이지의 유사 글꼴 증거를 사용할 수 있으며 페이지 전체 중앙값을 무조건 복사하지 않는다.
- 같은 모델 mask를 공유하는 연결 말풍선은 원문 중심과 mask 안의 경로를 이용해
  각 발화의 영역을 나눈다. 모델 자체와 OCR 발화 경계는 유지한다.
- 자동 생성한 가로 식자는 실제 폰트 폭, 어절, 한 글자 줄, 문단 균형과 mask 내부의
  공간을 함께 비교한다. 안전한 글자 크기를 정수 크기별로 탐색하며, 사용자 지정
  글자 크기·명시적 줄바꿈·수동 배치의 계약은 유지한다.

메인 경로는 `src/main/pipeline/sourceFontSizeEstimator.ts`와
`src/main/bubbleLayout/bubbleLayoutPageProcessor.ts`, 렌더러 경로는
`src/renderer/src/lib/overlayLayout.ts`와 `bubbleBlockTextLayout.ts`다.
실제 편집 화면과 이미지 출력이 사용하는 기존 렌더러에 적용한 것이며 연구용
HTML만 수정한 결과가 아니다. 저장된 원본과 기존에 내보낸 이미지 파일은 변경하지 않는다.

판타지·이세계 비중이 높은 보유 코퍼스이므로 모든 장르를 대표하는 통계 표본은 아니다.
이 표본으로 승인된 제품 코드를 변경하지 않았다. Codex 시각 메모를 사용자 정답
라벨이나 학습 데이터로 전용하지 않는다. 91페이지 OCR 분리 실패 세트는 이번 미학
평가에서 제외했고, 기존 49개 사용자 판정·8개 경계 보호 조건의 권위는 바꾸지 않았다.

## 남은 한계

짧은 반응·속삭임이 너무 작은 사례, 긴 단어를 붙이면서 강조가 약해지는 사례,
일부 부호만 남는 줄과 바깥 독백의 큰 글씨는 남아 있다. 전체적으로 개선됐다는
사용자 판단을 따르며 이러한 부분을 새 연구의 자동 재개 조건으로 삼지 않는다.
OCR 누락·지우기·선택 폰트 결함도 이번 식자 개선의 성공으로 세지 않는다.

## 적용 검증과 되돌리기

Windows / Node 26.7.0의 앱 기본 작업 폴더에서 전체 기능 테스트와 기존 커버리지
하한을 확인하고 실제 앱을 빌드했다. 사용자 지시에 따라 추가 수동 시각 QA는
생략했으며 자동 화면/출력 parity와 이미지 프로토콜 smoke는 실행했다.

- `npm run check` 통과: 테스트 646개 파일, 5,194개 통과·2개 플랫폼 조건부 생략.
  타입 검사·린트·포맷·구조·중복·미사용 코드 검사, 앱 빌드와 번들 경계도 통과했다.
- 커버리지: 기존 664개 파일·추가 396개 파일·삭제 10개 목록을 검증했다. 기존 하한은
  낮추지 않았으며 실제 측정 자료로 새 경로 9개를 등록했다. mask가 지원하지 않는
  영역의 소유권 fallback, 작은 raster 경계와 글씨가 전혀 들어갈 수 없는 경우,
  빈 번역의 동작을 추가 행동 테스트로 보호했다.
- 실제 편집 패널 / 이미지 출력 parity: 두 시나리오 모두 `mismatchedPixels=0`,
  `maxChannelDelta=0`. 긴 경로 이미지 프로토콜 smoke도 통과했다.
- 검사 로그: 기본 작업 폴더 `.tmp/typeset-app-apply-check-final.log`,
  `.tmp/check-logs/`, `.tmp/check-timings.json`.
- 제품 소스는 승인된 C5 해시 그대로이며 후속 수정은 테스트·커버리지 목록·문서다.
- 되돌릴 때는 `e35bdead`의 제품 변경과 대응하는 후속 테스트·커버리지 변경을 함께
  되돌린 뒤 다시 빌드한다. 연구화 사용 기록과 실험 자료, 사용자 보관함·출력물은
  보존한다. 다른 기능의 2.4.4 변경은 유지한다.
